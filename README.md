# 中医经典 AI 导师 — TRAE Skills

> 基于 TRAE AI Agent 的中医经典学习规则系统。以**黄帝内经**为绝对理论根基，**六经辨证**为核心实践工具，整合温病学、《伤寒杂病论》、《黄帝内经》三大经典，提供对话式学习、多学派临床案例分析与 L1-L4 渐进式水平评估。

本项目是一套**规则文档与知识库**，设计用于在 TRAE 中激活相应 Skill 后，由 AI Agent 按照规则进行教学。不包含可执行的应用代码。

---

## 工作流概览

用户在 TRAE 对话中说出触发词 → TRAE 自动激活对应 Skill → AI Agent 读取 `agent_prompt.md` + `shared_config.md` → 按规则进行对话式教学。

```
用户："开始温病学习"
  ↓
TRAE 激活 中医温病课程导师 Skill
  ↓
AI Agent 读取 agent_prompt.md + shared_config.md
  ↓
检查进度文件 → 读取学习次数 → 确定课程内容
  ↓
首次使用？→ L1-L4 水平评估 → 确定教学策略
  ↓                L3/L4？→ 学派偏好询问
  ↓
意义锚点 → 内经理论溯源 → 六经定位 → 条文/医案讲解
  ↓
用户给出方药？→ 多学派三层触发 → 五步分析流程
  ↓
提问互动（四大题型 / 四步提问 / 五步提问）
  ↓
保存学习记录 → 更新进度 → 间隔重复系统安排复习
```

### 理论层级

```
黄帝内经（阴阳五行 / 藏象经络）  ← 绝对理论根基
  ↓ 统摄
伤寒杂病论 + 温病课程  ← 六经辨证为实践工具
  ↓ 引用
15 位医家多学派视角  ← 辅助参考，平等触发
```

## 三大学习导师

| 导师 | 触发词（学习） | 触发词（测试） | 理论根基 | 实践工具 | 提问法 | 水平评估 |
|------|:---|:---|:---|:---|:---|:---|
| 温病课程导师 | 开始温病学习 / 继续温病学习 | 开始温病测试 | 黄帝内经 | 六经辨证解温病 | 四大题型教学法（L1/L2）/ 讨论式（L3/L4） | L1-L4 |
| 伤寒杂病论导师 | 开始伤寒杂病学习 / 继续伤寒杂病学习 | 开始伤寒杂病测试 | 黄帝内经 | 六经辨证（伤寒金匮合一） | 四步提问法 | L1-L4 |
| 黄帝内经导师 | 开始内经学习 / 继续内经学习 | —（无测试） | 原生阴阳五行藏象经络 | — | 五步提问法（含哲学思辨） | 无 |

### 核心设计理念

- **内经为体，六经为用**：内经理论是绝对根基，六经辨证是实践工具
- **有是证用是方**：方证对应的本质是"药证对应"，不僵化套用病名
- **病机对应而非方证对应**：关注病理环境而非线性"敌人"思维
- **整体评判处方**：方名仅具引导意义，看实际药物组成和剂量比例
- **模糊用词先确认再评价**：用户使用模棱两可的词语时，先确认含义再评价
- **意义先行**：教学不从知识点开始，从意义开始——先让学生感受到"为什么学"（详见教学方法论）

### 各课程学习流程

**温病课程**：以胡希恕《六经辨证解温病》为核心教材，将卫气营血/三焦体系翻译为六经语言。每节课围绕一个核心概念展开，L1/L2 用户采用四大题型教学法（概念提出 → 定义题 → 应用题 → 反向提问 → 自由发散 → 总结），L3/L4 用户直接进入独立辨证与讨论式教学。每节课包含两个真实医案，按"意义锚点 → 内经理论溯源 → 六经定位 → 医案分析 → 多学派分析"流程进行。

**伤寒杂病论课程**：将《伤寒论》与《金匮要略》统一于六经框架，以伤寒论六经条文为骨架，将金匮要略条文按六经归属插入对应经中。金匮要略第1篇（王叔和整理内容）排除，从第2篇开始学习。每条含方剂的条文围绕四步提问法展开，必须展示"内经理论溯源 → 多学派专家视角解读"。

**黄帝内经课程**：以哲学方式学习，保持原生阴阳五行、藏象经络体系，以内经原生框架为主、允许概念溯源。结合《说文解字》逐字溯源、《周易》《淮南子》追溯哲学源头，素问灵枢并重。采用五步提问法（定义题 → 应用题 → 哲学思辨题 → 反向提问 → 自由发散题），含L1-L3水平评估、原文分类教学、多注家解读（王冰、张景岳）、临床指导意义与概念溯源。复习采用黄帝-岐伯问答格式。

## 水平评估与分层教学

> 温病和伤寒杂病论课程内置 L1-L4 四级水平评估系统，根据学习者水平动态调整教学策略。黄帝内经课程使用L1-L3三级评估系统。

### 层级定义

| 层级 | 名称 | 判断依据 | 教学策略 |
|:---|:---|:---|:---|
| L1 | **入门** | 不能独立辨证，方药陌生 | 选项引导为主，详细术语解释 |
| L2 | **进阶** | 能辨证但方药不够精准 | 开放提问为主，关键术语解释 |
| L3 | **实战** | 能独立开出有效方药 | 讨论式教学 + 追问 |
| L4 | **精通** | 能灵活化裁，有独到见解 | 平等讨论 + 反向提问 |

### 评估方式

| 方式 | 适用场景 | 耗时 | 说明 |
|:---|:---|:---|:---|
| 快速评估 | 首次启动 | ~1 分钟 | 3 个问题快速判断 L1/L2 分界 |
| 系统化测试 | 首次启动或重新评估 | 15-20 分钟 | 4 模块递进式测试（基础知识 → 简单辨证 → 处方能力 → 深度分析），每模块有分数线，达不到则终止并判定层级 |
| 动态评估 | 案例分析中 | 随教学进行 | 根据用户首次案例分析表现自动匹配层级 |

### 学派偏好询问（L3/L4 专属）

当用户首次被评估为 L3 或 L4 层级时，系统主动展示 15 位医家的学术视角概述，询问用户是否希望固定某些医家在每次分析中出现。用户选择的医家在每次分析中固定出现，其他学派仍按处方特征自动触发。用户未选择时，所有学派按三层触发机制平等触发。

## 教学方法论

> 基于意义系统理论，指导教学流程设计。核心主张：教学不从知识点开始，从意义开始——先让学生感受到"为什么学"，再告诉"学什么"，最后才讲"怎么学"。

| 原则 | 核心要点 |
|:---|:---|
| **意义先行** | 每节课先建立"意义锚点"（为什么学这个），再进入核心内容，最后展开细节。不直接摆出学科结构作为教学起点 |
| **行为主义基础设施** | 基础性内容（药名、方名、条文原文）通过间隔重复系统（1-3-7-14-30-60 课次）建立"基础设施"，意义建构在此之上进行"精装修" |
| **新词管理** | 每节课引入新术语控制在 3-5 个以内，遵循"先功能后命名"原则——先用已理解的概念解释功能，再给出正式名称 |
| **意义空缺营造** | 引入新知识前先创设"认知断裂"，让学生感受到"这里缺了点什么"，然后才命名新知识 |
| **双向螺旋学习** | 自上而下（先搭框架再填细节）与自下而上（先积累案例再形成结构）交替进行，螺旋上升 |

## 多学派分析系统

> 温病和伤寒杂病论课程整合 15 位中医名家的学术视角。当用户在课程中给出方药时，系统自动触发多学派分析。黄帝内经课程不使用此系统。

### 三层触发机制

系统采用三层独立机制识别用户处方中的学派特征（详见 `common/学派触发映射表.json`）：

| 层级 | 识别依据 | 特点 |
|------|---------|------|
| 第一层：药对映射 | 处方中出现的药对组合（如桂枝-白芍、柴胡-黄芩） | 机械查表，不依赖 AI 推理 |
| 第二层：病机推理路径 | 症状群组合特征（如胸闷+脉促+微恶寒） | 不依赖药物，即使药对未命中也能触发 |
| 第三层：组方法度 | 处方整体结构逻辑（如五味补泻规则） | 看整体逻辑而非局部药对，区分度最高 |

三层互相独立，任一层命中即触发对应学派；多层同时命中提升该学派分析优先级。所有学派平等触发，不预设优先级。

### 三级应用体系

| 层级 | 要求 | 适用医家 |
|:---|:---|:---|
| **精通** | 药物组成完整、剂量合理、每味药及药对推论逻辑清晰、可独立辨证开方、可与原方逐药对比 | 核心医家 |
| **通识** | 引用经典方剂并展示药物和剂量，以独立辨证为主 | 重要医家 |
| **了解** | 能说出该医家大概的学术思想和用药习惯，在提问中增加"X医家会怎么治" | 拓展医家 |

系统不预设任何学派的层级分配，所有学派在分析中平等呈现。用户可在学习过程中随时声明想深入了解的学派，系统据此调整分析深度。

### 五步分析流程

| 步骤 | 内容 |
|:---|:---|
| **1. 学派识别** | 三层触发机制汇总：药对查表 → 症状群匹配 → 组方逻辑识别 → 回查用户固定关注的学派 |
| **2. 学派逻辑分析** | 用识别到的学派辨证逻辑分析用户方药，说明"这一套逻辑出现在谁的理论体系里" |
| **3. 其他学派视角补充** | 其他医家给出逻辑和依据，格式："我将以[医家名]的学术思想来回应你：[逻辑]→[依据]→[结论]" |
| **4. 综合评价与辩论** | 综合各方视角，指出方药正确之处和有失偏颇之处，促使用户与系统辩论 |
| **5. 标注整合观点** | 标明综合了哪几家的观点，若用户感兴趣可进一步深度询问 |

## 间隔重复系统

系统内置间隔重复机制，自动安排已学知识点的复习：

| 复习次数 | 距上次复习间隔（课次） |
|----------|:---:|
| 第1次 | 1 |
| 第2次 | 3 |
| 第3次 | 7 |
| 第4次 | 14 |
| 第5次 | 30 |
| 第6次及以后 | 60 |

每个知识点在进度文件中记录首次学习课次、已复习次数、下次应复习课次和掌握状态。**间隔复习仅在综合复习课时检查**，非综合复习课不触发。若复习后发现仍未掌握，重置间隔从第1次重新开始。

## 使用方式

### 1. 导入 TRAE

将本项目克隆或下载到本地，在 TRAE 中打开该目录。TRAE 会自动识别 `.trae/skills/` 下的技能。

### 2. 配置本地路径

各 Skill 文件中的路径为示例路径（如 `e:\叶天士\叶天士\`）。使用前请替换为你本地的实际路径。详见各 Skill 目录下的 `SKILL.md` 和 `common/shared_config.md` 中的路径配置说明。

### 3. 激活技能

在 TRAE 对话中，说出对应的触发词即可激活技能：

- **温病导师**："开始温病学习" / "继续温病学习" / "开始温病测试"
- **伤寒杂病论导师**："开始伤寒杂病学习" / "继续伤寒杂病学习" / "开始伤寒杂病测试"
- **黄帝内经导师**："开始内经学习" / "继续内经学习"
- **文档内化工具**："开始内化" / "处理新文档" / "录入新医家"（也可在新文档加入知识库时自动触发）

### 4. 在非 TRAE Agent 中使用（Claude Code / CodeX 等）

TRAE 以外的 AI Agent 没有"关键词触发 Skill"机制，但可以手动加载规则文件获得等效体验。当用户说出触发词时，Agent 应读取对应的 `agent_prompt.md` 并按其规则行事：

| 用户说出 | 应读取的规则文件 | 进入模式 |
|---------|----------------|---------|
| "开始温病学习" / "继续温病学习" | `.trae/skills/中医温病课程导师/agent_prompt.md` | 学习流程 |
| "开始温病测试" | 同上 | 4 模块渐进评估 |
| "开始伤寒杂病学习" / "继续伤寒杂病学习" | `.trae/skills/中医伤寒杂病论学习导师/agent_prompt.md` | 学习流程 |
| "开始伤寒杂病测试" | 同上 | 4 模块渐进评估 |
| "开始内经学习" / "继续内经学习" | `.trae/skills/中医黄帝内经学习导师/agent_prompt.md` | 学习模式（无测试） |
| "开始内化" / "处理新文档" / "录入新医家" | `.trae/skills/文档内化工具/agent_prompt.md` | 文档内化（自动/手动触发） |

> **给 Agent 的指令**：若你是不支持 Skill 自动触发的工具（如 Claude Code、CodeX），请在首次对话时读取 `CLAUDE.md` 中"Skill 触发规则"章节，据此响应用户的学习/测试请求。

## 知识库说明

`叶天士/00-原著全文/` 下的文本均为公开古籍或讲稿的文本版，供 AI 检索引用时使用。涵盖：

- **伤寒论类**：伤寒论原文（398条净本）、刘渡舟讲稿、郝万山讲稿
- **温病类**：六经辨证解温病（胡希恕）、温热论（叶天士）、温病条辨（吴鞠通）
- **金匮要略类**：金匮要略原文（22篇）、胡希恕金匮讲座
- **医案类**：叶天士、吴鞠通、王孟英、丁甘仁、胡希恕、曹颖甫等
- **黄帝内经类**：素问校释、灵枢经、黄帝内经词典、白话全译、说文解字、周易、淮南子
- **各家学说库**：辅行诀（陶弘景）、伤寒论诠解/金匮要略诠解（刘渡舟）、伤寒论讲义/医学衷中参西录（张锡纯）、四圣心源/伤寒悬解（黄元御）、伤寒论今释（陆渊雷）、太极三部六经（田合禄）、丹溪心法（朱丹溪）、圆运动的古中医学（彭子益）、脾胃论（李东垣）

### 名贵药材不可得处理

以下药材现代已不可得或极难获得，评判处方时不得以"缺少名贵药材"扣分：犀角（替代水牛角）、羚羊角（替代山羊角/水牛角）、天然牛黄（多为人工牛黄替代）、紫雪丹、龙骨。替代方案讨论应基于功效维度而非逐药对应。
