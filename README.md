# 中医经典教学系统（TCM AI Tutor）

> 一套"开箱即用"的中医经典学习系统：**《伤寒论》《金匮要略》《温病条辨》三书合一**（伤寒温病大一统），以《黄帝内经》为理论根基，六经八纲为教学框架（脚手架，非唯一真理），配合 21 位医家多学派视角 + 真实医案 + 四步提问法实现深度学习。
>
> 仓库内容 = **技能体系（skills/）+ 经典知识库（叶天士/00-原著全文/）+ 规则文档**，无应用代码，任何人可接入自己的 AI 工具使用。

## ⭐ 老用户升级必读（重要）

> **您是否用过旧版**（温病/伤寒/金匮三套独立课程）？本系统已升级为【经典临床】——三书合一教学（伤寒温病大一统），新版是当前唯一维护的版本。

| 对比 | 旧版（温病/伤寒/金匮分开） | 新版（经典临床合一） |
|:---|:---|:---|
| 课程结构 | 三套独立课程，各学各的 | 六经框架贯穿伤寒+金匮+温病，一经一学 |

**我们推荐您迁移到新版**：虽然新版会打乱您原来的学习顺序，但它**更科学、更有效、更有逻辑**——六经框架让伤寒金匮温病互相印证，方证簇让知识形成网络，多维画像让教学精准贴合您的实际水平。学习进度保留，旧笔记可按方证体系重新归类。AI 会在对话中自动识别老用户并播报迁移说明（详见 `CLAUDE.md` ★ 章节）。

> 若您从未使用过旧版，请忽略本公告，直接按下方说明开始使用。

## 快速开始（1 分钟）

1. 下载本仓库。
2. 把 `skills/` 目录复制到你的 **vault 根目录**（与 `00-原著全文/` 同级），或按下方"接入指南"放入你的 AI 工具对应位置。
3. 打开你的 AI 工具（TRAE / ZCode / Claude Code 等），对 AI 说：

   > **"开始经典临床学习"**

4. AI 会自动读取 `skills/经典临床/SKILL.md` 与 `课程流程.md`，从水平评估开始教学。**课程笔记目录由 AI 自动创建**（如 `01-经典临床（正课）/`）。

## 接入指南

技能体系是中性目录 `skills/`，各工具接入方式：

| 工具 | 接入方式 |
|------|---------|
| **TRAE** | 复制 `skills/` → 项目 `.trae/skills/`（自动识别 SKILL.md） |
| **ZCode** | 复制 `skills/` → 项目 `.zcode/skills/`（自动识别 SKILL.md） |
| **Claude Code** | 无需复制，AI 按 `CLAUDE.md` 第八章触发规则加载 |

> 路径说明：技能文件内全部为**相对路径**（基座 = vault 根目录）。只要 `skills/` 与 `00-原著全文/` 同级，所有引用自动生效。

## 技能体系（skills/）

| 技能 | 触发词 | 内容 |
|:---|:---|:---|
| **经典临床** | "开始经典临床学习"/"开始学习"/"继续学习" | 伤寒+金匮+温病合一临床教学（四步提问法+真实医案+多学派分析） |
| **黄帝内经** | "开始内经学习" | 内经哲学精读（道） |
| **经典基础** | "开始经典基础学习" | 内经生理+诸病源候论病理（术中之道） |
| **诊疗基础** | "开始诊疗基础学习" | 药理+诊断（案例驱动桥） |
| **文档内化工具** | "开始内化"/"处理新文档" | 新文档→医家学术体系内化 |
| **AI编程行为准则** | 编码任务自动触发 | AI 编程底层规范 |

- **新建技能**：复制 `skills/_新建技能模板/` 或运行 `python skills/common/新建技能.py <技能名>`（见模板内"建技能说明.md"）。

- **意义先行**：每课从"意义锚点"开始（第九章），不从知识点直接切入。

## 学习路线建议

```
黄帝内经（道·哲学根基）→ 经典基础（术中之道·生理病理）→ 诊疗基础（案例桥·认病用药）→ 经典临床（术中之术·辨证开方）
```

可从任意一步开始，随时调整。六经八纲仅是默认教学框架——若你有自己的辨证体系（黄元御一气周流、彭子益圆运动、卫气营血等），可在"方法精通表"中切换，条文与医案对所有体系通用。
