# 中医经典 AI 导师 — TRAE Skills

> 基于 TRAE AI Agent 的中医经典学习规则系统。以**黄帝内经**为绝对理论根基，四大模块分层教学：**内经精读**（道·世界观）→ **经典基础**（术中之道·生理病理）→ **诊疗基础**（案例驱动桥·认病用药与四诊）→ **经典临床**（术中之术·辨证开方），其中经典临床将《伤寒论》《金匮要略》《温病条辨》三书合一教学（伤寒温病大一统），提供对话式学习、多学派临床案例分析、案例驱动教学与 L1-L4 渐进式水平评估。

本项目是一套**规则文档与知识库**，设计用于在 TRAE 中激活相应 Skill 后，由 AI Agent 按照规则进行教学。不包含可执行的应用代码。

## 工作流概览

用户在 TRAE 对话中说出触发词 → TRAE 自动激活对应 Skill → AI Agent 读取 `agent_prompt.md` + `shared_config.md` → 按规则进行对话式教学。

```
用户："开始诊疗基础学习"
  ↓
TRAE 激活 中医诊疗基础学习导师 Skill
  ↓
AI Agent 读取 agent_prompt.md + shared_config.md
  ↓
检查进度文件 → 读取学习次数 → 确定课程内容
  ↓
模式确认（药理层/诊断层/完整回放/混合）→ L1-L4 水平评估
  ↓
意义停顿 → 案例呈现 → 病机回指 → 药理/诊断教学
  ↓
药池阶梯（积累→半自主→自主→进阶）| 四诊图谱直接贴出
  ↓
提问互动（双套五步 / 四步 / 五步提问）
  ↓
保存学习记录 → 更新进度 → 三线复习 + 间隔重复系统
```

### 核心设计理念

- **内经为体，经典为用**：内经理论是绝对根基，六经八纲是默认教学框架（脚手架）
- **伤寒温病大一统**：将《伤寒论》《金匮要略》《温病条辨》统一于六经辨证框架下教学
- **病机在教学链中的归属**：病机**在经典基础教学**（逆向五步），诊疗基础只做**回指调用**，不重复教学
- **有是证用是方**：方证对应的本质是"药证对应"，不僵化套用病名
- **整体评判处方**：方名仅具引导意义，看实际药物组成和剂量比例
- **意义先行**：教学不从知识点开始，从意义开始——先让学生感受到"为什么学"（详见教学方法论）

### 各模块学习流程

**经典基础学习**（术中之道）：把内经世界观落成医学理论。先学生理堆（内经生理主题：阴阳、藏象、脾胃、经络气血、病机总纲、治未病养生），再学病理堆（诸病源候论病候，范式源层与脏腑病机层螺旋交替）。病理教学用"逆向五步"范式（呈现症候 → 归病机 → 溯病因 → 归脏归经 → 回指生理），提问法为该范式的教学化（病理层五步）。**排课表**：生理堆 9 主题内嵌于 SKILL；病理堆按 `参考/病源核心层清单.md`（33 门类 602 条候）逐条推进。复习用三线（生理/病理/跨线对照）。

**诊疗基础学习**（案例驱动桥）：以真实医案驱动，教"怎么认病"（诊断）与"怎么用药"（药理）。**四模式可插拔**：A 药理层 / B 诊断层 / C 完整回放（推荐）/ D 混合。**两阶段**：阶段一药理（案例驱动学药，药池阶梯：积累→半自主→自主→进阶，出题只用已学药）；阶段二诊断（按阶段一案例序列 1:1 回放，L3/L4 精进者切换鉴别深挖/无提示读案）。**排课表**：与经典基础病机目录对齐（`参考/病机目录映射.md`，6 大门类顺序推进，不随机抽卡）。**案例库**：558 张卡片（丁甘仁 222 + 经方实验录 209 + 刘渡舟 127），自动质量分排序（`09-医案学习数据库/案例卡片库/`）。诊断层强制：脉诊双引用（濒湖脉学原文+白话解）、舌诊必引金镜录+双轨图谱（木刻原图+真实照片，直接贴图）、图中文字免责。

**经典临床学习**（术中之术）：将《伤寒论》《金匮要略》《温病条辨》统一于六经辨证框架下教学。以伤寒论六经条文为骨架，将金匮要略条文和温病条辨内容按六经归属插入对应经中，实现"一经一学、伤寒金匮温病合一"。每条含方剂的条文围绕四步提问法展开（温病归属内容用六步提问法），必须展示"内经理论溯源 → 多学派专家视角解读"。

**黄帝内经课程**（道）：以哲学方式学习，保持原生阴阳五行、藏象经络体系。结合《说文解字》逐字溯源、《周易》《淮南子》追溯哲学源头，新增**《抱朴子》养生哲学互证**。采用五步提问法（定义题 → 应用题 → 哲学思辨题 → 反向提问 → 自由发散题），含 L1-L3 水平评估、原文分类教学、多注家解读。复习采用黄帝-岐伯问答格式。

## 水平评估与分层教学

> 经典临床与诊疗基础内置 L1-L4 四级水平评估系统，根据学习者水平动态调整教学策略。黄帝内经课程使用 L1-L3 三级评估系统。

| 层级 | 名称 | 判断依据 | 教学策略 |
|:---|:---|:---|:---|
| L1 | **入门** | 不能独立辨证/读案，方药陌生 | 选项引导为主，详细术语解释 |
| L2 | **进阶** | 能辨证/读案但不够精准 | 开放提问为主，关键术语解释 |
| L3 | **实战** | 能独立读案、开出有效方药 | 讨论式教学 + 鉴别深挖（诊疗基础） |
| L4 | **精通** | 能灵活化裁，有独到见解 | 平等讨论 + 无提示读案（诊疗基础）/反向提问 |

### 诊疗基础四模式（可插拔）

| 模式 | 适用人群 | 说明 |
|:---|:---|:---|
| A 药理层 | 想快速上手认病用药 | 只学阶段一，不碰四诊 |
| B 诊断层 | 已有药功底、专攻四诊 | 只学阶段二，无回放依赖 |
| C 完整回放（推荐） | 初学者标准路径 | 阶段一 → 阶段二 1:1 回放 |
| D 混合 | 喜欢一案学到底 | 每案例药理+诊断一次走完 |

## 教学方法论

> 基于意义系统理论，指导教学流程设计。核心主张：教学不从知识点开始，从意义开始——先让学生感受到"为什么学"，再告诉"学什么"，最后才讲"怎么学"。

| 原则 | 核心要点 |
|:---|:---|
| **意义先行** | 每节课先建立"意义锚点"（为什么学这个），再进入核心内容，最后展开细节。不直接摆出学科结构作为教学起点 |
| **意义停顿** | 教学提问抛出后必须停顿等待学习者开口——意义空缺由学习者自己激活，AI 讲解永远在填充已暴露的缺口，不自问自答 |
| **行为主义基础设施** | 基础性内容（药名、方名、条文原文）通过间隔重复系统（1-3-7-14-30-60 课次）建立"基础设施"，意义建构在此之上进行"精装修" |
| **反格式塔（药池阶梯）** | 药理不在总纲列清单，在案例里认识、积累成药池、阶梯反转（积累→半自主→自主→进阶），出题只用已学药 |
| **新词管理** | 每节课引入新术语控制在 3-5 个以内，遵循"先功能后命名"原则 |
| **意义空缺营造** | 引入新知识前先创设"认知断裂"，让学生感受到"这里缺了点什么"，然后才命名新知识 |
| **双向螺旋学习** | 自上而下（先搭框架再填细节）与自下而上（先积累案例再形成结构）交替进行，螺旋上升 |
| **复习即调用** | 复习永不"背定义"——所有复习题应用型（给药说病机、给图谱说主病、走逆向五步），练调用不练记忆 |

## 多学派分析系统

> 经典临床课程整合 21 位中医名家的学术视角。当用户在课程中给出方药时，系统自动触发多学派分析。黄帝内经课程不使用此系统。诊疗基础复用此机制处理药对分歧。

### 四层触发机制

系统采用四层独立机制识别用户处方中的学派特征（详见 `common/学派触发映射表.json`）：

| 层级 | 识别依据 | 特点 |
|------|---------|------|
| 第一层：药对映射 | 处方中出现的药对组合（如桂枝-白芍、柴胡-黄芩） | 机械查表，不依赖 AI 推理 |
| 第二层：病机推理路径 | 症状群组合特征（如胸闷+脉促+微恶寒） | 不依赖药物，即使药对未命中也能触发 |
| 第三层：组方法度 | 处方整体结构逻辑（如五味补泻规则） | 看整体逻辑而非局部药对，区分度最高 |
| 第四层：用户开方逻辑 | 用户解释处方时的推理路径和术语 | 双模式：显性触发（关键词匹配）+ 隐性触发（推理链结构匹配） |

四层互相独立，任一层命中即触发对应学派；多层同时命中提升该学派分析优先级。所有学派平等触发，不预设优先级。触发后按区分度权重排序，默认输出前3-5个学派。

## 间隔重复系统

系统内置间隔重复机制，自动安排已学知识点的复习：

| 复习次数 | 距上次复习间隔（课次） |
|----------|:---:|
| 第1次 | 1 |
| 第2次 | 3 |
| 第3次 | 7 |
| 第4次 | 14 |
| 第5次 | 30 |
| 第6次及以后 | 60 |

每个知识点在进度文件中记录首次学习课次、已复习次数、下次应复习课次和掌握状态。若复习后发现仍未掌握，重置间隔从第1次重新开始。

## 使用方式

### 1. 导入 TRAE

将本项目克隆或下载到本地，在 TRAE 中打开该目录。TRAE 会自动识别 `.trae/skills/` 下的技能。

### 2. 配置本地路径

各 Skill 文件中的路径为示例路径（如 `e:\叶天士\叶天士\`）。使用前请替换为你本地的实际路径。详见各 Skill 目录下的 `SKILL.md` 和 `common/shared_config.md` 中的路径配置说明。

### 3. 激活技能

在 TRAE 对话中，说出对应的触发词即可激活技能：

- **内经精读（道）**："开始内经学习" / "继续内经学习"
- **经典基础（术中之道）**："开始经典基础学习" / "继续经典基础学习"
- **诊疗基础（案例驱动桥）**："开始诊疗基础学习" / "继续诊疗基础学习"
- **经典临床（术中之术）**："开始经典临床学习" / "继续经典临床学习" / "开始学习" / "继续学习" / "开始测试"
- **文档内化工具**："开始内化" / "处理新文档" / "录入新医家"（也可在新文档加入知识库时自动触发）

> **入口确认**：首次"开始学习"确认进入哪个模块。旧名词（温病学习/伤寒学习/金匮学习/伤寒杂病论学习）自动归并到经典临床学习并说明合并现状。

### 4. 在非 TRAE Agent 中使用（Claude Code / CodeX 等）

TRAE 以外的 AI Agent 没有"关键词触发 Skill"机制，但可以手动加载规则文件获得等效体验。当用户说出触发词时，Agent 应读取对应的 `agent_prompt.md` 并按其规则行事：

| 用户说出 | 应读取的规则文件 | 进入模式 |
|---------|----------------|---------|
| "开始经典临床学习" / "继续经典临床学习" / "开始学习" / "继续学习" | `.trae/skills/中医经典临床学习导师/agent_prompt.md` | 学习流程 |
| "开始测试" | 同上 | 4 模块渐进评估 |
| "开始内经学习" / "继续内经学习" | `.trae/skills/中医黄帝内经学习导师/agent_prompt.md` | 内经精读学习（道，无测试） |
| "开始经典基础学习" / "继续经典基础学习" | `.trae/skills/中医经典基础学习导师/agent_prompt.md` | 经典基础学习（术中之道，无测试） |
| "开始诊疗基础学习" / "继续诊疗基础学习" | `.trae/skills/中医诊疗基础学习导师/agent_prompt.md` | 诊疗基础学习（案例驱动桥，无测试） |
| "开始内化" / "处理新文档" / "录入新医家" | `.trae/skills/文档内化工具/agent_prompt.md` | 文档内化（自动/手动触发） |

> **给 Agent 的指令**：若你是不支持 Skill 自动触发的工具（如 Claude Code、CodeX），请在首次对话时读取 `CLAUDE.md` 中"Skill 触发规则"章节，据此响应用户的学习/测试请求。

### 舌象图谱使用规范

舌象图谱（`诊法类/舌象图谱/`）教学使用规则：
- **木刻原图**（金镜录明代刊本，Wellcome CC BY 4.0）作历史语境；**真实照片**（Wikimedia）作直观感受；双轨对照（浏览页 `舌象图谱浏览.html`）
- **图中文字免责**：木刻图上的古人文字注解仅作历史参考，**不作为教学诊断依据**——诊断以金镜录正文 + 介按 + 经典基础病机体系为准
- **直接贴图规则**：教学时必须直接内嵌展示图谱图片，禁止用文字口头描述替代

### 名贵药材不可得处理

以下药材现代已不可得或极难获得，评判处方时不得以"缺少名贵药材"扣分：犀角（替代水牛角）、羚羊角（替代山羊角/水牛角）、天然牛黄（多为人工牛黄替代）、紫雪丹、龙骨。替代方案讨论应基于功效维度而非逐药对应。
