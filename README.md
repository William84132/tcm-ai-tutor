# 中医经典教学系统（TCM AI Tutor）

> 一套"开箱即用"的中医经典学习系统：**四模块递进**（黄帝内经精读（道）→ 经典基础（术中之道）→ 诊疗基础（案例驱动桥）→ 经典临床（术中之术，伤寒+金匮+温病三书合一）），以《黄帝内经》为理论根基，六经八纲为教学框架（脚手架，非唯一真理），配合 20 余位医家多学派视角 + 真实医案 + 意义系统教学法实现深度学习。
>
> **2026 年已上线"精装修（学习者主动性层）"**：在意义系统"教的确定性"之上，叠加问题锚定 / 候选误差 / 碰撞记录 / 纵向谱系 / 鼓励性总结等机制，让"学的主动性"与"教的确定性"互补（详见下方"精装修"章节）。
>
> 仓库内容 = **技能体系（skills/）+ 经典知识库（叶天士/00-原著全文/）+ 规则文档**，无应用代码，任何人可接入自己的 AI 工具使用。

## 快速开始（30 秒，零门槛）

1. 下载本仓库。
2. 打开你的 AI 工具（TRAE / ZCode / Claude Code 等），把对话目录指向本仓库（或将本仓库的 `CLAUDE.md` 交给 AI）。
3. **直接提问即可**——比如问"怕冷出汗是怎么回事""桂枝汤证怎么辨"。**首次对话 AI 会自动激活导师模式**（无需任何触发词、无需手动复制 skills），之后按导师模式带教：意义先行、六经八纲辨证、原文引用、引导追问。更换会话也不会重复激活介绍。
4. 想系统学习时再说"**开始经典临床学习**"（或"开始内经学习"等），AI 会从水平评估开始正式排课。

> **激活状态**：AI 首次对话时会在仓库根目录自动创建 `.agent-state.md`（已激活标记，已加入 .gitignore 不会上传）；删除它即可重新触发一次介绍。

### 🆕 精装修（学习者主动性层，2026 年转正上线）

四课程在意义系统机制（矛盾点漏斗/外化验证锁死/间隔重复等）之上叠加"学的主动性"机制，细则见各模块 SKILL.md 头部转正声明：

- **问题锚定**：收集你自己/家人/身边人的真实困扰，作为案例与条文的入口——课程刚性不变（门类顺序/案例来源/课程环节/覆盖量四不变，问题只换入口包装与候选排序）
- **候选误差**：验证前先圈定"你最没底的一环"——先验你慌的、再查你自信的（防盲区）
- **碰撞记录**：多学派/多注家分析后留下"哪个动摇、哪个坚持、为什么"的立场档案（L3/L4）
- **纵向谱系**：每味核心药一句话谱系——本经→纲目→衷中参西录→本案角色（诊疗基础）
- **鼓励性总结**：综合复习时输出"这段时间你得到了什么"——潜意识数据驱动，具体到你在意的内容，不空洞
- **思想凝固**：内经季度回看课——与三个月前的自己对话，产出季度修正清单

- **新建技能**：复制 `skills/_新建技能模板/` 或运行 `python skills/common/新建技能.py <技能名>`（见模板内"建技能说明.md"）。
- **多学派机制**：`skills/common/核心机制.md` 第十章定义五步分析流程；`学派触发映射表.json` 为四层触发映射。
- **意义先行**：每课从"意义锚点"开始（第九章），不从知识点直接切入。

## 个人数据备份与迁移工具（`工具/个人数据备份与迁移/`）

> **更新系统（重新克隆 / 重新下载 zip）会丢个人记录吗？** —— 不会。本仓库发布版**零个人内容**（课程笔记、进度、账号数据均不在仓库内，且已被 .gitignore 排除）；`git clone` 到新文件夹从不触碰其他文件夹；唯一需要注意的场景是"先删旧文件夹再解压新版"——**切勿这样做**。

安全更新三步（zip 用户）：
1. 新版 zip **解压到新文件夹**（不要覆盖、不要删除旧文件夹）；
2. 把旧文件夹拖到新文件夹 `工具/个人数据备份与迁移/迁移合并.bat` 上；
3. 脚本自动合并笔记 / 进度 / 账号数据，**同名冲突双方都保留**（旧文件加 `.旧版备份_时间戳`），公共文件以新版为准。确认无误后再删旧文件夹。

两个脚本（Windows 10+，零依赖）：
| 脚本 | 用途 |
|:---|:---|
| `个人数据备份.bat` | 一键把笔记目录、学习进度追踪.md、users.db、.env、config.json 备份到带时间戳的文件夹 |
| `迁移合并.bat` | 把旧文件夹的个人数据合并进当前文件夹（拖入旧文件夹即可） |

详见 `工具/个人数据备份与迁移/使用说明.md`（含 git 用户、换电脑、手动兜底清单）。
