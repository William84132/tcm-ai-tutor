# 文档转TXT — 使用说明

> **本地一键转换 PDF / DOCX / DOC → TXT**。纯本地运行：零联网、零 token 消耗、不经过 AI。

## 用法（3 种方式任选）

1. **拖放**（最常用）：把 PDF/DOCX/DOC 文件**或整个文件夹**拖到 `文档转TXT.bat` 图标上，松开即开始转换。
2. **命令行**：`python 文档转TXT.py <文件或文件夹> [更多...]`
3. **桌面快捷方式**：桌面上的「文档转TXT」快捷方式同样支持拖放。

转换完成后，每个源文件所在目录下会出现 `转换输出/` 文件夹，里面是与源文件同名的 `.txt`。

## 支持格式与策略

| 格式 | 处理方式 | 说明 |
|:---|:---|:---|
| PDF（文本型） | pdfplumber 直接提取 | 秒级完成，不 OCR，质量最好 |
| PDF（扫描版） | 自动识别后 OCR | 平均每页有效字符 < 15 即判定为扫描版；pypdfium2 渲染 300dpi + tesseract（简体+繁体中文） |
| DOCX | python-docx 提取 | 段落 + 表格，纯文本提取 |
| DOC（旧格式） | Word COM 转换 | 需要本机安装 Microsoft Office |

## 工具依赖（本机已配置好，一般无需操作）

- `tesseract`（OCR 引擎）与 `tessdata`（中文语言包）：位于本机下载目录（示例：`E:/360Downloads/`）
- `poppler`（可选，文本 PDF 提取另有 pdfplumber 兜底）
- Python 库：pdfplumber / pypdfium2 / python-docx / pywin32（均已安装）

配置读取 `<仓库根>/叶天士/08-学习工具/工具配置.json`（字段 `tesseract`、`tessdata`、`poppler_bin`）；找不到时自动从 PATH 查找。

## 注意事项

- **速度**：文本型 PDF 秒级；扫描版 OCR 每页约 2~5 秒（300dpi），一本 500 页的书约半小时到一小时——属正常现象（本地免费识别）。建议先拖入单页/小文件试跑。
- **图片封面页**：整页为照片/图片的页面（如封面）识别不出文字，会被自动跳过，不影响正文。
- **加密 PDF**：需先解除密码才能转换。
- **.doc 转换**依赖本机 Word；无 Word 时可先用 Word/WPS 另存为 .docx 再转换。
- 转换输出永不覆盖源文件（输出在独立的 `转换输出/` 目录）。

## 故障排查

| 现象 | 处理 |
|:---|:---|
| 提示找不到 tesseract | 打开 `叶天士/08-学习工具/工具配置.json`，确认 `tesseract` 路径正确（本机示例：`E:/360Downloads/tesseract.exe`） |
| OCR 输出乱码 | 确认 `tessdata` 字段指向含 `chi_sim.traineddata`/`chi_tra.traineddata` 的目录 |
| .doc 转换失败 | 确认已安装 Microsoft Word，且文件未被占用 |
| 转换中途关闭窗口 | 大文件 OCR 耗时长，请勿关闭窗口；分批拖入更稳妥 |
