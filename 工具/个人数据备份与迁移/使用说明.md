# 个人数据备份与迁移工具 — 使用说明

> 解决一个核心问题：**更新系统（重新克隆 / 重新下载 zip）时，个人学习记录怎么保证不丢？**
> 本工具的原则：**任何操作都只复制、不删除、不覆盖个人文件**。公共文件（skills/、00-原著全文/ 等）一律以新版为准。

---

## 一、先回答：克隆 / 下载 zip 会不会覆盖或误删个人内容？

### 1. `git clone`（Git 克隆）—— 天生安全
- 克隆是**新建一个文件夹**写入内容，**永远不会触碰其他任何文件夹**。
- 如果目标文件夹已存在且非空，git 会**直接报错拒绝**，不会覆盖。
- 之后用 `git pull` 更新时，git 只更新"仓库里被追踪的文件"；你的个人文件（笔记、进度、users.db）**不在仓库里**，git 永远不会删它们；万一同名冲突，git 会报错让你处理，而不是静默覆盖。

### 2. 下载 zip 解压 —— 唯一需要注意的场景
- zip 里**没有**你的个人内容（本仓库发布版"零个人内容"），所以解压**只会写入/替换 zip 里有的文件**（skills/、00-原著全文/ 等公共文件），个人文件不在 zip 里就不会被动到。
- **真正的危险操作只有一个：先删除旧文件夹、再解压新版** —— 旧文件夹里的一切（包括你的笔记）会随删除而消失。
- ✅ **正确做法（本工具配套流程）**：把新版 zip 解压到**新文件夹**（不删旧文件夹），然后运行本目录下的 `迁移合并.bat` 把旧文件夹里的个人数据合并过来。旧文件夹留着，等确认无误再删。

### 3. "记录失效"的另一种情况
换到新文件夹后，应用（tcm-tutor-agent）的账号库 `users.db` 不会自动跟着走 —— 这不是被删，而是新文件夹里还没有它。用本工具的备份/迁移即可把账号、进度、笔记、API Key 全部带过去。

## 二、两个脚本

| 脚本 | 用途 | 用法 |
|:---|:---|:---|
| `个人数据备份.bat` | 把个人数据复制到带时间戳的备份文件夹（可指定位置） | 双击运行；或 `个人数据备份.bat "D:/我的备份"` |
| `迁移合并.bat` | 把**旧文件夹**里的个人数据合并进**当前文件夹** | 把旧文件夹**拖到**本文件图标上；或 `迁移合并.bat "D:/旧文件夹路径"` |

> 环境要求：Windows 10+，无需安装任何软件（内部使用系统自带的 PowerShell）。
> 找不到 `.ps1` 文件时请把整个 `工具/个人数据备份与迁移/` 文件夹一起复制，四个文件缺一不可。

### 个人数据边界（脚本会自动识别，存在才备份）

| 类型 | 路径（相对仓库根） |
|:---|:---|
| 课程笔记 | `叶天士/01-经典临床（正课）/`、`02-经典临床（复习）/`、`03-黄帝内经（正课）/`、`04-黄帝内经（复习）/`、`05-经典基础/`、`06-诊疗基础/`、`07-温病历史课（旧）/` |
| 进度文件 | `叶天士/学习进度追踪.md`、`叶天士/快速入门.md` |
| 应用数据 | `tcm-tutor-agent/.env`（API Key）、`tcm-tutor-agent/data/users.db`（账号与学习进度）、`tcm-tutor-agent/data/config.json` |

## 三、安全更新流程

### 场景 A：只用 zip 下载的用户（最常见）
1. 更新前，先在旧文件夹里双击 `个人数据备份.bat`（可选，但强烈建议）。
2. 下载新版 zip，**解压到新文件夹**（例如 `中医系统_v2`），**不要**覆盖、不要删除旧文件夹。
3. 进入新文件夹的 `工具/个人数据备份与迁移/`，把**旧文件夹**拖到 `迁移合并.bat` 图标上，回车确认。
4. 脚本会把笔记、进度、账号数据合并进新文件夹；若两边有同名个人文件，双方都会保留（旧文件会加 `.旧版备份_时间戳` 后缀）。
5. 用新文件夹开始使用；确认一切正常后，再删除旧文件夹。

### 场景 B：用 git 更新的用户
1. `git pull` 之前，先运行 `个人数据备份.bat`。
2. `git pull` 只会更新公共文件；若提示冲突，选择保留自己的版本或手动合并。
3. 更新完成后核对 `学习进度追踪.md` 等个人文件仍在原位。

### 场景 C：换新电脑
1. 旧电脑：运行 `个人数据备份.bat`，把备份文件夹（或整个项目文件夹）拷到新电脑。
2. 新电脑：下载新版 zip 解压 → 把旧项目文件夹拖到 `迁移合并.bat` 上 → 完成。

## 五、常见问题

**Q：备份出来的 users.db 怎么用？**
A：备份文件夹里有完整目录结构（`tcm-tutor-agent/data/users.db`）。迁移时脚本会自动放回新位置；手动操作时把该文件复制到新文件夹的 `tcm-tutor-agent/data/` 下即可（应用重启后生效）。

**Q：为什么备份文件夹不要上传到 GitHub？**
A：备份含 `.env`（API Key）与个人笔记，属于隐私数据。脚本默认把备份放在本目录下的 `备份_时间戳/` 文件夹，该文件夹已被 .gitignore 排除，不会误传。

**Q：新文件夹里我已经学了几课，合并会丢吗？**
A：不会。`迁移合并.bat` 遇到同名文件时保留双方：新文件夹里的不动，旧文件夹的另存为 `原名.旧版备份_时间戳`。

**Q：公共文件（skills/、00-原著全文/）会怎样？**
A：一律以新版为准，脚本不处理它们 —— 这正是"更新"的意义。
