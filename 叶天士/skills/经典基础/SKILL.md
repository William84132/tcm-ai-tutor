# 中医经典基础课程（内经生理 + 诸病源候论病理）

> **本 Skill 是"经典基础"教学系统：以《黄帝内经》生理为体（正常状态）、以《诸病源候论》病理为用（失常状态），教学目的是理解"人体正常怎么运作、失常为什么这样"，为【经典临床】（辨证开方）打地基。**
>
> **【教学框架声明·请先读】**
> 本系统位于三层教学逻辑的中间层（术中之道）：
> - 第一层【道】：黄帝内经精读（黄帝内经 Skill）——世界观，怎么看人体与生命
> - 第二层【术中之道】：**经典基础（本 Skill）**——把道落成医学理论：正常怎么运作（生理）+ 失常为什么这样（病理）
> - 第三层【术中之术】：经典临床（经典临床 Skill）——怎么辨证、怎么开方
>
> 白话注解：内经精读是世界观，经典基础是桥梁，经典临床是方法论。推荐按 道→术中之道→术中之术 顺序学习，但用户可随时调整起点，本系统不强制。

## 核心原则（最底层逻辑）

> **以下原则为技能调用的底层逻辑，所有学习流程、复习课均在此前提下进行。**

### 1. 三层分工原则（防重复的硬规则）

> **内经精读把篇章当"道"讲（哲学思辨，原文驱动）；经典基础把篇章当"零件"拆（生理机制，主题驱动）；经典临床把篇章当"论据"引（辨证需要，方证驱动）。同一批原文，三种用法，各取所需，不重复。**

| 维度 | 内经精读（道） | 经典基础（术中之道） | 经典临床（术中之术） |
|:---|:---|:---|:---|
| 组织方式 | 原文驱动：逐篇精读 | 主题驱动：跨篇重组 | 方证驱动：按六经引用 |
| 教学目标 | "为什么中医这样看世界？" | "人体正常是怎么运作的？" | "这个证为什么这样？" |
| 教学深度 | 哲学内涵、字词溯源、哲学思辨 | 生理机制；开篇一句话哲学定位即转入生理 | 条文作辨证论据引用 |
| 教学出口 | 理解"为什么用阴阳看问题" | 理解"正常怎么运作"+落地钩子指向病机 | 指导当下辨证开方 |

- **哲学占比规则**：经典基础内经部分哲学只做引子不做主体——每个生理主题开篇用一句话哲学定位（如"脾胃为后天之本"），随即转入生理机制与落地钩子；哲学思辨深度展开留给内经精读。
- **经典临床对内经一律"引用不论证"**（那是经典临床 Skill 的规则，本系统不涉及）。

### 2. 内容组织原则（方案A：按生理/病理性质切分）

- **不按"书"切分，按"内容性质"切分**：把《内经》与《诸病源候论》两本书中所有讲生理的内容归拢为**生理堆**，所有讲病理的内容归拢为**病理堆**。先学生理堆（正常状态），再学病理堆（失常状态）。
- **生理提前量机制**：生理在生理堆讲；病理堆遇到共用生理逻辑时直接回指"这个内经某某条学过"——病源论本就建立在内经生理框架上，这是还原原著关系。

### 3. 病理教学范式：逆向五步

```
第一步 呈现症候（具体症状群）
第二步 归病机（太过 or 不及）
第三步 溯病因（双路径：邪正相争 or 功能失和）
第四步 归脏归经（动态：主归+兼涉，不是查表）
第五步 回指生理（复习正常功能，闭环）
```

- **两条病机路径**（病理解释的双路径，非一条链）：
  - 路径一（外感类）：正气虚 → 邪气乘虚而入 → 邪伤脏腑经络 → 发病
  - 路径二（内伤类）：劳逸/情志/饮食自损 → 功能衰减/失和 → 太过或不及 → 发病

### 4. 病理堆内部顺序：双向螺旋交替

范式源门类与脏腑病机门类**成对循环**（自上而下搭架子 + 自下而上填肉交替）：

```
自上而下（搭架子）            自下而上（填肉）
风病（外因范式）     ←→   一个脏腑病机门类（如气病）
虚劳（内伤范式）     ←→   一个脏腑病机门类（如脾胃病）
伤寒/时气/温病       ←→   一个脏腑病机门类（如咳嗽）
…循环交替
```

### 5. 提问法：双套五步（生理层/病理层，2026-08-08）

> 本模块教学分层=生理层/病理层，提问法也分两套，各自对应本层教学任务的自然外化。每步提问后等待学习者回答（意义停顿，AI 不自问自答）。

**生理层五步提问法（"正常怎么运作"）**：

| 步 | 题型 | 例子 |
|:---|:---|:---|
| 第一步 | 机制复述题 | "脾胃作为后天之本，正常怎么运作？升降出入各指什么？" |
| 第二步 | 关联定位题 | "脾胃和哪个脏/腑互为表里？和肾、肺什么关系？" |
| 第三步 | 失调预演题 | "如果脾胃升降失常，可能出现哪些症候？"（指向病理堆落地钩子） |
| 第四步 | 反向纠错题 | "'脾胃就是消化器官'——错在哪？内经语境里它的功能范围是什么？" |
| 第五步 | 自由发散题 | 学习者自由提问，AI 结合内经原文回答 |

**病理层五步提问法（= 逆向五步教学化）**：

| 步 | 题 | 对应逆向五步 |
|:---|:---|:---|
| 第一步 | 症候辨析题："这个症状群最可能属于哪类病？" | 呈现症候 |
| 第二步 | 病机归因题："这是太过还是不及？走哪条路径（外感/内伤）？" | 归病机 |
| 第三步 | 病因追溯题："正气虚邪乘还是劳逸情志自损？证据是什么？" | 溯病因 |
| 第四步 | 归脏归经题："主归哪个脏？兼涉哪个经？为什么不是另一个脏？" | 归脏归经 |
| 第五步 | 生理回指题："这个脏正常怎么运作？失常坏在哪一环？" | 回指生理（闭环） |

**核心逻辑**：学习者走完五步提问 = 完成一次逆向五步的主动复述——提问法就是教学范式的"反向输出"，与诊疗基础同构。

## 课程内容与课时表

### 生理堆（第一阶段：内经生理主题）

| 主题 | 覆盖篇章（素材） | 落地钩子 |
|:---|:---|:---|
| 阴阳生理 | 阴阳应象大论、生气通天论（生理切片） | 阴阳失衡→病源冷热病 |
| 藏象总论 | 灵兰秘典论、六节藏象论 | 脏病候总纲 |
| 五脏生理 | 五脏生成篇、五脏别论 | 五味伤脏→病源 |
| 脾胃生理 | 太阴阳明论 | 脾胃病诸候 |
| 经络气血生理 | 灵枢·经脉、灵枢·决气、灵枢·营卫生会 | 气病、血病诸候 |
| 病因病机总纲 | 素问·百病始生、至真要大论（病机十九条） | **对接病理堆的总纲** |
| 诊法生理基准 | 脉要精微论、平人气象论 | 病候脉证解读 |
| 治未病养生（上） | 四气调神大论 + 抱朴子实操内容 | 养生世界观 |
| 治未病养生（下） | 抱朴子实操内容（摄生/五味/功法/情志） | 情志/五味/功法 |

### 病理堆（第二阶段：病源论）

按《病源核心层清单》（参考/病源核心层清单.md）组织，范式源层与脏腑病机层螺旋交替：

| 教学单元 | 内容 | 教学范式 |
|:---|:---|:---|
| 风病诸候（范式源·外因） | 风病诸候上/下（29+30条，按病机亚类分课） | 逆向五步 |
| 脏腑病机验证（如气病） | 气病诸候（25条） | 逆向五步 |
| 虚劳病诸候（范式源·内伤） | 虚劳病诸候上/下（72条，含抱朴子十四伤对照） | 逆向五步 |
| 脏腑病机验证（如脾胃病） | 脾胃病、呕哕、宿食（15条） | 逆向五步 |
| 外感大范式群 | 伤寒/时气/热病/温病/疫疠 | 逆向五步 |
| 脏腑病机验证 | 咳嗽/水肿/血病/消渴/霍乱/痢等 | 逆向五步 |

> **门类分课规则**：门类内部条候按"病机亚类"分组，每个亚类一课，一课6-10条。复习单位=门类。
> **课时总量**：生理堆约10课 + 病理堆约40-50课 + 复习课约25% ≈ 60-70课。

### 复习机制（三线复习，2026-08-08）

**总原则**：复习永不"背定义"——所有复习题都是应用型（复述机制、走逆向五步、对照论证），复习是练"调用"不是练"记忆"。

- **3学1复节奏**（约25%复习课）：每4课一次复习课（复习前3课内容）
- **间隔重复内嵌**：每课结束前检查到期知识点（1-3-7-14-30-60课次间隔，与 shared_config 一致）
- **复习单位=门类**：门类学完整体复习；间隔复习按门类调度

**三线复习**（每次综合复习三线各出题）：

| 线 | 复习形式 | 例子 |
|:---|:---|:---|
| 生理线 | 机制复述 + 失调预演 | "复习脾的生理——它正常管什么？升降乱了会出现什么？" |
| 病理线 | 逆向五步意义复述 | 给一个门类（如风病），让学习者走完"症候→病机→病因→归脏→回指"完整链条 |
| 跨线 | 生理-病理对照 | "脾的生理（升清）和它的病理（下陷）怎么对应？" |

**条候原文快速检查**作为行为主义基础辅助保留（每门 2-3 条核心条候，快速核对原文记忆）。
