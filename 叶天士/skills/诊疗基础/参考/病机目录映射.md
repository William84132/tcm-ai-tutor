## 门类进入流程

```
第 N 门类（如：风病诸候）
  1. 回指经典基础：本门类病机总纲（逆向五步已学的"诸风掉眩皆属于肝"等）
  2. 取卡：按标签"肝风/眩晕"从卡片库取 3-5 张候选（质量分优先）
  3. 逐案阶段一闭环（药理进阶）：意义停顿 → 病机回指 → 药对讲解 → 闭环
  4. 门类复盘：本门类学到的病机+药对小结
  5. 进入下一门类
（阶段二进行时，回到本门类案例做诊断进阶）
```

## 补充说明

- 卡片标签粒度偏粗（每卡多标签），取卡时 AI 精筛为准
- 无匹配门类的卡（如个别特殊病案）归入最近门类，或作检索层按需取用
- 门类内卡片学完标记 `learned: true`，复习调度按门类为单位
