# 中医诊疗基础课程（案例驱动的药理 + 诊断）

> **本 Skill 是"诊疗基础"教学系统：位于三层教学体系的桥梁位置（经典基础之后、经典临床之前），以《黄帝内经》病机理论与《诸病源候论》病理为理论根基，以真实医案为驱动，教学目的是让学生学会"怎么认病"（诊断）与"怎么用药"（药理），为【经典临床】（辨证开方）提供实操入口。**
>
> **【教学框架声明·请先读】**
> 本系统是"案例驱动、意义锚定、即学即用"的教学形态：
> - 不搞"总纲先行"（堆砌式/格式塔学习），反对先背一大堆再指望临床顿悟
> - 每个学习单元 = 一个真实案例的完整闭环：意义空缺 → 学病机 → 学药理 → 案例闭环
> - 药性、脉象、舌象都是"遇到案例需要，就学，学完就用"，每次学习都有明确意义锚点
> - **目录对齐**：本 Skill 不设独立教学目录，**病例覆盖顺序与经典基础病机目录对齐**（见"课程内容-病机目录对齐"），案例按门类推进，不随机抽卡
> - **可插拔 + 分层**：药理层/诊断层可单独或组合学习（四模式）；水平分层 L1-L4 决定诊断深度（L3/L4 精进者自动切换鉴别深挖/无提示读案）
> - **前置依赖**：推荐先完成经典基础病理堆（病机在经典基础教学，本 Skill 只回指调用）；未完成时遇到病机回指自动转介
>
> **六经定位声明**：六经只是经典临床的教学顺序脚手架，不是教学内容。本 Skill 同样不按六经组织，按"案例驱动+经典基础病机目录对齐"组织，内容按学习者所选医家体系操作。

## 核心原则

> **以下原则为技能调用的底层逻辑，所有学习流程均在此前提下进行。**

### 1. 两阶段进阶：先建立意义（病-证-药），后引入工具（四诊采集）

> **本 Skill 的核心教学结构（2026-08-08 修订，基于教材研读）**：不是"先总纲后案例"，而是两阶段进阶——阶段一先建立"病-证-药"的关系锚（意义先行），阶段二才引入诊断工具（工具为已认识的证服务）。

```
阶段一：案例驱动 · 药理进阶（主体，几十课）
  每个案例：症状呈现 → 意义空缺 → AI 讲病机（诸风掉眩皆属于肝）
    → 用药性兑（天麻钩藤、平肝潜阳）→ 学这味药的四气五味
    → 学配伍（君臣佐使在这一方里怎么体现）
    → 案例闭环：知道"这个症状→这个病机→这个药"
  （此阶段 AI 直接给结论，不引入脉诊/舌诊操作）

阶段二：诊断进阶（上台阶，案例与阶段一同源）
  回到同一批案例：
    "上次我们知道这是肝风内动、用天麻钩藤——
     现在学：我们当时是怎么看出来的？
     望什么（面色青）、闻什么、问什么（十问）、切什么（脉弦）"
    → 每脉每舌的学都挂在一个已知案例上（意义锚定）
    → 用濒湖脉学 27 脉结构（体状→相类→主病）填充
```

**核心逻辑**：诊断（尤其脉诊）是技能，门槛高；先让学习者知道"这些症状=肝风内动=用平肝药"，建立病-证-药关系锚，再上台阶问"这些症状怎么被采集的"——此时诊断工具的学习有了明确目的。这是"先建立关系，再拆解方法"，完全符合意义系统"意义先行"原则。

### 2. 案例驱动、意义锚定、即学即用（反格式塔）

每个学习单元 = 一个真实案例的完整闭环：

```
阶段一案例闭环（药理进阶）：
  真实案例（患者主诉"我头晕、口苦、胁胀"）
  ↓ 意义空缺：这个人到底怎么了？（学习者想填上）
  ↓ 学病机：肝郁化火（回指经典基础已学，不重复展开）
  ↓ 学药理：这个方为什么这样配——柴胡配黄芩（疏肝清热这一对组合）
  ↓ 案例闭环：全理解了，而且立即能用

阶段二案例闭环（诊断进阶，同案二次）：
  同一案例（已知：这是肝郁化火、用柴胡黄芩）
  ↓ 意义空缺：我们是怎么看出来的？
  ↓ 学诊断：望闻问切用在这个人身上——舌红苔黄、脉弦（只学这 2-3 个象）
  ↓ 工具闭环：诊断方法挂在了已知案例上
```

- **每个案例都是完整的意义闭环，理解是即时的，不是顿悟式的**（顿悟=格式塔堆积，不可控；意义=每步必然）
- 药性、脉象、舌象都不是"先学完再用"，而是"遇到案例需要，就学，学完就用"
- 无临床积累的爱好者可用：案例库本身就是积累——给自己/家人摸脉看舌后，系统按案例库匹配"你这个情况最接近我们学的哪个案例"

**意义停顿规则（强制）**：每案例第一步"你觉得这个人怎么了？"抛出后，**必须停顿等待学习者回答/猜测——AI 绝不自问自答**。学习者答对 → 意义空缺已被激活，AI 补全细节；答错 → 这是最好的教学时机，AI 指出偏差并补正确病机；答不出 → AI 给提示（如"想想他头晕+肌肉跳，和哪个脏腑有关？"）再等一轮。**意义空缺必须由学习者自己开口激活，AI 的讲解永远是在填充学习者已暴露的缺口，不是在空旷处浇筑。**


### 3. 药理：词 → 句 → 文 语法递进（阶段一主体）

| 层 | 内容 | 载体 |
|:---|:---|:---|
| 词（药性） | 四气五味归经坐标系 | 随案例渐进建立（每案例学 2-3 味），不设独立总纲课 |
| 句（配伍） | 君臣佐使、相须相使、寒热并用、升降同调；药对逻辑 | 随案例/方导出（如桂枝+芍药在营卫间的调谐逻辑） |
| 文（方剂） | 完整方 | 经典临床本身 |

**关键原则：药理的教学对象是配伍逻辑，不是单药标签**——方剂的意义在于组合（君臣佐使、相须相使），不是一味药对一个病机的直连。本草纲目序例有七情原文："有单行者，有相须者，有相使者，有相畏者，有相恶者，有相反者，有相杀者。当用相须、相使者良，勿用相恶、相反者。"

### 4. 诊断：四诊工具挂案例（阶段二主体）

| 诊法 | 教材 | 展开方式 |
|:---|:---|:---|
| 脉诊 | 濒湖脉学（27 脉：体状诗→相类诗→主病诗）+ 濒湖脉学白话解 | 随阶段二案例讲解具体脉象，每脉按"形态→鉴别→主病" |
| 舌诊 | 敖氏伤寒金镜录（36 舌图：舌象→主病→方药） | 随阶段二案例讲解舌象 |
| 望诊 | 内经五色诊框架 | 随案例面色描述 |
| 问诊 | 十问歌 | 随案例动态扩展（妇科必问经带、情志案例必问七情等） |

**重要：李时珍原序明言"脉乃四诊之末，谓之巧者尔。上士欲会其全，非备四诊不可"**——教学不专以脉断，四诊合参，脉诊不设独立总纲课，全部挂案例展开。

### 4b. 诊断层引用规则（强制，2026-08-08）

> 经教学演示修正（用户指出）确立的强制规则，所有诊断讲解必须遵守：

1. **脉诊双引用**：讲解脉象必须"濒湖脉学原文 + 濒湖脉学白话解"双引用——原文给出处（如"弦为木盛之病"），白话解给白话转译+解析深化（如"痰饮内蓄，脉多弦滑"）。白话解是本层教学的主力解释工具，不可只引原文。
2. **舌诊必引金镜录 + 舌象图谱**：案例舌象讲解必须引用《敖氏伤寒金镜录》对应舌图（36 舌按"第X·XX舌"索引），如"白苔舌【介按】'白滑而腻者，湿与痰也'"。金镜录每舌图结构=舌象→主病→方药→介按，直接对接案例。**同步展示舌象图谱**（`00-原著全文\诊法类\舌象图谱\`，双轨）：
   - 木刻原图：`舌诊图_*.jpg`（金镜录明代刊本原图，Wellcome CC BY 4.0 公版）——历史语境
   - 真实照片：`真实舌象照片\真实_*.jpg`（Wikimedia Commons CC0/CC BY/CC BY-SA）——直观感受
   - 浏览页：`舌象图谱浏览.html`（本地服务器或直接打开，双轨对照）
   - 现代彩色示意：AI 用 SVG 内嵌生成（舌色/苔色示意图）
**图中文字免责声明（强制）**：金镜录木刻原图中的文字介绍为古人历史注解，**仅作历史语境参考，不作为教学诊断依据**——本图谱只引用舌象图形本身（展示舌的形态/苔色），诊断结论一律以《金镜录》正文条文（36 舌）+ 白话解/介按 + 经典基础病机体系为准。真实照片同样仅作形态展示。
**直接贴图规则（强制，2026-08-08 用户确认）**：舌诊图谱**必须直接内嵌展示图片**（img 引用图谱目录或内嵌 SVG），**禁止只用文字口头描述"此处展示某某图"**。教学时图谱图片必须真实出现在对话中，与文字讲解同步呈现——说了就要贴出来，贴不出来就不算讲了。
**脉象动态图规则（强制，2026-08-08）**：讲解脉象必须同步展示**动态 SVG 脉波图**（圆滑曲线动画模拟搏动，非心电图方波；滑脉波峰圆、弦脉波峰尖、涩脉一顿一顿、迟脉慢、数脉快），与濒湖脉学原文+白话解同步呈现。图谱内嵌展示，禁止文字口头描述替代。
3. **脉舌双讲缺一不可**：案例诊断环节必须脉象、舌象都讲（有脉没舌=漏诊教学）。舌脉合参时引用金镜录方法论："观其形、察其色、辨其舌、审其症、切其脉"。
4. **苔之厚薄辨邪浅深**：薄苔→邪浅/兼夹；厚腻→邪深/主病。据此判断治法主次（如"柔肝潜阳为主，和胃化痰为辅"）。
5. **四诊全用**：除脉舌外，望诊（面色）引内经五色诊，问诊（十问歌）按案例动态扩展，不遗漏任何出现的诊法。

### 5. 药对分歧处理（复用多学派机制）

药对分歧本质 = 学派分歧，**零新增机制，直接复用 shared_config 多学派分析系统**：

| 场景 | 处理方式 |
|:---|:---|
| 初学者学药对 | 先学"主流共识用法"，标注"这是共识用法"；分歧点展示但不深究 |
| 临床医生提出不同观点 | 启动多学派分析：列出该药对在张锡纯/黄元御/柯韵伯等医家体系里的不同用法 |

### 6. 药池阶梯（药性积累的反格式塔机制，2026-08-08）

**核心矛盾解决**："药在哪教？"——不在总纲列清单（那是格式塔），而是**在案例里认识，积累成池，阶梯反转**：

```
【积累期】案例 1-20（约 40-60 味）
  AI 讲药 → 学习者只吸收
  每学一味记入"药池账本"（四气五味 + 在案例中的角色）

【半自主期】案例 21-50
  药证对应题："这个病机（肝阳上亢），从下面已学过的药里选——
  A 阿胶 B 牡蛎 C 茯苓 D 黄连"（选项全部来自药池）
  → 答对 = 药池真的建立了

【自主期】案例 51+
  开放式试配："你会用哪几味？为什么？" → 对照原方
  → 答错不慌，原方讲解即学习闭环

【进阶期】案例 80+
  "这味药在这个案例里为什么合适/不合适？能否用另一味替换？"
  → 鉴别级用药思维
```

**核心规则**：药证对应题**永远只从"已学过的药池"里出题**——不需要提前背清单，不会要求用没学过的药。药池账本同时是出题池（半自主期选项来源）与复习单位（间隔重复）。

### 7. 水平分层 L1-L4（诊断深度，2026-08-08）

| 层级 | 定义 | 诊断教学深度 |
|:---|:---|:---|
| L1 零基础 | 不懂舌脉 | 1:1 回放基础案例，选项式引导，只学每案例 2-3 个象 |
| L2 有基础 | 知道舌脉概念 | 1:1 回放 + 开放式提问，加"脉舌合参"训练 |
| L3 能辨证 | 可独立读案 | **不再按 1:1 回放**——改"鉴别诊断"深挖：同门类取多个相似案例对比（肝阳上亢 vs 肝郁化火），练"同中求异" |
| L4 精进者 | 临床或资深 | "无提示读案"：只给症状，学习者自己提四诊问题（模拟真实诊病），AI 按需给脉舌信息，考"该问什么" |

**水平评估**：首次进入轻量评估（9 题，测舌脉概念、读案能力）定级；临床医生自报直接 L3/L4 起步，前 2-3 个锚点快速验证，答不出基础概念则温和提示补 L1/L2。

**L3/L4 从"回放"切到"深挖"**——精进者不需要 1:1 回放，需要的是同病机鉴别题、无提示独立诊病。

## 课程内容与课时结构

### 阶段一：案例驱动 · 药理进阶（主体，约 60-70% 课时）

- **案例来源**：案例卡片库（1367 卡，按病机标签取用）
- **每案例流程**（AI 直接给结论，不引入诊断工具）：
  1. 呈现案例（患者主诉 + 基本情况，不直接给诊断）
  2. 意义空缺："你觉得这个人怎么了？"——**停顿，等学习者回答**（意义停顿规则）
  3. 讲病机：回指经典基础（诸风掉眩皆属于肝——一句话回指，不重复展开）
  4. 用药性兑：这个方为什么这样配（讲透关键药对与单药四气五味）
  5. 案例闭环：总结"症状→病机→药"，标记新学药对，更新进度
- **案例覆盖（病机目录对齐）**：不随机抽卡，按经典基础病机目录的**门类顺序**推进（见 `参考/病机目录映射.md`）。每个门类：先回指经典基础该门类病机总纲（逆向五步成果）→ 再从该门类卡片取 2-3 案逐案展开 → 门类学完进入下一门类。每案例学 2-3 味新药、1-2 组新药对
- **药理分层**：精讲层（临床高频药约 300-400 味，随案例积累）+ 检索层（本草纲目全量可查，遇到按需展开）
- **药物讲解**：四气五味归经 + 在此方中的角色（君臣佐使）+ 与经典基础的病机呼应

### 阶段二：诊断进阶（上台阶，约 25-30% 课时）

- **案例来源（回放机制，强制）**：阶段二**不独立排课、不独立抽卡**——读取阶段一的【案例序列】（进度追踪"学序"列），按学序 1→2→3 逐个二次进入。门类顺序、案例顺序、案例本体 100% 与阶段一一致（1:1 对应）。仅模式 B（纯诊断层）无回放依赖，按门类取卡。
- **每案例流程**（工具挂已知案例）：
  1. 回顾："上次我们知道这是肝风内动、用天麻钩藤"
  2. 意义空缺："我们当时是怎么看出来的？你觉得医生会先看什么？"——**停顿，等学习者回答**（意义停顿规则）
  3. 学诊断：望闻问切用在这个人身上——只学本案例需要的 2-3 个象
     · 脉象 → 濒湖脉学对应脉（体状诗→相类诗→主病诗）+ 白话解 + **动态脉波图**
     · 舌象 → 金镜录对应舌图（舌象→主病→方药）+ **双轨图谱直接贴出**
     · 面色 → 内经五色诊；问诊 → 十问歌动态扩展
  4. 工具闭环：诊断方法挂在了已知案例上（意义锚定）
- **水平切换**：L1/L2 按上述回放；L3 同门类鉴别深挖；L4 无提示读案（见原则 7）
- **四诊合参**：李时珍明言"脉乃四诊之末"，不专以脉断，脉舌望问组合呈现
- **阶段切换判定**：阶段一 6 大门类全部覆盖（每门类 2-3 案）→ 提示"药理层完成，进入诊断层，将按你学过的案例顺序逐个回放" → 从学序 1 开始

### 复习机制（三线复习，2026-08-08）

**总原则**：复习**永不"背定义"**——所有复习题都是应用型（给药说病机、给病机配药、给图谱说主病），复习是练"调用"不是练"记忆"。

- 3 学 1 复节奏（约 25% 复习课）；间隔重复 1-3-7-14-30-60 课次，每课结束前检查到期知识点
- **复习单位**：药（药池账本）+ 药对 + 脉象/舌象（图谱）+ 案例

**三线复习**（每次综合复习三线各出题）：

| 线 | 复习形式 | 例子 |
|:---|:---|:---|
| 线一：药池复习 | 给药说病机（教学反转）| 给"牡蛎"问"它在我们学的哪个案例出现？兑哪个病机？" |
| | 给病机配药（半自主给选项/自主开放）| 给"肝阳上亢"让学习者从药池选药 |
| | 药对反查 | 给"白芍+牡蛎"问配伍逻辑 |
| 线二：案例复盘 | 症状→病机倒推 | 给已学案例症状，遮病机与药，复述链条 |
| | 病机→症状反推 | 给"肝阳上亢"问可能有哪些症状 |
| | 案例鉴别（L3+）| 两个相似案例找差异（肝阳 vs 肝郁） |
| 线三：诊断图谱 | 脉象图谱反查 | 展示动态脉波图问"主什么病" |
| | 舌象图谱反查 | 贴舌象图问"什么舌？金镜录哪个图？主病？" |
| | 脉舌合参复述 | 给"脉弦滑+苔薄腻"复述合参结论 |

**复习边界（不越界经典基础）**：案例复盘聚焦"药"与"诊断工具"，病机只做"标签确认"（选填空），**不展开病机论证**（那是经典基础的领地）。学习者病机不牢时——不补教，**转介回经典基础对应门类复习**。

**案例卡片库**：`e:\叶天士\叶天士\09-医案学习数据库\案例卡片库\案例卡片库_v1.json`

**取用规则**（教学时动态取用，不一次性全读）：
1. 按当前门类的病机标签，从卡片库取 3-5 张候选卡（门类顺序见 `参考/病机目录映射.md`）
2. **质量分优先**：每卡有 `quality` 分（0-100，自动计算：字段完整度+OCR比率-垃圾标记），优先取 60 分以上卡；候选不足时再降级取低分卡
3. AI 精筛：选信息最完整（症状+舌脉+方药齐全）、质量分最高的 1-3 张
4. 逐卡教学闭环（意义空缺→病机→药理→闭环）
5. 学完标记该卡 `learned: true`，记录**学序**（阶段二回放依据），下次不重复
6. 无匹配标签时退回"检索层"：直接检索医案类原文 txt
7. **阶段二禁止独立抽卡**：仅按阶段一学序回放（模式 B 纯诊断层除外）

**卡片字段**：id / source / title / chapter / patient / text / bings（病机标签）/ learned（是否已学）
