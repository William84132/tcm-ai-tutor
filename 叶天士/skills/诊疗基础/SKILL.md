# 中医诊疗基础课程（案例驱动的药理 + 诊断）

> **本 Skill 是"诊疗基础"教学系统：位于三层教学体系的桥梁位置（经典基础之后、经典临床之前），以《黄帝内经》病机理论与《诸病源候论》病理为理论根基，以真实医案为驱动，教学目的是让学生学会"怎么认病"（诊断）与"怎么用药"（药理），为【经典临床】（辨证开方）提供实操入口。**
>
> **【教学框架声明·请先读】**
> 本系统是"案例驱动、意义锚定、即学即用"的教学形态：
> - 不搞"总纲先行"（堆砌式/格式塔学习），反对先背一大堆再指望临床顿悟
> - 每个学习单元 = 一个真实案例的完整闭环：意义空缺 → 学病机 → 学药理 → 案例闭环
> - 药性、脉象、舌象都是"遇到案例需要，就学，学完就用"，每次学习都有明确意义锚点
> - **目录对齐**：本 Skill 不设独立教学目录，**病例覆盖顺序与经典基础病机目录对齐**（见"课程内容-病机目录对齐"），案例按门类推进，不随机抽卡
>
> **六经定位声明**：六经只是经典临床的教学顺序脚手架，不是教学内容。本 Skill 同样不按六经组织，按"案例驱动+经典基础病机目录对齐"组织，内容按学习者所选医家体系操作。

## 入口路由

> **本系统为四大学习模块之一**：内经精读（道）· 经典基础（术中之道）· **诊疗基础（案例驱动桥，本 Skill）** · 经典临床（术中之术）。

### 模块命名

| 模块 | 名称 | 内容 | 性质 |
|:---|:---|:---|:---|
| 理论根基 | 内经精读 | 黄帝内经（素问、灵枢等）逐篇哲学精读 | 道（世界观） |
| 生理病理 | 经典基础 | 内经生理 + 诸病源候论病理 | 术中之道（桥梁） |
| **实操入口** | **诊疗基础（本 Skill）** | 案例驱动的药理（词句文）+ 诊断（望闻问切画像） | **案例驱动桥** |
| 临床实践 | 经典临床 | 伤寒论+金匮要略+温病条辨合一 | 术中之术（方法论） |

**推荐路径**：
- 零基础：内经精读 → 经典基础 → 诊疗基础 → 经典临床

**切换自由度**：无条件放行，不拦截；切换时一句温和提示。

## 核心原则

> **以下原则为技能调用的底层逻辑，所有学习流程均在此前提下进行。**

### 1. 两阶段进阶：先建立意义（病-证-药），后引入工具（四诊采集）

> **本 Skill 的核心教学结构（2026-08-08 修订，基于教材研读）**：不是"先总纲后案例"，而是两阶段进阶——阶段一先建立"病-证-药"的关系锚（意义先行），阶段二才引入诊断工具（工具为已认识的证服务）。

```
阶段一：案例驱动 · 药理进阶（主体，几十课）
  每个案例：症状呈现 → 意义空缺 → AI 讲病机（诸风掉眩皆属于肝）
    → 用药性兑（天麻钩藤、平肝潜阳）→ 学这味药的四气五味
    → 学配伍（君臣佐使在这一方里怎么体现）
    → 案例闭环：知道"这个症状→这个病机→这个药"
  （此阶段 AI 直接给结论，不引入脉诊/舌诊操作）

阶段二：诊断进阶（上台阶，案例与阶段一同源）
  回到同一批案例：
    "上次我们知道这是肝风内动、用天麻钩藤——
     现在学：我们当时是怎么看出来的？
     望什么（面色青）、闻什么、问什么（十问）、切什么（脉弦）"
    → 每脉每舌的学都挂在一个已知案例上（意义锚定）
    → 用濒湖脉学 27 脉结构（体状→相类→主病）填充
```

**核心逻辑**：诊断（尤其脉诊）是技能，门槛高；先让学习者知道"这些症状=肝风内动=用平肝药"，建立病-证-药关系锚，再上台阶问"这些症状怎么被采集的"——此时诊断工具的学习有了明确目的。这是"先建立关系，再拆解方法"，完全符合意义系统"意义先行"原则。

### 2. 案例驱动、意义锚定、即学即用（反格式塔）

每个学习单元 = 一个真实案例的完整闭环：

```
阶段一案例闭环（药理进阶）：
  真实案例（患者主诉"我头晕、口苦、胁胀"）
  ↓ 意义空缺：这个人到底怎么了？（学习者想填上）
  ↓ 学病机：肝郁化火（回指经典基础已学，不重复展开）
  ↓ 学药理：这个方为什么这样配——柴胡配黄芩（疏肝清热这一对组合）
  ↓ 案例闭环：全理解了，而且立即能用

阶段二案例闭环（诊断进阶，同案二次）：
  同一案例（已知：这是肝郁化火、用柴胡黄芩）
  ↓ 意义空缺：我们是怎么看出来的？
  ↓ 学诊断：望闻问切用在这个人身上——舌红苔黄、脉弦（只学这 2-3 个象）
  ↓ 工具闭环：诊断方法挂在了已知案例上
```

- **每个案例都是完整的意义闭环，理解是即时的，不是顿悟式的**（顿悟=格式塔堆积，不可控；意义=每步必然）
- 药性、脉象、舌象都不是"先学完再用"，而是"遇到案例需要，就学，学完就用"
- 无临床积累的爱好者可用：案例库本身就是积累——给自己/家人摸脉看舌后，系统按案例库匹配"你这个情况最接近我们学的哪个案例"

**意义停顿规则（强制）**：每案例第一步"你觉得这个人怎么了？"抛出后，**必须停顿等待学习者回答/猜测——AI 绝不自问自答**。学习者答对 → 意义空缺已被激活，AI 补全细节；答错 → 这是最好的教学时机，AI 指出偏差并补正确病机；答不出 → AI 给提示（如"想想他头晕+肌肉跳，和哪个脏腑有关？"）再等一轮。**意义空缺必须由学习者自己开口激活，AI 的讲解永远是在填充学习者已暴露的缺口，不是在空旷处浇筑。**


### 3. 药理：词 → 句 → 文 语法递进（阶段一主体）

| 层 | 内容 | 载体 |
|:---|:---|:---|
| 词（药性） | 四气五味归经坐标系 | 随案例渐进建立（每案例学 2-3 味），不设独立总纲课 |
| 句（配伍） | 君臣佐使、相须相使、寒热并用、升降同调；药对逻辑 | 随案例/方导出（如桂枝+芍药在营卫间的调谐逻辑） |
| 文（方剂） | 完整方 | 经典临床本身 |

**关键原则：药理的教学对象是配伍逻辑，不是单药标签**——方剂的意义在于组合（君臣佐使、相须相使），不是一味药对一个病机的直连。本草纲目序例有七情原文："有单行者，有相须者，有相使者，有相畏者，有相恶者，有相反者，有相杀者。当用相须、相使者良，勿用相恶、相反者。"

### 4. 诊断：四诊工具挂案例（阶段二主体）

| 诊法 | 教材 | 展开方式 |
|:---|:---|:---|
| 脉诊 | 濒湖脉学（27 脉：体状诗→相类诗→主病诗）+ 白话解 | 随阶段二案例讲解具体脉象，每脉按"形态→鉴别→主病" |
| 舌诊 | 敖氏伤寒金镜录（36 舌图：舌象→主病→方药） | 随阶段二案例讲解舌象 |
| 望诊 | 内经五色诊框架 | 随案例面色描述 |
| 问诊 | 十问歌 | 随案例动态扩展（妇科必问经带、情志案例必问七情等） |

**重要：李时珍原序明言"脉乃四诊之末，谓之巧者尔。上士欲会其全，非备四诊不可"**——教学不专以脉断，四诊合参，脉诊不设独立总纲课，全部挂案例展开。

### 5. 药对分歧处理（复用多学派机制）

药对分歧本质 = 学派分歧，**零新增机制，直接复用 shared_config 多学派分析系统**：

| 场景 | 处理方式 |
|:---|:---|
| 初学者学药对 | 先学"主流共识用法"，标注"这是共识用法"；分歧点展示但不深究 |
| 临床医生提出不同观点 | 启动多学派分析：列出该药对在张锡纯/黄元御/柯韵伯等医家体系里的不同用法 |

## 课程内容与课时结构

### 阶段一：案例驱动 · 药理进阶（主体，约 60-70% 课时）

- **案例来源**：案例卡片库（558 卡，按病机标签取用）
- **每案例流程**（AI 直接给结论，不引入诊断工具）：
  1. 呈现案例（患者主诉 + 基本情况，不直接给诊断）
  2. 意义空缺："你觉得这个人怎么了？"——**停顿，等学习者回答**（意义停顿规则）
  3. 讲病机：回指经典基础（诸风掉眩皆属于肝——一句话回指，不重复展开）
  4. 用药性兑：这个方为什么这样配（讲透关键药对与单药四气五味）
  5. 案例闭环：总结"症状→病机→药"，标记新学药对，更新进度
- **案例覆盖（病机目录对齐）**：不随机抽卡，按经典基础病机目录的**门类顺序**推进（见 `参考/病机目录映射.md`）。每个门类：先回指经典基础该门类病机总纲（逆向五步成果）→ 再从该门类卡片取 2-3 案逐案展开 → 门类学完进入下一门类。每案例学 2-3 味新药、1-2 组新药对
- **药理分层**：精讲层（临床高频药约 300-400 味，随案例积累）+ 检索层（本草纲目全量可查，遇到按需展开）
- **药物讲解**：四气五味归经 + 在此方中的角色（君臣佐使）+ 与经典基础的病机呼应

### 阶段二：诊断进阶（上台阶，约 25-30% 课时）

- **案例复用**：阶段一已学的案例，二次进入
- **每案例流程**（工具挂已知案例）：
  1. 回顾："上次我们知道这是肝风内动、用天麻钩藤"
  2. 意义空缺："我们当时是怎么看出来的？你觉得医生会先看什么？"——**停顿，等学习者回答**（意义停顿规则）
  3. 学诊断：望闻问切用在这个人身上——只学本案例需要的 2-3 个象
     · 脉象 → 濒湖脉学对应脉（体状诗→相类诗→主病诗）+ 白话解
     · 舌象 → 金镜录对应舌图（舌象→主病→方药）
     · 面色 → 内经五色诊；问诊 → 十问歌动态扩展
  4. 工具闭环：诊断方法挂在了已知案例上（意义锚定）
- **四诊合参**：李时珍明言"脉乃四诊之末"，不专以脉断，脉舌望问组合呈现

### 复习机制

- 3 学 1 复节奏（约 25% 复习课）
- 间隔重复 1-3-7-14-30-60 课次，每课结束前检查到期知识点
- 复习单位 = 案例（教学单位）+ 药对/脉象/舌象（知识点）

### 案例库与取用规则（2026-08-08 v1）

**案例卡片库**：`e:\叶天士\叶天士\09-医案学习数据库\案例卡片库\案例卡片库_v1.json`
（558 卡：经方实验录 209 + 刘渡舟验案精选 127 + 丁甘仁医案 222，已打病机标签）

**取用规则**（教学时动态取用，不一次性全读）：
1. 按当前学习主题的病机标签，从卡片库取 3-5 张候选卡
2. **质量分优先**：每卡有 `quality` 分（0-100，自动计算：字段完整度+OCR比率-垃圾标记），优先取 60 分以上卡；候选不足时再降级取低分卡
3. AI 精筛：选信息最完整（症状+舌脉+方药齐全）、质量分最高的 1-3 张
4. 逐卡教学闭环（意义空缺→诊断→病机→药理→闭环）
5. 学完标记该卡 `learned: true`，下次不重复
6. 无匹配标签时退回"检索层"：直接检索医案类原文 txt

**卡片字段**：id / source / title / chapter / patient / text / bings（病机标签）/ learned（是否已学）

**已知局限（v1）**：
- 刘渡舟 OCR 文本有错字（如"刘某树"应为"刘某"），教学时可顺带纠正
- 经方实验录 txt 混入部分现代医家案例（郭立中/柴瑞霭等），病机标签可能偏差
- 标签为关键词初版，粒度偏粗（每卡多标签），教学时以 AI 精筛为准
- 丁甘仁为纯文本版，质量最好，优先取用
- **质量分机制**：全自动排序，无需人工校正——低分卡自动沉底不取用
- **吴鞠通/王孟英/胡希恕**：未做卡片（编年体无案例边界/OCR错字率高），作为检索层原文保留（吴鞠通已做字符还原：`医案类\吴鞠通医案_字符还原版.txt`）
