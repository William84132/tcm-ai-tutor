## 第二步：总纲课教学（前 7 课建立坐标系）

总纲课只建坐标系和规则，不穷举：

1. **药性坐标系课**：四气（寒热温凉）× 五味（酸苦甘辛咸）× 归经。用图谱建立全貌，不逐药背。检索神农本草经与本草纲目。
2. **配伍总纲课**：君臣佐使、相须相使、七情（单行相须相使相畏相恶相反相杀）。检索本草纲目序例。
3. **脉诊总览课**：28 脉体状（浮沉迟数滑涩虚实等）。检索濒湖脉学。
4. **舌诊总览课**：舌质（淡红红绛紫）/舌苔（白黄灰黑厚薄腻）。检索敖氏伤寒金镜录。
5. **望诊总览课**：五色诊框架（青赤黄白黑对应五脏）。检索内经诊法篇。
6. **问诊总纲课**：十问歌（寒热汗头身便饮食胸腹聋渴旧病因）。
7. **辨证总纲课**：八纲（表里寒热虚实阴阳）+ 与经典基础病机（太过/不及、双路径）对接。

> **总纲课原则**：只给坐标系和规则，不给穷举。每课结束时明确"后面的案例课会用到这些工具"（意义锚点）。

## 第三步：案例学习课教学（主体）

每个案例按以下流程：

```
第一步 呈现案例：患者主诉 + 基本情况（不直接给诊断）
第二步 意义空缺：问"这个人到底怎么了？"（不急着给答案）
第三步 学诊断：望闻问切用在这个人身上——只学本案例需要的 2-3 个象
  · 脉象 → 检索濒湖脉学对应脉，**必须"原文+白话解"双引用**（原文给出处，白话解给白话转译+解析）
  · 舌象 → 检索金镜录对应舌图（36 舌按"第X·XX舌"索引），**必引金镜录**；苔厚薄辨邪浅深
     **并展示舌象图谱**（`00-原著全文\诊法类\舌象图谱\`）：木刻原图（历史语境）+ 真实照片（直观）+ 必要时 SVG 彩色示意
  · 面色 → 内经五色诊
  · 问诊 → 按病机需求动态扩展
  **脉舌双讲缺一不可**：有脉没舌=漏诊教学；舌脉合参引金镜录方法论"观其形、察其色、辨其舌、审其症、切其脉"
第四步 学病机：回指经典基础（这个病机学过，一句话回指不重复展开）
第五步 学药理：这个方为什么这样配——讲透关键药对（词句文：从方导出药对与药性）
第六步 案例闭环：总结全案，标注学了什么新知识（新象、新药对），更新进度
```

**案例覆盖策略**：按病机目录渐进覆盖（肝风/脾胃/肺系/肾系/气血/痰饮等），每案例学到 2-3 个新象、1-2 组新药对。精讲层药（高频 300-400 味）随案例积累；检索层药（本草纲目全量）遇到按需展开。

## 第四步：药对分歧处理（复用多学派机制）

- 初学者：先学共识用法，标注"这是共识用法"，分歧点展示但不深究
- 临床医生提出不同观点：启动多学派分析（shared_config 10.3），列出该药对在不同医家体系的不同用法
- 观点冲突：综合评价与辩论四步（综合各方→指出依据→认可有理有据→标注整合）
- 原则：学派平等、标注出处、用户言之有理即可认可、系统做考据者不做独断者
