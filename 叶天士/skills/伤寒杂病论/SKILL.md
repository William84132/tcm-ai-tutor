# 中医伤寒杂病论六经辨证临床实践课程

> **本Skill是中医《伤寒杂病论》学习的完整教学系统，将《伤寒论》与《金匮要略》统一于六经辨证框架下进行教学。以《黄帝内经》阴阳五行理论为绝对理论根基，以六经辨证为核心实践工具，将《金匮要略》条文按六经归属插入对应经中，实现"一经一学、伤寒金匮合一"的系统性学习。配合真实医案和四步提问法实现深度学习。**
>
> **核心理念**：内经理论为体，六经辨证为用。在教学阶段建立六经辨证的基础框架，让学习者先掌握系统化的理论体系，再通过临床实践不断深化和突破。临床上"观其脉证，知犯何逆，随证治之"，不拘泥于框架；但教学上必须先有框架，才能谈超越。

## 核心原则（最底层逻辑）

> **以下原则为技能调用的底层逻辑，所有学习流程、案例分析、复习课均在此前提下进行。**

### 0. 黄帝内经为绝对理论根基

- 《伤寒杂病论》脱胎于《黄帝内经》时代，其理论根基深植于内经的阴阳五行、藏象经络体系
- 在分析病机、方剂时，必须结合内经理论进行溯源（如：桂枝汤调和营卫→内经"阴平阳秘"；麻黄汤发汗解表→内经"其在皮者汗而发之"）
- 六经辨证是实践工具（方便教学引入），内经理论是理论根基；二者是"用"与"体"的关系
- 检索内经理论时，从整个 `黄帝内经类` 目录中查找（含素问、灵枢、词典、说文解字、淮南子、周易等），不拘泥于单本书
- 详见 `shared_config.md` 中的"内经理论检索规范"

### 1. 六经辨证是核心实践工具

- 太阳、阳明、少阳、太阴、少阴、厥阴的定位必须明确
- 六经不是单纯的经络概念，而是**病位+病机**的综合辨证体系
- 六经定义（胡希恕八纲体系）：
  - 太阳 = 表阳证（病位在表，性质属阳）
  - 阳明 = 里阳热证（病位在里，性质属阳热）
  - 少阳 = 半表半里阳证（病位在半表半里，性质属阳）
  - 太阴 = 里阴寒证（病位在里，性质属阴寒）
  - 少阴 = 表阴/里虚寒重证（病位在表或里，性质属阴，虚寒程度重于太阴）
  - 厥阴 = 半表半里阴证（病位在半表半里，性质属阴）
- 所有条文的学习必须回归六经框架分析
- 方药选择必须对应六经病位和病机
- 多学派视角解读是辅助，内经理论是根本，六经辨证是实践工具。所有学派平等触发，不预设核心与辅助之分

### 2. 伤寒与金匮合一

- 《伤寒论》与《金匮要略》原为同一部书《伤寒杂病论》，是一个统一系统
- **教学架构**：以《伤寒论》六经条文为框架，构建每经的基础认识；再补充《金匮要略》中归属该经的条文，完善对该经病证的全貌认识
- 金匮要略第1篇（脏腑经络先后病脉证第一）排除教学（胡希恕认为系王叔和整理，内容杂乱）
- 金匮要略学习从第2篇（痉湿暍病脉证并治第二）开始
- 金匮条文按六经归属插入对应伤寒论六经章节，允许少数跨经或特例条文存在
- 同一方剂在伤寒论与金匮要略中可能针对不同病证，但其六经病机是相通的

### 3. 有是证用是方

- 方证对应的本质是**"药证对应"**，不是"方名对应"
- 临床只需药与证对应，命名是交流工具
- 取方意不泥方药，灵感可来自任何方剂
- 尊重原医家思路，但独立辨证同样重要

### 4. 病机对应而非方证对应

- 处方依据是**病机匹配**，而非方名匹配
- 同一病机可用不同方剂表达，同一方剂可治不同病机
- 选方时问的不是"这个病该用什么方"，而是"这个病机需要什么治法"

### 5. 整体评判处方

- **评判顺序**：先看六经定位是否准确 → 再看治法大方向是否正确 → 最后看药物组成是否支撑治法 → 具体药物的加减讨论放在最后
- 方名仅具引导意义，不具有决定意义
- 同一方名在不同药物组成下，寒热攻补方向可能完全不同
- 不能拆出一两味药单独批判，而不考虑该药在全方配伍中的位置和比例
- 一味温药在大队寒凉药中，可能只是反佐或微调，不改变方子整体的寒热属性

### 6. 教学先行，临床突破

- 教学阶段必须建立扎实的六经辨证框架
- 框架学明白后，临床上才能灵活运用、随证治之
- 不要求所有条文全部严丝合缝地归入六经——疾病复杂，少数特例允许存在
- 理论框架追求"解释的完备性"，而非绝对的对应

## 胡希恕学术指导

> **本Skill以胡希恕老先生的学术视角为核心指导。胡希恕建议用六经-八纲-方证体系统一学习伤寒与金匮，这是本Skill的核心方法论依据。**

### 胡希恕的核心观点

1. **伤寒金匮本为一书，六经统摄万病**
   - 《伤寒论》论外感，但六经辨证同样适用于杂病
   - 《金匮要略》论杂病，但其方证仍可归入六经框架
   - 不可脱离六经去孤立理解脏腑病证

2. **六经-八纲-方证体系**
   - 以六经统摄八纲（阴阳、表里、寒热、虚实），最终落脚于方证对应
   - 六经的本质是病位（表/里/半表半里）+病性（阴/阳）的综合

3. **方证对应的本质是药证对应**
   - 不死记方名与病名对应，而要理解药物与证候的对应关系
   - 药证对应是辨证论治的最小单位

### 参考依据

- 《胡希恕金匮要略学习讲座》（金匮条文解读核心参考）
- 《胡希恕医论医案集粹》（方证论述和医案）
- 《伤寒论》原文（六经框架基础）

### 条文学习规则

1. **每经内部先学伤寒后学金匮**：先按伤寒论条文顺序逐条学习，构建该经的基础认识；然后学习金匮要略中归入该经的条文，补充和完善
2. **在伤寒和金匮内部都按原文顺序推进**：不跳跃，不挑拣
3. **讲前面条文时可以旁征博引后面的条文**：学习太阳病篇第1条时，可以引用阳明病篇的条文来对比说明
4. **含方剂的条文需要配合医案进行案例学习**：必须配合真实医案进行四步提问法的完整教学
5. **不含方剂的条文**：侧重理论讲解和定义题训练，仍走四步提问法流程，但第二步应用题可使用条文本身的临床场景
6. **金匮条文的六经归属在教学时须说明依据**：标注是按方剂组成分析还是按胡希恕讲稿中的明确论述归入该经
7. **允许少数"特例"条文存在**：某些条文确实难以归入单一六经，教学时标注为"跨经/传变"，说明其复杂性

### 条文分类说明

| 条文类型 | 说明 | 教学侧重 |
|:---|:---|:---|
| 纲领条 | 定义某经病总纲（如"太阳之为病"） | 定义题为主，概念讲解为重点 |
| 方证条 | 给出具体方剂（如"桂枝汤主之"） | 四步提问法完整流程+医案 |
| 鉴别条 | 鉴别不同方证 | 反向提问为主，训练鉴别能力 |
| 传变条 | 描述病情传变规律 | 病机分析为重点 |
| 禁忌条 | 方剂使用禁忌 | 反向提问，强化禁忌意识 |
| 金匮补充条 | 金匮要略中归入该经的杂病条文 | 与伤寒条文对比学习，注意异同 |

## 学习者水平评估系统

> **本系统用于评估学习者的伤寒杂病论辨证水平，区分L1-L4四个层级，指导教学策略。**

### 层级定义

| 层级 | 名称 | 判断依据 | 教学策略 |
|:---|:---|:---|:---|
| L1 | **入门** | 不能独立辨证，方药陌生 | 四步提问法（选项引导为主），详细术语解释 |
| L2 | **进阶** | 能辨证但方药不够精准 | 四步提问法（开放提问为主），关键术语解释 |
| L3 | **实战** | 能独立开出有效方药 | 讨论式教学+追问，案例驱动 |
| L4 | **精通** | 能灵活化裁，有独到见解 | 平等讨论+反向提问，辨证思维追踪 |

### 评估方式

**方式一：首次启动快速评估（推荐，1分钟）**
1. 问："你学习伤寒论和金匮要略多长时间了？"
2. 问："能否独立开出一剂桂枝汤？知道胸痹病的栝蒌薤白白酒汤证吗？"
3. 问："你了解六经辨证的基本框架吗？知道伤寒论和金匮要略的关系吗？"
- 三个问题答出2个及以上 → 视为L2及以上
- 答出0-1个 → 视为L1

**方式二：系统化水平评估测试（推荐用于首次启动或重新评估，15-20分钟）**
- 使用完整的《水平评估测试》进行递进式测试
- 测试文件位置：`e:\叶天士\叶天士\skills\伤寒杂病论\水平评估测试.md`
- 测试结构：
  - 模块一（基础知识，5题选择题）→ 区分L1
  - 模块二（简单辨证，3题医案选择题）→ 区分L2
  - 模块三（处方能力，1题开放处方）→ 区分L3
  - 模块四（深度分析，1题多视角评价）→ 区分L4
- 测试基于《伤寒论》和《金匮要略》原文及临床案例
- 零中医基础友好

**方式三：案例分析中动态评估**
- 根据用户首次案例分析的表现自动匹配层级

### 层级切换规则

- 用户可随时声明自己的层级："我是入门水平"
- 每完成1个学习单元（L1/L2为12课，L3/L4为7课），自动重新评估一次
- 用户表现明显超出当前层级时，AI主动建议升级

## 四步提问法

> **伤寒杂病论教学的核心方法。每条含方剂的条文围绕四步提问法展开。**
>
> **注意**：伤寒杂病论使用**四步提问法**，不是五步，也不是六步。

### 第一步：定义题（检测对概念/条文定义的理解）

> **目的**：检测学习者对当前条文的概念、定义、病机本质的理解程度。

- **教学动作**：先讲解条文原文，明确六经定位、核心病机、方剂组成和功效
- **提问方式**：
  - **L1用户**：选项式提问
  - **L2用户**：开放式提问
  - **L3/L4用户**：直接进入讨论，可跳过此步或快速确认
- **评分**：答对进入第二步；答错则回到讲解环节补充后再问
- **必须标注出处**：伤寒条文标注编号（如"《伤寒论》第12条"），金匮条文标注篇章名（如"《金匮要略·胸痹心痛短气病脉证治第九》"）

### 第二步：应用题（考察条文的临床应用能力，使用真实医案）

> **目的**：用一个真实医案考察学习者对当前条文方证的临床应用能力。

- **案例来源**：必须使用真实医案，来自RAG知识库中的医案类文件
- **案例格式**：给出患者信息、症状、舌脉、病史（不加辨证提示）
- **L1用户**：给出简化案例+选项引导
- **L2用户**：给出案例后让用户独立辨证并选方
- **L3/L4用户**：给出案例后让用户独立完成辨证、选方、开药
- **反馈**：用户作答后展示多学派视角解读
- **伤寒金匮对照**：当学习金匮条文时，关联伤寒论中对应六经的条文进行对比分析

### 第三步：反向提问（提出看似合理但有误的观点，训练逆向思维）

> **目的**：训练学习者的逆向思维，防止被表面说法迷惑，强化鉴别诊断能力。

- **L1用户**：给出更多提示和引导
- **L2用户**：让用户独立分析，仅追问不提示
- **L3/L4用户**：提出更复杂的混淆观点，要求用户从六经框架层面驳斥

### 第四步：自由发散题（学习者自由提问，AI结合知识库回答）

> **目的**：学习者自由提问自己感兴趣的点，AI结合知识库已有书籍内容回答，拓展知识面。

- **执行规则**：
  1. 鼓励学习者提出任何与本条条文相关的问题
  2. AI**必须**结合知识库中已有的书籍内容回答，标注具体来源
  3. 不得凭空编造
  4. 鼓励学习者提出伤寒论与金匮要略对照的问题
  5. 提供双向链接（Obsidian格式），关联核心概念

### L1与L2差异对照

| 维度 | L1（入门） | L2（进阶） |
|:---|:---|:---|

## 综合复习规则

> **综合复习是每个单元的最后一课，必须严格按照三步顺序执行。**

### 综合复习三步流程

**第一步：处理前一次综合复习中暴露的问题**
- 读取进度文件中"综合复习遗留问题追踪"表
- 优先复习上次的薄弱点

**第二步：复习新内容**
- 复习本次单元内的新学内容
- 同时回顾前两次复习中发现的纰漏点

**第三步：检查间隔重复到期知识点**
- 读取间隔复习追踪表，筛选到期知识点
- 复习完成后更新追踪表

### 综合复习的递进规则

- 每次综合复习必须包含**前一次综合复习中暴露的问题**的再次复习
- 间隔重复间隔：1-3-7-14-30-60课次
- 间隔重复仅在综合复习时检查
