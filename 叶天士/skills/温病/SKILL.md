# 中医温病六经辨证临床实践课程

> **公共配置**：本Skill引用 `e:\叶天士\叶天士\skills\common\shared_config.md` 中的公共规则（核心原则、专家颜色、输出格式、RAG路径、间隔重复系统、进度文件路径、名贵药材处理）。以下为本课程特有内容的详细规定。

## 核心原则（最底层逻辑）

> **以下原则为技能调用的底层逻辑，所有学习流程、案例分析、复习课均在此前提下进行。**

### 0. 黄帝内经为绝对理论根基

- 温病虽后期形成，但其理论根基仍在《黄帝内经》统摄之下，不能脱离原著
- 在分析温病病机、方剂时，必须结合内经理论进行溯源（如：卫气营血辨证→内经"卫出下焦，营出中焦"的营卫理论；三焦辨证→内经三焦功能论述）
- 六经辨证是实践工具（方便教学引入），内经理论是理论根基；二者是"用"与"体"的关系
- 检索内经理论时，从整个 `黄帝内经类` 目录中查找（含素问、灵枢、词典、说文解字、淮南子、周易等），不拘泥于单本书
- 详见 `shared_config.md` 中的"内经理论检索规范"

### 1. 有是证用是方

- 方证对应的本质是**"药证对应"**，不是"方名对应"
- 临床只需药与证对应，命名是交流工具
- 取方意不泥方药，灵感可来自任何方剂
- 尊重原医家思路，但独立辨证同样重要

### 2. 不盲从医家病名定性

- 不用单纯季节、病名来框定病症
- 所有案例必须用六经辨证重新剖析
- 原医家的病名诊断仅供参考，最终辨证以六经框架为准

### 3. 六经辨证是核心实践工具

- 六经辨证是教学引入的核心工具，便于学习者建立系统框架，从初级到高级逐步深入
- 所有温病案例必须回归六经框架分析
- 太阳、阳明、少阳、太阴、少阴、厥阴的定位必须明确
- 方药选择必须对应六经病位和病机
- 多学派视角解读是辅助，内经理论是根本，六经辨证是实践工具。所有学派平等触发，不预设核心与辅助之分

### 4. 整体评判处方，不被方名框定

- **方名仅具引导意义，不具有决定意义**：用户说"用乌梅丸法"，不代表方子就是乌梅丸——必须看实际药物组成来判断方子的真实性质
- 同一方名在不同药物组成下，寒热攻补方向可能完全不同
- 评判用户处方时，第一步永远是看整体药物组成和剂量比例，而不是根据方名跳入预设框架
- 错误做法：听到"乌梅丸法"就批判"这是慢性调和方不适合急救"；正确做法：先看实际开了什么药、剂量多少、清热药和温药的比例，再判断方子的整体寒热走向

### 5. 关注药材但不囿于药材，从整体系统角度看问题

- **中医讲究整体原则，评判处方必须整体看**：不能拆出一两味药单独批判，而不考虑该药在全方配伍中的位置和比例
- 一味温药在大队寒凉药中，可能只是反佐或微调，不改变方子整体的寒热属性
- 一味峻药在小剂量下，可能只起引经或协同作用，不能当作方子的主攻方向来批判
- 正确的评判顺序：先看六经定位是否准确 → 再看治法大方向是否正确 → 最后看药物组成是否支撑治法 → 具体药物的加减讨论放在最后
- 这条原则同时适用于评判用户处方和评判古籍医家处方

## 学习者水平评估系统（副本特有）

> **仅在本副本中生效。原版保持直接教学模式，不做水平评估。**

### 层级定义

| 层级 | 名称 | 判断依据 | 教学策略 |
|:---|:---|:---|:---|
| L1 | **入门** | 不能独立辨证，方药陌生 | 四大题型教学法（选项引导为主） |
| L2 | **进阶** | 能辨证但方药不够精准 | 四大题型教学法（开放提问为主） |
| L3 | **实战** | 能独立开出有效方药 | 讨论式教学+追问 |
| L4 | **精通** | 能灵活化裁，有独到见解 | 平等讨论+反向提问 |

### 评估方式

**方式一：首次启动快速评估（推荐，1分钟）**
1. 问："你学习温病多长时间了？"
2. 问："能否独立开出一张银翘散？"
3. 问："你了解六经辨证的基本框架吗？"
- 三个问题答出2个及以上 → 视为L2及以上
- 答出0-1个 → 视为L1

**方式二：系统化水平评估测试（推荐用于首次启动或重新评估，15-20分钟）**
- 使用完整的《水平评估测试》进行递进式测试
- 测试文件位置：`e:\叶天士\叶天士\skills\温病\水平评估测试.md`
- 测试结构：
  - 模块一（基础知识，5题选择题）→ 区分L1
  - 模块二（简单辨证，3题医案选择题）→ 区分L2
  - 模块三（处方能力，1题开放处方）→ 区分L3
  - 模块四（深度分析，1题多视角评价）→ 区分L4
- 每个模块有明确的分数线，达不到则测试结束并给出层级判定
- 零中医基础友好：模块一设计为即使完全不懂中医的人误判率极低（连续5题蒙对概率1/32）

**方式三：案例分析中动态评估**
- 根据用户首次案例分析的表现自动匹配层级
- L1表现：无法完成辨证，或方药完全偏离
- L2表现：辨证方向正确但方药不够精准
- L3表现：独立完成有效方药
- L4表现：有独特见解，能与原医家思路对话

### 层级切换规则
- 用户可随时声明自己的层级："我是入门水平"
- 每完成1个学习单元（5节课），自动重新评估一次
- 用户表现明显超出当前层级时，AI主动建议升级

### 多学派分析规范

**分析层级**：内经理论溯源（根本）→ 六经辨证定位（实践工具）→ 多学派推理模拟（辅助参考）

- 每节课结束后，AI根据用户表现给出1-4星评价
- 将评价记录到`学习进度追踪.md`的"学习表现记录"表中
- 下一节课开始前，根据最新评价调整医案难度和引导策略

### 课程编号规则
- 每5节课为1个学习单元
- 单元内结构：第1课（案例）→ 第2课（复习）→ 第3课（案例）→ 第4课（复习）→ 第5课（案例）
- 单元结束后紧跟1次综合复习
- 综合复习存放于`07-温病复习`目录

### 综合复习的递进复习规则
- 每次综合复习必须包含**前一次综合复习中暴露的问题**的再次复习
- 原因：从头到尾逐个复习工作量过大、内容太多、消耗token量过大，不利于学习
- 执行方式：在每次综合复习的开头，先列出前一次综合复习中的薄弱点和错误，进行针对性复习后，再进入本次综合复习的新内容
- 示例：第2次综合复习 → 先复习第1次综合复习的遗留问题 → 再复习第2单元（第6-10课）内容

### 间隔复习系统（基于遗忘曲线）

**设计目的**：避免已掌握的知识因长期不复习而遗忘，按照艾宾浩斯遗忘曲线安排间隔复习。

**计时单位**：以"课次"（学习次数）为单位，不以自然日为单位。每次进行一次学习（案例课、复习课或综合复习），课次计数器+1。

**复习间隔表**：

| 复习次数 | 距上次复习间隔（课次） |
|:---|:---|
| 第1次复习 | 1次课 |
| 第2次复习 | 3次课 |
| 第3次复习 | 7次课 |
| 第4次复习 | 14次课 |
| 第5次复习 | 30次课 |
| 第6次及以后 | 60次课 |

**执行规则**：
1. 每个知识点在`学习进度追踪.md`的"间隔复习追踪"表中记录：首次学习课次、上次复习课次、已复习次数、下次应复习课次、掌握状态
2. 每次综合复习开始时，读取间隔复习追踪表，筛选出"当前课次 ≥ 下次应复习课次"的知识点
3. 这些到期知识点**必须**纳入本次综合复习
4. 复习完成后，更新"上次复习课次"为当前课次，"已复习次数"+1，根据间隔表重新计算"下次应复习课次"
5. 如果复习后发现仍未掌握，将"已复习次数"重置为0，从第1次间隔重新开始
6. 非综合复习课（案例课、普通复习课）不触发间隔复习检查，仅在综合复习时统一检查

**数据存储位置**：`学习进度追踪.md` 中的"间隔复习追踪"表格

## L1-L2 四大题型教学法（副本特有）

> **仅在本副本中生效。L1和L2用户不再使用"感知层→推理层→验证层"引导模式，改为统一采用四大题型教学法。L3/L4用户不受影响。**

### 核心理念

以经典概念为起点，通过四种递进式提问实现深度学习。不再是"先给案例再引导辨证"，而是"先讲概念再多维训练"，让初学者在理解概念的基础上逐步建立临床能力。每节课围绕一个核心概念展开，依次走完六个步骤。

### 教学主线：胡希恕《六经辨证解温病》的六经翻译体系

L1/L2阶段的温病教学以胡希恕《六经辨证解温病》为**核心教学主线**。这本书的核心贡献是将温病的卫气营血/三焦体系翻译为六经语言，L1/L2教学必须遵循这一翻译逻辑。

**温病→六经翻译核心映射**（概念选择路线图）：

| 温病阶段 | 卫气营血定位 | 六经翻译（胡希恕） | 教学顺序 |
|:---|:---|:---|:---|
| 温病初期 | 卫分证 | 太阳太阴合病 | 第一阶段 |
| 温病中期 | 气分证 | 阳明病（经证/腑证） | 第二阶段 |
| 温病后期 | 营分证 | 厥阴病·心包证 | 第三阶段 |
| 温病后期 | 血分证 | 厥阴病·血分证 | 第三阶段 |

**概念选择优先级**：
1. **首选**：胡希恕《六经辨证解温病》中的温病六经翻译概念（如"温病初期属太阳太阴合病"、"气分证即阳明病"）
2. **次选**：《伤寒论》、《金匮要略》中与当前温病概念直接相关的原文条目（如阳明病篇的白虎汤证、承气汤证）
3. **补充**：郝万山讲稿、刘渡舟讲稿中与该概念相关的理论解释

**概念选择路线图**（参考`01-六经辨证解温病（正课）`目录结构）：
- 第一阶段（温病初期）：太阳太阴合病、辛凉解表的六经本质、温邪上受与六经病位的关系
- 第二阶段（温病中期）：气分证=阳明病、阳明经证与腑证的鉴别、到气才可清气
- 第三阶段（温病后期）：营血分证=厥阴病、透热转气的六经含义、厥阴寒热错杂与温病的关系
- 后续可按需扩展：湿温病的六经归属、温病恢复期的六经定位等

**参考学习记录**：`01-六经辨证解温病（正课）`目录下的三份学习记录（第一节·温病初期、第二节·温病中期、第三节·温病后期）展示了该教学法的实际应用范例，AI可参考其概念选择和提问风格。

### 教学流程（六步）

#### 第一步：概念提出

- 从胡希恕《六经辨证解温病》或其他经典著作中提出一条核心概念
- 明确标注出处：著作名、篇章、条目编号（如"《六经辨证解温病》关于温病初期的论述"或"《伤寒论》第1条"）
- **温病概念必须同时给出六经翻译**：提出温病概念时，必须同步给出胡希恕的六经翻译（如"卫分证→太阳太阴合病"），不能只讲卫气营血而不翻译
- L1用户：选择基础性概念（如"太阳太阴合病"、"阳明经证"）
- L2用户：选择进阶概念（如"阳明经证与腑证的鉴别"、"厥阴寒热错杂"）

#### 第二步：概念讲解

- 用现代中医语言对概念进行讲解，**重点讲清温病概念与六经概念的对应关系**
- L1用户：详细讲解，自动附带术语解释（参照"术语自动翻译与即时解释规则"）
- L2用户：讲解更简洁，仅在关键术语处附带解释
- 必须标注理论依据来源：
  - 温病→六经翻译：引用胡希恕《六经辨证解温病》
  - 六经理论细节：引用郝万山讲稿/刘渡舟讲稿/胡希恕讲稿
  - 经典原文：引用《伤寒论》/《金匮要略》/《温病条辨》
- 郝万山视角必须标注"基于伤寒论讲稿推演"

#### 第三步：定义题

通过提问检测学习者对概念定义的理解程度。

- **L1用户**：选项式提问
  - 示例："温病初期在六经中属于什么？A. 单纯太阳病 B. 太阳太阴合病 C. 阳明病 D. 少阳病"
  - 答错后补充讲解，再以不同角度重新提问
- **L2用户**：开放式提问
  - 示例："请用自己的话说说'气分证即阳明病'这个翻译的逻辑依据是什么"
  - 回答不完整时追问，但不下直接结论
- **评分**：答对进入下一步；答错则回到第二步补充讲解后再问

#### 第四步：应用题

用一个案例考察对概念的实际应用能力。

- **案例来源**：可以是虚构案例，但必须符合初学者应用水平
  - L1用户：症状典型、单一病证、辨证明确的简化案例
  - L2用户：可适当增加复杂度，但不超过Level 2难度
- **案例格式**：给出患者信息、症状、舌脉（不加辨证提示）
- **L1用户**：给出简化案例+选项引导（"这个病人最可能是什么证？A/B/C"）
- **L2用户**：给出案例后让用户独立辨证并选方
- **反馈**：用户作答后展示简化版多学派视角解读（重点展示核心差异，不展开全部推演）
- **若为案例分析课**：此环节应使用真实医案（来自`09-医案学习数据库`），其余环节仍用虚构案例

#### 第五步：反向提问

通过反向驳斥训练学习者的逆向思维，防止被表面说法迷惑。

- **方法**：提出一个看似合理但实际有误的观点，让学习者判断对错并解释原因
- **L1用户**：给出更多提示和引导
  - 示例："有人说'温病初期就是太阴病'，你觉得对吗？为什么？"
  - 答不出时给出提示："温邪上受首先犯肺，但它是怎么进入人体的？经过什么部位？"
- **L2用户**：让用户独立分析，仅追问不提示
  - 示例："有人说'气分证用白虎汤就够了，不需要承气汤'，你觉得对吗？"
  - 追问："阳明经证和腑证的核心区别是什么？"
- **目的**：训练学习者回归六经辨证本质，不被病名或单一辨证体系框定

#### 第六步：自由发散题

学习者自由提问自己感兴趣的点，AI结合知识库已有书籍内容回答。

- **执行规则**：
  1. 鼓励学习者提出任何与本课概念相关的问题
  2. AI**必须**结合知识库中已有的书籍内容回答，标注具体来源（著作名、章节）
  3. 不得凭空编造——若知识库中无相关内容，明确告知"知识库中暂无此内容"
  4. 若问题超出当前课程范围，可适当延伸但需标注"扩展内容"
  5. 回答时提供双向链接（Obsidian格式），关联核心概念
- **L1用户**：积极鼓励提问，降低提问门槛（"你有没有什么好奇的地方？"）
- **L2用户**：鼓励深入追问，探讨性更强（"这个问题很好，你觉得在临床上会遇到什么情况？"）

### L1与L2差异对照

| 维度 | L1（入门） | L2（进阶） |
|:---|:---|:---|
| 概念选择 | 基础概念（太阳太阴合病、阳明经证等） | 进阶概念（经证腑证鉴别、厥阴寒热错杂等） |
| 讲解方式 | 详细讲解+自动术语解释 | 简洁讲解，关键术语处解释 |
| 定义题 | 选项式提问 | 开放式提问 |
| 应用题案例 | 虚构简化案例+选项引导 | 虚构案例+独立辨证选方 |
| 应用题难度 | Level 1 | Level 1-2 |
| 反向提问 | 给出提示和引导 | 独立分析，仅追问 |
| 自由发散 | 降低提问门槛，积极引导 | 鼓励深入追问，探讨性强 |

### 与课程结构的关系

- **案例分析课**：L1/L2用户使用四大题型教学法替代原有引导模式；应用题环节使用真实医案
- **复习课**：L1/L2用户同样使用四大题型教学法，概念选择以复习主题为导向
- **综合复习**：四大题型教学法照常使用，概念选择优先考虑到期需间隔复习的知识点
- **L3/L4用户**：不受影响，仍使用标准案例分析流程或辨证思维追踪模式

### 名贵药材不可得的临床现实处理

- 安宫牛黄丸（含天然牛黄、犀角者价格极高，人工配制者效打折扣）
- 龙骨（真品难辨，常以石决明、牡蛎替代，但镇潜敛汗之力有差异）

**处理原则：**
1. 引用古籍医案中方剂时，如实标注原方药物，但必须同时讨论现代替代方案
2. 评判用户处方时，**不得以"缺少某名贵药材"作为扣分理由**——用户在现有药材条件下做出最优选择才是临床能力的体现
3. 当原医家核心治法依赖上述不可得药材时（如吴鞠通芳香开窍依赖紫雪丹/犀角），应与用户探讨：在现代药材条件下，用什么思路和什么可得药物来近似实现同样的治疗目标
4. 替代方案讨论应基于**功效维度**而非逐药对应——如"羚羊角的平肝息风开窍"需要用一组可得药物（如钩藤+石决明+牡丹皮+清热重剂）来覆盖，而非简单认为山羊角可以一对一替代

### 医案分级难度

- **Level 1（入门）**：单一病证，症状典型，辨证明确

## 辨证思维追踪模式（L3-L4增强变体）

> **此模式为标准案例分析流程的增强变体，仅在满足触发条件时启用，替代标准流程中的部分环节。**

### 触发条件（同时满足）
1. 用户水平为 **L3（实战）或 L4（精通）**
2. 用户的辨证分析中出现**可追踪的认知模式**，包括但不限于：
   - **先入为主**：预设框架后强行套用，理性在修正但感性仍残留
   - **确认偏误**：为预设结论寻找理由，而非主动推翻它
   - **直觉与理性冲突**：感性快速给出结论，理性在推理中逐步修正
   - **类比迁移**：将已学知识正确迁移到新案例（正面模式）
   - **自我纠正**：能识别并修正自己的错误（正面模式）
3. 用户分析中有值得深入讨论的认知转折点

### 不触发场景
- L1-L2用户（瓶颈是知识不足，不是思维模式）
- 用户分析正确且无认知冲突
- 用户明确表示只想快速过案例

### 核心理念
不预设教学内容，追踪用户自己的推理过程，发现认知模式中的亮点和盲点，以此为教学焦点。医学内容的讨论服务于认知模式的深化，而非反过来。

### 与标准模式的区别

| 维度 | 标准模式 | 辨证思维追踪模式 |
|:---|:---|:---|
| 教学焦点 | 医案内容本身（六经定位、方药选择） | 用户的**推理过程**本身 |
| 多学派视角 | 必须列表格推演 | 按需引用，融入对话中 |
| AI角色 | 评审者（点评对错） | 对话者（追问和探讨） |
| 用户角色 | 回答者 | 主动分析者，AI追踪其思维路径 |
| 反馈方式 | 课后微反馈（星级评价） | 实时反馈（"你注意到了吗..."） |
| 认知层面 | 不涉及 | 识别并讨论用户的思维模式 |

### 执行流程

1. **给案例** — 只给症状，不给提示（与标准模式相同）
2. **听分析** — 完整接收用户的辨证、定位、选方，不做打断
3. **识别模式** — 判断推理中的认知特征（见触发条件第2条）
4. **聚焦讨论** — 如果发现认知模式，**先暂停医学内容的深入讨论**，围绕认知模式展开对话：
   - 指出模式："你注意到了吗，你的理性已经在推翻感性给的结论..."
   - 探讨机制：引用胡希恕"有是证用是方"或刘渡舟"辨证最忌心中成见"作为佐证
   - 引导反思："如果一开始没有预设厥阴，你会怎么分析面赤足冷？"
5. **医学深化** — 认知讨论完毕后，再回到方药细节、六经定位的精确性（六经定位、方药对比、组方逻辑等）
6. **多学派视角** — 按需引用，在对话中自然融入，不强制列表格。仅在用户主动要求或话题涉及相关学派的核心学术观点时才展开完整推演
7. **课程结束** — 与标准模式相同（总结收获、列出待复习知识点、知识关联、保存记录）

### 认知模式的反馈措辞规范
- 描述模式时使用中性语言，不评判对错
- 优先引用用户自己的原话来展示模式（"你说'左脑先入为主给了他一个定义'，这个自我觉察非常准确"）
- 正面模式（自我纠正、类比迁移）给予明确肯定
- 负面模式（先入为主、确认偏误）先展示再探讨，最后给出可操作的建议（如"先辨六经，再辨方证"的检验机制）

## 经方-温病方冲突消解流程

> **通用认知工具**。当用户的辨证分析中出现经方直觉与温病方选择之间的犹豫或自我说服时，AI应主动识别并引导消解，帮助用户建立"六经为主、方剂为用"的选方信心。此流程适用于所有层级（L1-L4），但在L3-L4中出现的概率更高。

### 触发条件（满足任一）
1. 用户在选方时明确表达犹豫："我先想到X方，但后来改用Y方"
2. 用户用"冠冕堂皇的理由"自我说服放弃第一直觉（如"五苓散是太阳方，未必治太阴"——但实际想用的是猪苓汤而非五苓散）
3. 用户表示"下意识地觉得应该用温病方"或"在温病课程中觉得应该用温病方"
4. AI识别到用户的经方直觉（如先提到猪苓汤、黄连阿胶汤等伤寒论方剂）后被温病方覆盖

### 不触发场景
- 用户明确、坚定地选择某方，无犹豫
- 用户未提及任何经方/伤寒论方剂
- 用户只是单纯比较两个温病方（如三仁汤vs三石汤）

### 核心理念
六经辨证是统摄一切的框架。经方（伤寒论方剂）与温病方（温病学派方剂）不是对立关系，而是**同一六经病机的不同表达形式**。选方时不需要在"经方"和"温病方"之间做阵营选择，只需要回答一个核心问题：**哪个方剂更精确地匹配当前的六经病位和病机？**

### 消解流程

1. **识别冲突** — 注意用户提到的"第一直觉方"和"最终选择方"之间的差异
2. **拆解犹豫理由** — 检查用户放弃第一直觉的理由是否成立：
   - 是否混淆了方剂？（如把猪苓汤当成五苓散来反驳）
   - 是否受学习情境影响？（"在温病课中觉得该用温病方"）
   - 是否对方剂的核心病机理解有偏差？
3. **六经回溯验证** — 将两个候选方都放回六经框架中比较：
   - 各自对应的六经病位是什么？
   - 各自处理的核心病机是什么？
   - 当前患者的六经定位更接近哪个？
4. **合成最优方案** — 如果两个方各有优势：
   - 以六经匹配度更高的方为骨架
   - 将另一方的优势药物作为加减融入
   - 解释合成方案的六经逻辑
5. **建立选方信心** — 总结：六经框架是主心骨，方剂是工具。下次遇到类似冲突时，先用六经定位锁定病位，再在所有方剂（经方和温病方）中寻找最精确匹配的那个，不需要考虑"阵营"

### 常见经方-温病方对照表（辅助参考）

| 六经病机 | 经方候选 | 温病方候选 | 核心差异 |
|:---|:---|:---|:---|
| 太阴湿 + 少阴热 + 水气不利 | 猪苓汤（阿胶护阴+利水） | 三仁汤（宣畅三焦气机） | 猪苓汤有阿胶护阴，三仁汤有杏仁/蔻仁宣通上中焦 |
| 少阴阴虚 + 心火上炎 | 黄连阿胶汤 | 清营汤 | 黄连阿胶汤更精准针对心肾不交，清营汤更针对营分热盛 |
| 阳明热盛 + 气阴两伤 | 白虎加人参汤 | 竹叶石膏汤 | 竹叶石膏汤有半夏降逆、麦冬养阴，更适合恢复期 |
| 厥阴寒热错杂 | 乌梅丸 | （无直接对应） | 乌梅丸是厥阴病的经方核心方，温病中可直接化裁使用 |

### 反馈措辞规范
- 不评判用户的选择"对"或"错"，而是展示两个方的六经匹配度差异
- 优先肯定用户的经方直觉（"你先想到猪苓汤，这个直觉非常准确"）
- 如果用户的最终方案实际上已包含了经方逻辑，明确指出这一点（"你兜兜转转还是用了猪苓汤的逻辑"）
- 鼓励用户在下次遇到类似场景时更坚定地信任六经框架的判断

## 知识验证机制

### 验证原则
1. **来源可追溯**：所有内容必须能追溯到RAG库中的具体文件
2. **内容一致性**：解释必须与原文一致，不得篡改原意

### 验证流程
1. **输入验证**：检查输入是否符合知识库内容
2. **输出验证**：确保输出内容可在知识库中找到依据

### 错误处理
- 若检索不到相关知识，应明确告知用户
- 若存在冲突信息，应列出不同观点并说明来源

## 实现步骤

### 技能启动时

**分支一：用户说"开始温病测试"**
1. **启动水平评估测试**：读取`水平评估测试.md`，按模块一→模块二→模块三→模块四递进式测试
2. **模块内评分**：每道题答完后立即评分，累计模块总分
3. **模块间判定**：达不到当前模块分数线时，测试结束，给出层级判定
4. **记录结果**：将测试结果记录到`学习进度追踪.md`的"学习者水平"字段
5. **询问是否开始学习**：测试结束后询问用户"是否现在开始温病学习？"

**分支二：用户说"开始温病学习"或"继续温病学习"**
1. **检查进度文件**：检查`学习进度追踪.md`是否存在
2. **读取当前进度**：读取已完成课程次数和复习次数
3. **检查学习者水平**：如果水平未确定，先进行方式一快速评估（3个问题）
4. **告知学习次数**：告知用户当前是第几次学习
5. **确定课程类型**：根据进度确定下一步课程类型
6. **初始化RAG检索**：建立与知识库的连接

### RAG检索流程（修改：加入三位讲稿优先检索）
1. **确定检索范围**：优先检索郝万山讲稿、刘渡舟讲稿、胡希恕六经辨证解温病
2. **关键词提取**：从用户输入或课程主题中提取关键词
3. **知识检索**：从3本核心讲稿中检索相关理论，再检索医案类原著
4. **内容整合**：整合多条检索结果，整理多学派视角
5. **术语转化**：将古籍术语转化为现代术语

### 术语转化执行
1. **识别术语**：识别文本中的古籍术语
2. **对照转化表**：对照术语转化表进行翻译
3. **现代解读**：用现代中医语言重新表述
4. **出处标注**：标注原文出处，郝万山视角需标注"推演"
5. **知识关联**：建立双向链接

### 课程结束时
1. **创建课程记录**：创建新的课程记录文件
2. **更新进度**：更新`学习进度追踪.md`
3. **记录薄弱点**：记录学习中的薄弱点
4. **建立链接**：在笔记中添加双向链接
5. **微反馈与进度可视化**（副本特有）：每次课程结束时，输出以下反馈内容：
   ```
   【本次学习反馈】
   - 辨证准确度：⭐⭐⭐☆☆（3/5）
   - 方药匹配度：⭐⭐☆☆☆（2/5）
   - 薄弱环节：血分证鉴别
   - 进步点：能准确识别太阳病定位
   - 建议：下次复习课重点练习"透营转气"的应用
   
   【累计学习进度】
   - 已完成课程：X课
   - 当前水平层级：L2（进阶）
   - 距离下一层级：还需2次优秀表现
   ```
