# 中医温病医案学习系统

## 系统说明

这个系统帮助您：
1. 收集和管理中医医案
2. 自动生成学习内容
3. 追踪学习进度
4. 建立知识关联网络

## 目录结构

```
叶天士/
├── 09-医案学习数据库/
│   ├── 医案库/                # 存放输入的医案
│   ├── 已学习/                # 已经学习过的医案
│   ├── 知识卡片/              # 生成的知识卡片
│   └── 学习计划.md           # 学习计划和进度
├── 10-学习工具/
│   └── 医案处理工具.py       # 医案处理工具
└── 学习进度追踪.md           # 学习进度（已有）
```

## 使用流程

### 第一步：输入医案

从PDF中复制医案内容，保存为markdown文件到 `09-医案学习数据库/医案库/`

### 第二步：处理医案

运行医案处理工具，自动提取关键信息

### 第三步：开始学习

根据学习计划进行学习

## 医案格式

每个医案文件应该包含：
- 患者信息
- 症状描述
- 舌脉
- 诊断（可选）
- 处方（可选）
- 医家点评（可选）
