# 本草家融合标注·使用规范

> 用途：诊疗基础用药教学——管理多本草家（陈士铎/王好古/徐灵胎/张锡纯……）对同一批药物的观点，防止"谱系逻辑无限庞大"。
> 机制定位：仿经典临床多学派机制（核心机制第十章/第十一章），但数据形态不同——本草家面对同一对象（药），故不按家分文件，而**按药归并、按层分类**。
> 适用：`本草类/` 目录下所有"*_共识与创新标注.md"类文件的新建与更新。

---

## 一、三层结构（对每一味药）

| 层 | 内容 | 教学出场 | 规模增长方式 |
|:---|:---|:---|:---|
| **①共识层**（默认教学） | 所有本草家一致认同的用法（与《神农本草经》《本草纲目》及现代《中药学》教材通行认识一致） | **默认教学内容**，每次讲这味药都讲 | 新家观点与已有共识一致→**直接并入，不新增条目** |
| **②特色层**（按需触发） | 某家独有的创见，逐条附原文短引+出处标注 | 平时不出现；由七杠杆纵向谱系、检索或用户提问触发才出场 | 每味药每新增一家，只加 **0-3 条**（只记真正独有的） |
| **③冲突层**（相背观点） | 各家**直接相背**的观点 | 触发"药对多视角卡片"，按核心机制 11.5 模板展示 | 冲突条目最稀少，每味药可能长期为 0，只在真矛盾时建 |

**规模控制原则**：新本草家加入时，其内容约 90% 与已有共识重复——这些自然归入共识层（本就在，不新增）；只有 ~10% 独见进特色层；极少数相背观点进冲突层。**规模线性微增，不指数爆炸。**

---

## 二、一致性检验（新本草家准入流程）

每加入一位新本草家，先跑本流程，**通过才允许挂载**：

```
Step 1 提取：对全书高频药（先只做教学重点药，约 30-50 味）提取该家核心观点
Step 2 比对：与现有共识层逐条比对 → 分类为：
   ┌─ 一致  → 并入共识层（不新增条目，可在流变备注注明"XX亦持此说"）
   ├─ 独见  → 进特色层，标注"仅[医家]持此说"+原文短引
   └─ 相背  → 进冲突层，必须写清：
       【该家观点】vs【共识/他家观点】
       【分歧本质】相背的理论根源
       【临床取舍】教学时如何指导学生（有是证用是方）
Step 3 挂载：完成归类后写入对应标注文件；同步在检索规范登记
```

**准入判定规则**：
- 某家与现有共识**大面积相背**（阴阳立场整体相反，如整体滋阴 vs 整体扶阳）→ 不硬塞进单药表，走医家内化流程在医家体系中单独立派（`各家学说库/医家体系概要/`），仅在冲突层挂一条"本家与共识的整体分歧说明"。
- 观点查证不足 → 标注"待考"，不强行归类。
- 不因"某家没提某药"而补写观点——缺省即视为认同共识，不产生条目。

## 三、文件格式约定

### 3.1 文件命名
`本草类/《书名》（医家）_共识与创新标注.md`
- 样板①：`本草新编（陈士铎）_共识与创新标注.md`（126 药，已按三层格式改造）
- 样板②：`神农本草经百种录（徐灵胎）_共识与创新标注.md`

### 3.2 文件头部模板

```
# 《书名》（医家）共识与创新标注

> **【本草家融合标注·通用格式样板N】**
> - **①共识层（默认教学）** = 与主流本草学一致、后世沿用的部分——多本草家共同认同的用法归此层，教学默认讲授；
> - **②特色层（按需触发）** = 该本草家个人创见，逐条附原文短引，标注出处——平时不默认讲授，由纵向谱系或用户提问触发出场；
> - **③流变备注（共识验证）** = 有据可查的后世沿用/流变，用于验证①与②的边界；查证不足标"待考"。
> 加入时按《本草家融合标注_使用规范.md》一致性检验流程归类；相背观点进冲突层。
> 依据：《书名》清·XX著（本库版本 NNNN 行…）。
```

### 3.3 药物条目格式

```
### N. 药名（卷·集/篇名）
- **①共识层**：<与主流一致的核心功效与主治>
- **②特色层**（[医家]）：a.独见1（原文短引）……b.……
- **③冲突层**：<无> 或 <该家观点 vs 他家观点 + 分歧本质 + 临床取舍>
- **流变备注**：<后世沿用情况/待考>
```

### 3.4 速查表（文件开头，教学重点药）
| 药物 | ①共识层 | ②特色层（一句话） | ③冲突层 |
|:---|:---|:---|:---|

## 四、教学触发规则

1. **默认教学**：只讲①共识层——保证基础稳定，不因本草家增多而教学内容膨胀。
2. **纵向谱系课**（诊疗基础"纵向谱系"杠杆）：按谱系链（本经→纲目→本草新编→张锡纯→本案角色）逐站出场②特色层——每站就是一层，链长固定，不随本草家数量变长。
3. **分歧出现**：同一药出现对立用法（③冲突层非空）→ 触发"药对多视角卡片"（核心机制 11.5 模板），展示共识层+各家视角+分歧焦点。
4. **用户提问**：问"XX家怎么看这味药"→ 检索该家特色层+冲突层条目，按该家视角回答。

---

## 五、更新流程（新增本草家时执行）

1. 阅读新本草家原著（或已有 `各家学说库/医家体系概要/[医家].md`）
2. 跑一致性检验（第二节流程）
3. 更新/新建对应标注文件（第三节格式）
4. 更新 `skills/common/核心机制.md` 诊疗基础检索规范（登记新标注文件）
5. 若该家有大面积相背 → 走医家内化流程（`skills/文档内化工具/`），并在冲突层挂整体分歧说明
6. 提交推送（工作流第3条：commit + push mandatory）
