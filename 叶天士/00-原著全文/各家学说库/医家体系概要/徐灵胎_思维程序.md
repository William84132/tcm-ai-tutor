# 徐灵胎思维程序

> 本文件不是"徐灵胎理论概要"，而是一套可执行的推理程序。
> 目标：模拟徐灵胎（徐大椿）面对患者时的思考过程，从症状入口到处方出口。
> 所有规则均从徐灵胎五部著作原文归纳：《医学源流论》《兰台轨范》《伤寒论类方》《神农本草经百种录》《洄溪医案》，引用标注格式：书名·篇名/案名。
> 如果AI读取本文件后，能像徐灵胎一样辨证求因、以方类证、识别温补误治、鉴别亡阴亡阳，则内化成功。

## 程序总则

### 核心公理（不可动摇的前提）

| 编号 | 公理 | 原文依据 |
|:---|:---|:---|
| A1 | **元气存亡决死生**。诊病断吉凶先看元气（先天定分），不看病之轻重；攻补不得其道则"实其实而虚其虚"，故药不可轻试 | "诊病决死生者，不视病之轻重，而视元气之存亡，则百不失一矣"（医学源流论·元气存亡论） |
| A2 | **辨证求因，一病必有主方，一方必有主药**。病名必须先实指，不许以"阴虚阳虚"等笼统之谈概之；同病异因必须分治 | "凡人之所苦谓之病，所以致此病者谓之因"（医学源流论·病同因别论）；"一病必有主方，一方必有主药"（兰台轨范·原序） |
| A3 | **经方为法度，古方加减有纪律**。病情与古方全合则全用原方；有出入则据古法加减，必使无一药不对症；去主药即不得冒原方之名 | "能识病情与古方合者则全用之，有别症则据古法加减之"（医学源流论·古方加减论）；"凡古方与病及证俱对者，不必加减"（洄溪医案·伤寒） |
| A4 | **邪未去不可补，补必留邪为害**。参附熟地只许用于确证之虚；邪盛投补则"元气与邪气相并，反助邪而肆其毒" | "病未去而用参，则非独元气不充，而病根遂固"（神农本草经百种录·人参条）；"邪盛而投以大剂参附……越一二日，元气与邪气相并，反助邪而肆其毒，为祸尤烈"（医学源流论·劫剂论） |
| A5 | **治病必先辨寒热虚实真假**。以"问所便"（口渴喜冷/热饮）与脉症合参为辨；"身大热而反欲热饮则假热真寒，身寒战而反欲寒饮则假寒真热" | "假寒者寒在外而热在内也，虽大寒而恶热饮；假热者热在外而寒在内也，虽大热而恶寒饮"（医学源流论·寒热虚实真假论）；"临病患问所便……百不失一"（医学源流论·临病患问所便论） |
| A6 | **多法并治，煎服法度不可废**。病在经络筋骨者汤药不能尽病，须针、灸、砭石、熨浴、薄贴、围药等法；煎法服法失度则药必无效 | "《内经》治病之法，针灸为本……若邪在筋骨肌肉之中，则病属有形，药之气味不能奏功也"（医学源流论·汤药不足尽病论）；"煎药之法最宜深讲，药之效不效全在乎此"（医学源流论·煎药法论） |

## 推理程序

### 第一步：入口判断——"先问所便，次辨寒热真假"（首辨，四诊锚点）

徐灵胎不看"什么病"，先判"阴阳寒热真假"与"有无实邪"。**收到任何症状集合，先执行以下判断**：

```
输入：患者症状集合 S

判断0（总开关）：问所便——
  ① 口渴否？喜冷饮还是热饮？（最关键锚点）
  ② 汗出否？汗冷汗热？味咸味淡？
  ③ 脉是洪实有力还是浮空/沉微无力？
  ④ 手足温还是冷？

若：身大热/面赤/烦躁 而 反欲热饮 ＋ 脉浮数而空或沉微 ＋ 汗冷味淡微粘 ＋ 手足冷
  → 假热真寒（格阳/戴阳/亡阳倾向）
  依据："如身大热而反欲热饮，则假热而真寒也"（医学源流论·临病患问所便论）

若：身寒战/肢冷 而 反欲寒饮 ＋ 脉洪实 ＋ 汗热味咸 ＋ 口渴喜凉
  → 假寒真热（热深厥深）
  依据："身寒战而反欲寒饮，是假寒而真热也"（同上）；
      亡阴之汗"身畏热、手足温、肌热、汗热味咸、口渴喜凉饮、气粗、脉洪实"
      （医学源流论·亡阴亡阳论）

若：不渴/喜热饮 与 大渴饮冷 均不明显，则以脉症合参——
  脉症相合者从合，脉症相反者按"症脉轻重论"定从症或从脉
  依据："脉与症分观之，则吉凶两不可凭，合观之乃可定矣"
      （医学源流论·症脉轻重论）
```

### 第二步：辨证求因子程序（本程序的核心分歧点）

```
子程序A：求病因——"此病因何而起？"
  同一身热，问：是风？寒？痰？食？阴虚火升？郁怒忧思？劳怯？虫病？
  依据："热同而所以致热者不同，则药亦迥异"（医学源流论·病同因别论）
  □ 伤食恶食：闻饭气则呕、不食不寝 → 宿食在胃，去宿食则食自进
      （"伤食恶食人所共知，去宿食则食自进，老少同法"——洄溪医案·外感停食）
  □ 痰实诸窍：体丰气旺、脉滑实、阳升不降 → 痰火充实，禁温补
      （洄溪医案·痰证杨姓"痰火愈结身强如尸"；小续命汤去桂附加生军案）
  □ 外邪留经络：痛有定处、肿毒、流注 → 外治提邪外出，禁"风药不验即温补"
      （洄溪医案·周痹"先服风药不验即用温补，使邪气久留，即不死亦为废人"）
  □ 热邪留胃（时证）：神昏脉数，外感之邪久必归阳明 →
      有食结燥矢用三承气；无食凝热痰用三泻心
      （洄溪医案·时证"邪轻而无食则凝为热痰，三泻心汤主之"）
  □ 暑邪闭窍：卒倒厥僵、齿噤不开、脉绝心温 → 芳香通灵开窍
      （紫金锭/至宝丹，"非芳香通灵之药不能即令通达"——洄溪医案·暑）
  □ 血证：先辨咳血/吐血/衄血、血脱之阴阳 →
      咳者成劳不咳者不成劳；脱血后先保阴后议补
      （医学源流论·吐血不死咳嗽必死论；洄溪医案·吐血诸案）

子程序B：辨真假——"外象与内因是否相反？"
  触发：症状与常见病机相反者（冒寒反恶热、伤暑反恶寒、伤食反易饥、
        畏寒十年服附子反剧、肢冷脉伏而口臭气粗……）
  逐项核查：
    □ 口渴：喜滚饮/不渴 → 寒（真寒假热）；大渴饮冷 → 热
    □ 汗：汗冷味淡、手足冷、舌润 → 亡阳，用参附（如：毛介堂暑病大汗脉微肢冷面赤气短
        "此即刻亡阳矣，急进参附以回其阳"——洄溪医案·暑）
       汗热不粘、手足温、舌干、脉洪 → 亡阴，禁热药（浮麦大枣止汗——洄溪医案·痰喘亡阴）
    □ 脉：浮空虚数重按无根 → 阳虚外越；洪大有力 → 实热痰火
    □ 神情：昏沉但欲寐+面赤如妆 → 格阳；烦躁谵语+目赤气粗 → 实热
    □ 病史：前医是否已服参附温补而病反增？→ 高度怀疑补住邪气/误补
  判定：症状与脉、与所便相反且前医温补无效 → 按"相反者"立法，
      不得沿用温补思路（R3/R4/R6/R7 按病类执行）
  依据："此等之病尤当细考，一或有误而从症用药，即死生判矣"
      （医学源流论·脉症与病相反论）
```

### 第三步：定位——脏腑经络躯壳+六经定位（徐氏定位表）

```
在阴阳方向与病因确定后，落定部位：

一、层次定位（医学源流论·躯壳经络脏腑论）：
  皮肉筋骨（躯壳）→ 病属有形，汤药难达 → 外治（敷拓薰蒸、薄贴、围药、针灸）
  经络 → 易传，用药引经透达
  脏腑 → 难治多死，主方主药必求精准

二、六经定位（伤寒论类方·六经脉证 + 十二类方）：
  太阳 → 脉浮头项强痛恶寒；汗出恶风脉缓=中风（桂枝汤类）；
          无汗而喘脉浮紧=伤寒（麻黄汤类）；项背强几几（葛根汤类）
  阳明 → 胃家实；潮热谵语腹满硬痛绕脐痛手足濈然汗出（承气汤类急下存阴）；
          身热汗出口渴脉洪大无表证（白虎汤类）
  少阳 → 口苦咽干目眩脉弦；往来寒热胸胁苦满默默不欲饮食心烦喜呕
          （小柴胡汤类，但见一证便是）
  太阴 → 腹满而吐自利益甚时腹自痛；自利不渴=脏寒（理中汤类）
  少阴 → 脉微细但欲寐；寒化：厥逆下利清谷（四逆汤类）；
          热化：心中烦不得卧（黄连阿胶汤）
  厥阴 → 消渴气上撞心饥而不欲食食则吐蛔（乌梅丸）；热利下重（白头翁汤）
  依据："欲读《伤寒论》必先识六经之本证……其症之分并疑似及用药加减异同之故
        可以晓然"（伤寒论类方·六经脉证）
```

### 第四步：处方生成（基础架构 + 加减矩阵）

#### 4.1 处方生成总则

```
输入：病因+部位+寒热真假判定结果
1. 查主方：此病（此因此症）在仲景方/六朝唐方中主方为何？
   → 病情与古方所列之症全合 → 全用原方，不加减（洄溪医案·伤寒倪姓大承气案）
2. 有出入 → 据古法加减，必使"无一药之不对症"（医学源流论·古方加减论）
3. 定煎服法：主药先煎（麻黄汤先煎麻黄去沫）、去渣再煎（小柴胡）、
   啜粥温覆（桂枝汤）、麻沸汤渍（泻心汤）、分服次数等，一律按方后法
4. 定效验预期：预立医案，说明服后何时减去何症；不验必求所以不验之故
   （医学源流论·治人必考其验否论）
5. 急症急救药须平时预备：至宝丹、紫金锭、苏合香丸、黑锡丹等
   （医学源流论·医必备药论）
```

#### 4.2 以方类证十二类主方架构（伤寒论类方）

```
① 桂枝汤类（19方）：桂枝+芍药+甘草+姜+枣 —— 太阳中风解肌
   加减示例（古方加减论）：项背强+葛根；喘+厚朴杏仁；漏汗恶风+附子；
   悸而烦→小建中（倍芍药加饴糖，另立方名）；下后脉促胸满去芍药……
② 麻黄汤类（6方）：麻黄+桂枝+杏仁+甘草 —— 太阳伤寒发汗
   汗出而喘无大热→麻杏石甘；不汗出而烦躁→大青龙；心下有水气→小青龙；
   少阴反发热脉沉→麻黄附子细辛
③ 葛根汤类（3方）：项背强几几无汗恶风（葛根汤）/有汗（桂枝加葛根）；
   下利协热而喘汗→葛根芩连
④ 柴胡汤类（6方）：小柴胡（但见一证便是）；呕不止心下急→大柴胡（加枳实芍药大黄）；
   胸满烦惊谵语→柴胡加龙骨牡蛎；热入血室→小柴胡/刺期门
⑤ 栀子汤类（7方）：汗吐下后虚烦不得眠心中懊憹 → 栀子豉加减
   （栀子生用取吐；"在上者因而越之"）
⑥ 承气汤类（12方）：大承气（急下存阴）、小承气（微和胃气）、调胃承气；
   蓄血→桃核承气/抵当汤丸；结胸→大陷胸（下蓄水）/小陷胸（下黄涎）；
   水饮→十枣汤；脾约→麻仁丸
⑦ 泻心汤类（11方）：心下痞——三泻心（半夏/生姜/甘草）寒热并用；
   大黄黄连泻心（麻沸汤渍取轻扬）；附子泻心（附子别煮取汁）；黄连汤（加桂枝和表里）
⑧ 白虎汤类（3方）：白虎（脉滑而厥、里有热）；白虎加人参（大汗大烦渴脉洪大）；
   竹叶石膏（伤寒解后虚羸少气气逆欲吐，滋养肺胃之阴）
⑨ 五苓散类（4方）：蓄水消渴小便不利（五苓散，多饮暖水汗出愈）；
   少阴下利咳呕渴烦不得眠（猪苓汤）；汗出而渴/不渴（五苓/茯苓甘草之别）
```

## 验证用例（全部提取自《洄溪医案》真实案例，辅以《医学源流论》理论）

### 用例1：中风（封门金姓）——温补误治翻案（R3 执行示范）

```
输入症状：早立门首卒遇恶风，口眼歪斜，噤不能言；医用人参、桂、附诸品
  （"近日时医治风证不祧之方"）；其形如尸，面赤气粗，目瞪脉大。
辨证（徐氏）：虚邪贼风，实邪闭窍——"此正《内经》所谓虚邪贼风也，
  以辛热刚燥治之固非，以补阴滋腻治之亦谬"。
处方：祛风消痰清火之剂（辛凉为主，佐以甘温），三剂醒而能食；
  后以膏方调理，腿膝手臂渐复。
关键判断：面赤气粗脉大=实象，绝非虚证——"壮年得此必大虚"之说是时医通病；
  同卷王公叙揆案更明示：脉洪大有力面赤气粗者"服参附立毙矣"，
  以小续命汤去桂附加生军而愈。
（洄溪医案·中风；理论依据：医学源流论·中风论）
```

### 用例2：伤寒失下（苏州柴行倪姓）——经方原方不加减（A3 执行示范）

```
输入症状：伤寒失下，昏不知人，气喘舌焦，已办后事。
辨证（徐氏）：大承气汤证。

  戒曰"一剂不下则更服，下即止"。
转归：月余而返，其人已强健如故。
按语："古方之神效如此……若不当下者反下之，遂成结胸，以致闻者遂以下为戒，
  颠倒若此，总由不肯以仲景《伤寒论》潜心体认耳。"
（洄溪医案·伤寒）
```

### 用例3：暑热坏证阳越（芦墟迮耕石）——亡阳急救与阳回转清（A5+R6 执行示范）

```
输入症状：暑热坏证，脉微欲绝，遗尿谵语，寻衣摸床——阳越之证，将大汗出而脱。
辨证（徐氏）：暑邪内闭，真阳外越（先回阳，后清暑——两步序贯）。
第一步处方：参附加童便饮之（童便咸降引阳归宅）——少苏而未识人。
第二步（阳回火复）：医者仍用前方煎成未饮，徐至曰："阳已回，火复炽，阴欲竭矣，
  附子入咽即危"——命以西瓜啖之（"西瓜有天生白虎汤之名"），连日啖数枚，
  更饮清暑养胃之方而愈。
关键判断：同一病人先后两法截然相反——回阳有时，清暑有时；
  "附子古名霹雳散，果服三剂，非西瓜则伏暑何由退"。
（洄溪医案·暑；对照：毛介堂案"此即刻亡阳矣急进参附"、龚孝维案
  脉微而躁肤冷汗出参附方——亡阳之辨以脉微、汗冷、舌润为据）
```

### 用例4：畏寒（洞庭卜夫人）——十年温补误案，热深厥深之反例（R8 执行示范）

```
输入症状：寒疾，有名医进以参附日以为常，十年以来服附子数十斤而寒愈剧；
  初冬即四面环火，绵衣几重，寒栗如故。
辨证（徐氏）：热邪并于内，逼阴于外——"《内经》云热深厥亦深，又云热极生寒。
  当散其热，使达于外"。
处方：芦根数两煎清凉疏散之药饮之，三剂而去火，十剂而减衣，
  常服养阴之品而身温；逾年附毒积中者尽发，周身如火烧、遍体热疮，
  以治热毒之法一年乃复，后反恶热。
关键判断：寒栗畏寒+十年温补无效+服附数十斤 → 先怀疑"热极生寒"；
  "如不知其理而更进以热药，则热并于内寒并于外，阴阳离绝而死，
  死之后人亦终以为阳虚而死也"——温补误人而病家不悟之典型。
（洄溪医案·畏寒）
```

### 用例7：肠红脱血（淮安程春谷）——血脱后参附之弊与茅根引阳（R10 执行示范）

```
  参附之力皆达于外，自能手足温而卧矣。"
（洄溪医案·肠红）
```

2. 患者大汗不止，名医断为亡阳欲用参附熟地干姜。你诊见脉洪大、手足不冷、汗热不粘、口渴喜凉饮。怎么办？
   - [ ] 错误回答：大汗即亡阳，参附回阳
   - [x] 正确回答：亡阴（汗热味咸、脉洪实、手足温、口渴喜凉）——"亡阴之药宜凉"，浮麦大枣汤先敛汗，再消痰降火；亡阳（脉微、汗冷如膏、厥逆舌润）才用参附。一或相反无不立毙。

3. 74岁老人外感停食，闻饭气则呕、匝月不食，前医以年高"非补不纳"，惟参汤续命。怎么办？
   - [ ] 错误回答：高年正虚，补中气待其自消
   - [x] 正确回答：伤食恶食——"去宿食则食自进，老少同法"，生大黄攻宿食（注意煎成强服、中病即止）；"以老人停食不可消止宜补中气"是"乱道"。

4. 患者畏寒十年，前医日服参附，附子已服数十斤而寒愈剧，冬月环火重绵寒栗如故。怎么分析？
   - [ ] 错误回答：寒证无疑，加重温补
   - [x] 正确回答：十年温补无效+服附数十斤 → 高度怀疑"热极生寒/热深厥深"，热邪并于内逼阴于外；芦根清凉疏散之剂散其内热，三剂去火十剂减衣；若再进热药则阴阳离绝而死。

5. 患者暑月卒倒、齿噤不开、脉绝心温，家人已备后事。怎么办？
   - [ ] 错误回答：脉绝即脱证，灌参附
   - [x] 正确回答：暑邪闭塞诸窍（尸厥），非芳香通灵之药不能即令通达——紫金锭磨灌开窍，再服清暑通气之方；唯脉微欲绝、汗出肢冷、舌润之真阳越者才用参附童便，且阳回即转清暑。

6. 产妇产后发热如炭、唇燥舌紫，前医执"产后属虚寒"用干姜熟地。怎么办？
   - [ ] 错误回答：产后必虚，温补固本
   - [x] 正确回答：血枯火炽兼风热，刚燥滋腻益火塞窍——遵仲景竹皮石膏汤清阳明盛火；"产后宜温"是邪说，仲景产后用石膏白薇竹茹无不神效。

7. 患者大吐血数升后，面色白而带青、脉微声哑。前医拟浓煎人参汤灌之。你怎么处理？
   - [ ] 错误回答：血脱益气，人参一两浓煎
   - [x] 正确回答：血脱后用人参只可"以接其气，气稍接即当用血药，否则孤阳独旺而阴愈亏"——阿胶、三七保阴止血，微和人参；"断不可重用人参升气助火，亦不可多用滋腻以助痰滞胃"。

8. 患者自述"我这是阴虚，该吃六味地黄"，前医亦以六味治时证发热而病重。你的看法？
   - [ ] 错误回答：六味平和，阴虚通用无妨
   - [x] 正确回答：外感之邪最忌滋滞（仲景113方惟复脉用地黄）；时证神昏脉数乃热邪留胃，"浙中医家不论何病必用六味"正是时弊——邪轻无食凝为热痰用三泻心，有食成燥矢用三承气。

9. 一个"阳虚失血"患者（面色㿠白、肢冷、血淡），前医已用鹿茸温补，服后血上冒连吐十余碗。你怎么判断？
   - [ ] 错误回答：阳虚失血，加大温补固摄
   - [x] 正确回答：素体阴虚之人气升火旺之时见红，反用大热升发之剂"以扰其阳而烁其阴"——血脱之后脏腑经络俱空，鲜生地十斤绞汁煎浓略加人参末徐徐进之，再进阿胶三七诸养阴之品；"血脱补阳"只用于大脱之后阴尽阳无所附、肢冷汗出之顷刻。

10. 患者诉"胁下素有饮癖，发则胀痛呕吐，前医每以补剂疗之，发益勤而甚"。怎么办？
    - [ ] 错误回答：久病必虚，参附峻补托邪
    - [x] 正确回答：饮癖之疾"惟以消饮通气为主，断不可用温补，补则成坚癖不可治矣"——消饮通气（可合外治蒸法），忌温补。
