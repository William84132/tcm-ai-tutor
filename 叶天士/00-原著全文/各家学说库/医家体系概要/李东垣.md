## 二、核心辨证方法

### 脾胃升降辨证

李东垣以脾胃为辨证核心，创立了独特的"脾胃学说"：

1. **内伤脾胃，百病由生**：一切疾病皆源于脾胃功能失调
2. **升阳益气**：脾胃以升为健，重视升发脾阳
3. **阴火学说**：脾胃气虚，元气不足，阴火上冲
4. **虚实辨证**：外感与内伤的根本区别在于脾胃状态

### 外感与内伤鉴别

李东垣在《内外伤辨惑论》中详细区分：

| 鉴别要点 | 外感 | 内伤 |
|:---|:---|:---|
| 发热特点 | 发热恶寒并见 | 发热恶热，得凉则止 |
| 手足温度 | 手背热 | 手心热 |
| 头痛 | 头痛不止 | 时痛时止 |
| 口渴 | 口不渴 | 口渴喜温饮 |
| 脉象 | 脉浮紧/浮数 | 脉洪大，按之无力 |
| 饮食 | 饮食如故 | 饮食减少 |
| 精神 | 精神不衰 | 精神倦怠 |

## 三、医理体系

### 3.1 脾胃为后天之本

李东垣脾胃学说的核心观点：

- **元气论**：元气乃先身生之精气，非胃气不能滋之
- **脾胃为元气之本**：元气之充足，皆由脾胃之气无所伤
- **胃虚则脏腑经络皆无所受气而俱病**：脾胃一虚，五脏六腑皆病
- **养生当实元气**：欲实元气，当调脾胃

### 3.2 阴火学说

李东垣独创的"阴火"理论：

- **阴火的本质**：脾胃气虚，元气不足，相火（阴火）失其制约而上冲
- **阴火的表现**：身热、面赤、心烦、口渴、脉洪大（类似实热，实为虚热）
- **阴火的病机**："脾胃气虚，元气不足，而心火独盛"
- **治阴火之法**：不直折其火，而以甘温之剂补其中、升其阳

### 3.3 甘温除热法

李东垣治疗"气虚发热"的独特方法：

- **不用寒凉**：不用黄连、黄芩等苦寒直折
- **甘温为主**：用黄芪、人参、白术、甘草等甘温之药
- **少加寒凉**：在甘温药中少加黄柏、生地黄以泻阴火
- **代表方**：补中益气汤、升阳散火汤

### 3.4 升阳理论

- **脾主升清**：脾主升发清阳之气上至心肺头目
- **胃主降浊**：胃主受纳腐熟，降浊下行
- **升清阳，降浊阴**：脾胃升降正常，则气机调畅
- **风药升阳**：用防风、羌活、柴胡、升麻等风药升发脾阳

## 四、用药偏好与药对

### 4.1 用药总体特征

- **重用人参、黄芪**：大补脾胃之气
- **善用风药升阳**：防风、羌活、柴胡、升麻等升发清阳
- **甘温为主**：少用苦寒，多用甘温
- **轻清灵动**：不喜重浊滋腻，以免碍脾

### 4.2 常用药对

## 五、学术特点

### 5.1 核心学术标签

- **补土派**：以补脾胃为治病核心
- **易水学派**：继承张元素，重视脏腑辨证
- **甘温除热派**：以甘温之剂治疗气虚发热
- **升阳学派**：重视升发脾阳

### 5.2 对后世的影响

- **明清温补学派**：薛立斋、张景岳、李中梓等深受影响
- **温病学派**：叶天士养胃阴之法受东垣启发
- **现代临床**：补中益气汤至今仍为常用方

### 5.3 用药特色

- **量大效宏**：补中益气汤中黄芪可用至一两（30g以上）
- **风药与补药同用**：在补气药中加入风药升阳，是其独特配伍
- **甘温与苦寒并用**：甘温为主，少加苦寒以泻阴火

### 5.4 养生思想

- **饮食有节**：饮食不节则脾胃受伤
- **劳倦内伤**：劳倦过度则元气受损
- **情志致病**：忧思过度则伤脾
- **养生当实元气**：调养脾胃为养生之本

## 六、与六经辨证的关系

李东垣以脏腑辨证为主，但与六经辨证有对应关系：

| 六经 | 李东垣辨治特色 | 代表方药 |
|:---|:---|:---|
| 太阳病 | 表证兼脾胃气虚，扶正解表 | 补中益气汤加解表药 |
| 阳明病 | 胃家实兼气虚，通下护正 | 承气汤加减，顾护胃气 |
| 少阳病 | 胆火犯胃，和解兼健脾 | 小柴胡汤加白术 |
| 太阴病 | 脾虚寒湿，温中健脾 | 理中汤、补中益气汤 |
| 少阴病 | 心肾两虚，补脾以生血 | 补中益气汤加附子 |
| 厥阴病 | 寒热错杂，调脾胃以和阴阳 | 乌梅丸加减 |

李东垣的脾胃学说为六经辨证补充了"内伤"维度，使六经辨证不仅适用于外感，也适用于内伤杂病。

## 七、学派矛盾点

李东垣的学术主张与部分学派存在张力：

| 矛盾维度 | 李东垣立场 | 对立学派立场 |
|:---|:---|:---|
| 治病求本 | 百病皆由脾胃生 | 刘完素认为"六气皆从火化"，火热为本 |
| 用药寒热 | 甘温除热，慎用苦寒 | 寒凉派主张寒凉泻火 |
| 攻邪与扶正 | 先扶正，正气足则邪自去 | 攻邪派主张先攻邪，邪去正自安 |
| 滋阴与升阳 | 升阳为主，阳生阴长 | 朱丹溪主张"阳常有余阴常不足"，重在滋阴 |
