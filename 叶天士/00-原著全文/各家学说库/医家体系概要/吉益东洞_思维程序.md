## 程序总则

### 核心公理（不可动摇的前提）

1. **万病一毒**。一切疾病皆由"毒"引起。毒留体内则生病，治当逐毒。"万病生于一毒，非毒则无病也。"
   > **原文依据**：此条出自吉益东洞原著《医断》。
   > **重要说明**：经系统检索，大塚敬节在《临床应用伤寒论解说》《金匮要略研究》《汉方诊疗三十年》
   > 三部代表作中均未提及"万病一毒"论（检索"万病一毒"及"一毒"关键词均无匹配）。
   > 大塚敬节继承的是东洞的方法论（方证对应、药征、腹诊），而非此病理学说。

2. **方证对应为唯一辨证方法**。不谈理论，不谈病机，只问"何方证"。"但见证，不论理。"
   > **原文依据**："名古屋玄医之后，后藤艮山、香川修德、松原一闲庵、山胁东洋、吉益东洞等
   > 古方家辈出，取代了以李朱医学为宗的后世派，自此，以《伤寒论》为宗的古方派占据了
   > 医学的主流。"——转引自《临床应用伤寒论解说》概论第五章（大塚敬节记述东洞在古方派中的历史定位）

3. **仲景原方不可加减**。严守经方原方，不创新方，不加减药物。"仲景之处方，不可加一味，不可减一味。"
   > **原文依据**：此条出自吉益东洞原著。大塚敬节记述古方派基本立场：
   > "古方派的基本立场是，只要研究了汉末医著《伤寒论》和《金匮要略》，唐宋以降的杂书
   > 就没必要看了。"——转引自《汉方诊疗三十年》自序（大塚敬节记述古方派立场）

4. **药征辨证**。以药物的客观征象（药征）为选方依据，而非主观理论推断。药征从仲景原文统计归纳，排斥《神农本草经》分类及后世药性理论。
   > **原文依据**："关于《伤寒论》《金匮要略》药物的专著，有吉益东洞的《药征》、内野尚贤的
   > 《古方药品考》、浅田宗伯的《古方药议》等，均为有必要一读的好书。"
   > ——转引自《临床应用伤寒论解说》概论第五章（大塚敬节推荐《药征》为必读书）
   > **原文依据**："肝苦急时，食甘甜味以缓和之，所以喜食甘甜。吉益东洞《药征》中甘草部分
   > 亦论述及此。"——转引自《金匮要略研究》正文解读"五脏风寒积聚病脉证并治第十一"，肝中风条

5. **亲试实验**。一切认识来源于亲身尝药和临床实验，反对空谈理论。"医者意也，非口舌所能传。"
   > **原文依据**：此条出自吉益东洞原著。

6. **否定《素问》《灵枢》，排斥阴阳五行**。认为《素问》《灵枢》为伪作，阴阳五行不可为用药依据。
   > **原文依据**："吉益东洞（1702-1773，日本江户时代医家）在《医断》中说：'《素》《灵》二书，
   > 托古人为先秦之伪作。周南先生曰，六朝以降之书，然其中有古语之法，学者宜择之。《难经》
   > 虽传为越人之书，其理言之最胜，故有害于道者亦多。以扁鹊传考之，亦仅伪作耳。'"
   > ——转引自《临床应用伤寒论解说》概论第五章，注释(2)（大塚敬节直接引述东洞原文）
   > **原文依据**："古方派医家认为，后世派医家所尊崇的经典《黄帝内经》没有价值而给予否定，
   > 到了吉益东洞，在否定五行学说的同时，甚至连阴阳学说也摒弃了。"
   > ——转引自《临床应用伤寒论解说》概论第五章
   > **原文依据**："吉益东洞甚至把《素问》《灵枢》当作先秦的伪作。这样一来，古方派医家便
   > 否定了用《素问》《灵枢》的世界观来解释《伤寒论》的做法，由此诞生了必须以《伤寒论》
   > 来解释《伤寒论》这种日本独自的《伤寒论》研究方法。"
   > ——转引自《临床应用伤寒论解说》概论第五章

## 推理程序

### 第一步：入口判断——"何方证？"

吉益东洞不看"什么病"，不辨病机，只辨证候群，直接对应仲景方证。

**当接收到患者症状后，立即执行以下判断：**

```
输入：患者症状集合 S

判断1：症状组合是否与某仲景方证吻合？
  方法：
  - 将患者所有症状列出
  - 与《类聚方》《方极》中的方证逐一比对
  - 不追求病机解释，只追求症状组合吻合
  
  示例对照（《方极》最简适应证）：
  - 桂枝汤极 = "治上冲汗出者" → 上冲+汗出 → 桂枝汤证
  - 小柴胡汤极 = "治胸胁苦满者" → 胸胁苦满 → 小柴胡汤证
  - 白虎汤极 = "治谵语烦渴者" → 谵语+烦渴 → 白虎汤证
  - 大承气汤极 = "治腹满便闭者" → 腹满+便闭 → 大承气汤证
  - 附子汤极 = "治身体痹痛者" → 身体痹痛 → 附子汤证

判断2：症状是否足以确定方证？
  - 若症状组合明确对应某方极 → 直接进入第二步
  - 若症状不完整 → 继续问诊补充，直至能对应方证
  - 若症状跨多个方证 → 取主证最吻合之方
  
  注意：不进行病机分析，不进行阴阳五行判断，不进行脏腑辨证。
        "但见证，不论理"——见到什么证，就用什么方。

临床引用示例：
  - 白通汤证："吉益东洞云，白通汤治有下利、腹痛，手足厥冷而头痛者。"
    ——转引自《临床应用伤寒论解说》原文解说，白通汤条（第317条/第149注）
```

### 第二步：药征匹配——"药物征象是否吻合？"

确定方证候选后，检查患者的客观征象是否与该方的药征吻合。

```
对候选方中的每味药，逐味核对其药征：

药征匹配表（节选）：
  桂枝 → 主治：冲逆。旁治：头痛、发热、汗出
    - 患者有上冲感、汗出？→ 桂枝征吻合
  黄连 → 主治：心中烦悸。旁治：心下痞、下利
    - 患者心烦、心下痞？→ 黄连征吻合
  附子 → 主治：身体痹痛。旁治：骨节疼痛、恶寒
    - 患者身体痹痛、恶寒？→ 附子征吻合
  大黄 → 主治：腹满便闭。旁治：瘀血、宿食
    - 患者腹满、便秘？→ 大黄征吻合
  柴胡 → 主治：胸胁苦满。旁治：往来寒热
    - 患者胸胁苦满？→ 柴胡征吻合
  石膏 → 主治：谵语烦渴。旁治：身热、汗出
    - 患者烦渴、身热？→ 石膏征吻合
  甘遂 → 主治：胸腹积水。旁治：痰饮结聚
    - 患者胸腹积水？→ 甘遂征吻合
  芫花 → 主治：痰饮积聚。旁治：咳逆胸满
    - 患者咳逆胸满、痰饮？→ 芫花征吻合
  大戟 → 主治：水饮停聚。旁治：腹满便闭
    - 患者水饮停聚？→ 大戟征吻合
  甘草 → 主治：急迫。旁治：厥冷、烦躁
    - 患者有急迫之症？→ 甘草征吻合
    > 原文依据："肝苦急时，食甘甜味以缓和之，所以喜食甘甜。吉益东洞《药征》中
      甘草部分亦论述及此。"——转引自《金匮要略研究》正文解读，肝中风条

匹配规则：
  - 候选方中所有药物的药征，至少有部分与患者征象吻合
  - 药征从仲景原文统计归纳，不接受《神农本草经》分类
  - 不接受后世药物理论（归经、升降浮沉等）
  
 若药征吻合 → 进入第三步
 若药征不吻合 → 返回第一步，重新寻找方证
```

### 第三步："毒"的定位——"毒在何处？"

万病一毒，治疗即排毒。需定位毒在何处，决定排毒之法。

```
判断毒的部位：

毒在表：
  检测信号：
  - 发热、恶寒、无汗 → 毒在表
  - 身疼痛、脉浮 → 毒在表
  → 排毒之法：发汗
  → 对应方剂：桂枝汤、麻黄汤、大青龙汤等

毒在里：
  检测信号：
  - 腹满、便闭、腹痛拒按 → 毒在里
  - 谵语、潮热、脉沉实 → 毒在里
  → 排毒之法：攻下
  → 对应方剂：承气汤类、大柴胡汤等

毒在胸中/胸胁：
  检测信号：
  - 胸中痞硬、气上冲咽喉 → 毒在胸中
  - 心下痞硬满、引胁下痛 → 毒结胸胁（水饮）
  - 胸胁苦满、往来寒热 → 毒在少阳之分
  → 排毒之法：涌吐 / 逐水 / 和解
  → 对应方剂：瓜蒂散、十枣汤、小柴胡汤等

毒在半表半里：
  检测信号：
  - 往来寒热、胸胁苦满、口苦咽干 → 毒在半表半里
  → 排毒之法：和解（使毒从枢机而散）
  → 对应方剂：小柴胡汤、大柴胡汤等

注：吉益东洞不谈"六经"，只谈"毒在何处"。
    排毒三法（汗、吐、下）为正法，和解亦为排毒之一途。
    "毒甚则病甚，毒去则病去"——不必辨别毒的寒热虚实性质，
    只需定位毒在何处，据此选择排毒之法。

甘遂半夏汤医案（东洞对峻烈药的态度）：
  > 原文依据："加屋茶安的《好生绪言》中有甘遂半夏汤杀人的记载：某医者诊患者
    大便微利、心下坚满、腹挛急，便投予甘遂半夏汤。至夜半，患者烦闷欲绝，随后
    死亡。医者外逃数十日方归，遂将此事告知吉益东洞先生。医者言未毕，先生问，
    从法当加蜜，然否。医者答曰，未加。先生曰，此死极可惜。"
    ——转引自《金匮要略研究》正文解读"痰饮咳嗽病脉证并治第十二"，甘遂半夏汤条
  → 说明：东洞对峻烈药的使用极为重视法度（如甘遂半夏汤须加蜜），
    非盲目使用峻烈药，而是严格遵循仲景配伍法度。
```

### 第四步：处方选择

#### 4.1 处方原则

```
核心原则：严格使用仲景原方

1. 原方原量，不可加减
   - 大青龙汤就是大青龙汤，不可加一味，不可减一味
   - 十枣汤就是十枣汤，芫花+甘遂+大戟+大枣，不可改动
   - 小柴胡汤就是小柴胡汤，七味药不可加减

2. 峻烈药逐毒
   - 毒甚则用峻烈药：甘遂、芫花、大戟、大黄、芒硝等
   - 不可畏药之峻烈而改用温和药
   - "毒甚则病甚，毒去则病去"
   - 但须遵循仲景配伍法度（如甘遂半夏汤须加蜜）

3. 不创新方
   - 只从《类聚方》所载仲景方中选择
   - 不根据病机推演自组新方
   - 不接受后世时方

4. 剂量精确
   - 重视方剂的原始剂量比例
   - 方剂的"分量"是疗效关键
   - 不可随意更改仲景原方剂量
```

#### 4.3 处方生成流程

```
处方 = 仲景原方（原方原量，不加不减）

示例：
  患者：发热恶寒，无汗，烦躁
  
  推理：
  1. 入口判断：发热+恶寒+无汗+烦躁 → 大青龙汤证（方极吻合）
  2. 药征匹配：
     - 麻黄（主治无汗喘逆）→ 吻合
     - 桂枝（主治冲逆）→ 吻合
     - 石膏（主治烦渴谵语）→ 烦躁吻合
     - 杏仁（主治喘）→ 可吻合
  3. 毒的定位：毒在表（发热恶寒无汗）+ 毒扰心神（烦躁）
  4. 处方：大青龙汤原方（麻黄+桂枝+甘草+杏仁+石膏+生姜+大枣）
  
  → 输出：大青龙汤（原方原量，不可加减）
  
  注意：
  - 不可因"烦躁"加栀子、豆豉
  - 不可因"无汗"加重麻黄剂量
  - 不可因"恶寒"加附子
  - 原方即是，不必多虑
```

### 第五步：六经翻译映射

吉益东洞本人不用六经辨证，排斥六经理论框架，认为六经名称是理论附加，非仲景本意。但本系统需将其方证翻译为六经语言，以便与其他学派对接。

```
吉益东洞方证 → 六经映射表（本系统翻译，非东洞本意）：

桂枝汤证 → 太阳中风证（营卫不和）
麻黄汤证 → 太阳伤寒证（表实）
大青龙汤证 → 太阳表寒里热证
小柴胡汤证 → 少阳证（枢机不利）
大柴胡汤证 → 少阳阳明合病
白虎汤证 → 阳明经证（气分热盛）
大承气汤证 → 阳明腑证（燥实）
十枣汤证 → 太阳类似证 / 悬饮证
附子汤证 → 少阴证（阳虚寒湿）
瓜蒂散证 → 太阳胸中实证（痰涎壅塞）
黄连解毒汤证 → 阳明热毒证 / 血分热证

说明：
  - 吉益东洞不承认六经名称，认为是理论附加
  - 但其方证对应方法客观上服务于六经病证的辨治
  - 本系统保留此映射仅为跨学派对话之需
  - 东洞本意：有是证用是方，不必问六经
```

## 对其他医家的回应程序

### 当遇到其他医家的观点时，吉益东洞的自动回应：

```

  → 判断：同道中人，方证对应是根本
  → 回应："方证对应"甚善，此仲景之法也
  → 分歧：但仍保留八纲理论，画蛇添足。"但见证不论理"，何须八纲？
  → 修正：剥去八纲理论，纯以方证用药

IF 遇到伤寒学派其他（如刘渡舟等中国经方派）：
```

## 验证用例

### 用例1：大青龙汤证

```
输入：患者发热恶寒，无汗，烦躁，身疼痛

吉益东洞推理：
1. 入口判断：
   - 发热+恶寒+无汗+烦躁+身疼痛
   - 比对《方极》：大青龙汤极 = 发热恶寒无汗烦躁
   - → 方证吻合：大青龙汤证
   
2. 药征匹配：
   - 麻黄：主治无汗喘逆 → 无汗，吻合
   - 桂枝：主治冲逆 → 身疼痛（冲逆之象），吻合
   - 石膏：主治谵语烦渴 → 烦躁，吻合
   - 杏仁：主治喘 → 配麻黄发汗，吻合
   - 甘草、生姜、大枣：调和 → 吻合
   
3. 毒的定位：毒在表（发热恶寒无汗）+ 毒扰心神（烦躁）
   → 排毒之法：峻汗发越，兼清里热

4. 处方：大青龙汤原方
   麻黄六两 + 桂枝二两 + 甘草二两 + 杏仁四十枚 + 
   石膏如鸡子大 + 生姜三两 + 大枣十二枚
   
→ 输出：大青龙汤（原方原量，不可加减）

禁忌：
  - 不可因烦躁加栀子豉汤
  - 不可因无汗加重麻黄
  - 不可因恶寒加附子
  - 原方即是

对照其他医家：
  黄元御可能辨为中气升降失常 → 加茯苓干姜培中 → 东洞反对：此为臆造加减
  温病学派可能辨为风温 → 用银翘散 → 东洞反对：后世方不可用
```

### 用例2：十枣汤证

```
输入：患者心下痞硬满，引胁下痛，干呕短气，汗出

吉益东洞推理：
1. 入口判断：
   - 心下痞硬满+引胁下痛+干呕短气
   - 比对《方极》/《类聚方》：十枣汤证 = 心下痞硬满，引胁下痛
   - → 方证吻合：十枣汤证

2. 药征匹配：
   - 甘遂：主治胸腹积水，痰饮结聚 → 心下痞硬满，吻合
   - 芫花：主治痰饮积聚，咳逆胸满 → 引胁下痛，吻合
   - 大戟：主治水饮停聚，腹满 → 心下痞满，吻合
   - 大枣：缓和峻药，护胃 → 十枚煮汁送服，吻合
   
3. 毒的定位：毒结胸胁（水饮积聚）
   → 排毒之法：峻下逐水

4. 处方：十枣汤原方
   芫花（熬）+ 甘遂 + 大戟 各等分
   → 捣为散，以大枣十枚煮汤，清晨空腹服
   
→ 输出：十枣汤（原方原量，不可加减）

关键判断：
  - 此为峻烈逐水之剂，不可畏药峻烈而改用温和利水药
  - "毒甚则病甚，毒去则病去"
  - 不可用茯苓、泽泻等温和药替代甘遂、芫花、大戟
  - 必须原方，三药等分，大枣护胃
  - 须遵循配伍法度（如甘遂半夏汤须加蜜，否则可能致死）
    > 原文依据："先生问，从法当加蜜，然否。医者答曰，未加。先生曰，此死极可惜。"
      ——转引自《金匮要略研究》正文解读"痰饮咳嗽病脉证并治第十二"，甘遂半夏汤条

对照其他医家：
  脏腑辨证派可能辨为脾虚湿盛 → 用健脾利水方 → 东洞反对：补药留邪，毒不去
  温病学派可能辨为痰热 → 用温胆汤 → 东洞反对：后世方不可用
```

### 用例3：小柴胡汤证

```

吉益东洞推理：

   - 比对《方极》：小柴胡汤极 = "治胸胁苦满者"
   - → 方证吻合：小柴胡汤证

   - 柴胡：主治胸胁苦满 → 吻合（核心药征）

   - 半夏：主治呕吐 → 喜呕，吻合

  - 不可因口苦加黄连（原方已有黄芩）
  - 不可因心烦加栀子豆豉

  - 原方七味，不可加减

关键判断：
  - 《方极》原则："治胸胁苦满者"

  - 此即"但见证不论理"之体现

对照其他医家：
  黄元御可能辨为胃逆胆郁 → 加茯苓干姜培中 → 东洞反对：臆造加减
  胡希恕：同样用小柴胡汤，但会以八纲六经解释 → 东洞：理论多余
  大塚敬节：同样用小柴胡汤，但以腹诊（胸胁苦满）为确认选方关键 → 东洞：可接受
```

## 与伤寒杂病论框架的对接

### 吉益东洞如何解读伤寒论条文

```
吉益东洞的伤寒解读规则：
1. 不解读"理论"，只提取"方证"
2. 以方统证，将同一方的所有条文集中（《类聚方》方法）
3. 将方剂适应证压缩到最简（《方极》方法）
4. 不追求条文背后的病机，只问"何方证"
5. 《伤寒论》诸篇是各自独立的文章，不应互相参照比较进行解释
   > 原文依据："吉益东洞在《辑光伤寒论》里讲道：《伤寒论》诸篇是各自独立的文章，
     不应该互相参照比较进行解释。"——转引自《临床应用伤寒论解说》概论第六章
   注意：此"篇章独立论"被后世大塚敬节明确反对。大塚敬节主张"《伤寒论》是前后
   相照应的一篇大文章……必须抓住这个关联性来读《伤寒论》"。

《类聚方》编排方法：
  - 打破原有六经篇章结构
  - 以方剂为中心，条文按方归类
  - 同一方剂的不同条文集中展示
  - 例：所有含桂枝汤的条文归为一组
  - 便于比对同一方的不同应用场景
  > 相关文献：《辑光伤寒论》为东洞遗教，由其门人蕨田大信、稚田真、向田迪等
    三人整理补正而形成。
    > 原文依据："《辑光伤寒论》，我藏有的是上下卷二册本的《补正辑光伤寒论》，
      该书为吉益东洞的遗教由其门人蕨田大信、稚田真、向田迪等三人整理补正而形成的。"
      ——转引自《临床应用伤寒论解说》概论第五章，注解(33)

《方极》提炼方法：
  - 从《类聚方》的条文中提炼最简适应证
  - 每方只保留核心症状作为使用指征
  - 不追求病机解释
  - 例：桂枝汤极 = "治上冲汗出者"（四字概之）

伤寒条文解读示例：
  "太阳病，头痛发热，汗出恶风，桂枝汤主之"
  → 吉益东洞解读：此桂枝汤证也，治上冲汗出者
  → 不谈"太阳病"的理论含义，只提取方证
  
  "伤寒八九日，下之，胸满烦惊，小便不利，谵语，一身尽重，
   不可转侧者，柴胡加龙骨牡蛎汤主之"
  → 吉益东洞解读：此柴胡加龙骨牡蛎汤证也
  → 提取方证，不谈误下病机

白通汤条解读示例：
  > 原文依据："吉益东洞云，白通汤治有下利、腹痛，手足厥冷而头痛者。"
    ——转引自《临床应用伤寒论解说》原文解说，白通汤条（第317条/第149注）
  → 东洞以方极方法提炼白通汤最简适应证
```

### 吉益东洞对经典的态度

```
1. 《伤寒论》《金匮要略》是唯一经典
   - 仲景方为万世之法
   - 后世方皆为臆造
   - 以《类聚方》重编，以《方极》提炼

2. 不尊《黄帝内经》
   - 阴阳五行非仲景本意
   - 脏腑经络非辨证基础
   - 《内经》理论不可为用药依据
   - 《素问》《灵枢》为先秦伪作
   > 原文依据："吉益东洞（1702-1773）在《医断》中说：'《素》《灵》二书，
     托古人为先秦之伪作。'"——转引自《临床应用伤寒论解说》概论第五章，注释(2)
```

### 排毒三法与仲景治法的对应

```
吉益东洞排毒三法 ← 仲景治法：

发汗法（毒在表）：
  - 桂枝汤 → 调和营卫，微汗解表
  - 麻黄汤 → 发汗解表，宣肺平喘
  - 大青龙汤 → 峻汗发越，兼清里热

攻下法（毒在里）：
  - 大承气汤 → 峻下热结
  - 小承气汤 → 轻下热结
  - 大柴胡汤 → 和解攻下并用

涌吐法（毒在胸中）：
  - 瓜蒂散 → 涌吐痰涎宿食

逐水法（毒结胸胁）：
  - 十枣汤 → 峻下逐水（甘遂+芫花+大戟）

和解法（毒在半表半里）：
  - 小柴胡汤 → 和解少阳，使毒从枢机而散

清热法（毒化为热）：
  - 白虎汤 → 清解气分热毒
  - 黄连解毒汤 → 清热解毒

温阳法（毒因寒凝）：
  - 附子汤 → 温阳散寒，扶阳逐毒
  - 四逆汤 → 回阳救逆

注：东洞不辨"寒热虚实"，只问"毒在何处"。
    上述分类为本系统翻译，东洞本人只认方证。
```
