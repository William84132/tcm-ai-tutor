## 二、核心辨证方法

### 卫气营血辨证

叶天士创立了温病学的核心辨证体系——**卫气营血辨证**，将温病的传变过程分为四个层次：

1. **卫分证**：温邪犯表，肺卫失宣。症见发热、微恶风寒、头痛、咳嗽、口微渴
2. **气分证**：邪热入里，热盛津伤。症见高热、不恶寒、汗出、口渴、苔黄
3. **营分证**：热入营分，扰神窜络。症见身热夜甚、心烦不寐、斑疹隐隐、舌绛
4. **血分证**：热入血分，动血耗血。症见出血、斑疹透露、舌深绛、狂躁

### 传变规律

- **顺传**：卫→气→营→血，由表入里，由轻到重
- **逆传**：卫分直接传入心包（跳过气分），症见神昏谵语

### 六经翻译映射（本系统专用）

> 叶天士的卫气营血辨证在本系统中翻译为六经语言：

| 卫气营血层次 | 六经对应 | 理论依据 |
|:---|:---|:---|
| 卫分证 | 太阳病（温病型） | 温邪上受首先犯肺，肺主表属太阳 |
| 气分证 | 阳明病（经证/腑证） | 热盛阳明，正邪剧争 |
| 营分证 | 少阴病（热化证）+ 厥阴病（心包受邪） | 营属心，热入营分扰心神，少阴热化 |
| 血分证 | 厥阴病（血分）+ 少阴病（阴竭） | 血分动血，肝藏血主厥阴 |

## 三、医理体系

### 3.1 温邪上受，首先犯肺，逆传心包

这是叶天士对温病发病学的高度概括：
- **温邪上受**：温为阳邪，其性上升，从口鼻而入
- **首先犯肺**：肺主一身之表，温邪从呼吸道侵入，先犯肺卫
- **逆传心包**：若正气不足或邪气太盛，可不经气分，直接内陷心包

### 3.2 辨舌体系

叶天士极度重视舌诊，是其辨证的核心工具：

| 舌象 | 病理意义 | 治法提示 |
|:---|:---|:---|
| 白苔薄而干 | 温邪在卫，津液已伤 | 辛凉轻透 |
| 白苔厚而干 | 气分热盛，津液大伤 | 辛寒清气 |
| 黄苔 | 邪入气分 | 清气泄热 |
| 舌绛苔黄 | 营血热盛兼气分湿热 | 清营兼化湿，忌滋腻 |
| 舌绛无苔 | 热入营血，阴液已伤 | 清营透热，养阴生津 |
| 舌深绛 | 血分热盛，动血之兆 | 凉血散血 |
| 舌绛而干 | 阴液大伤 | 滋阴清热 |
| 舌绛而不鲜，干枯而痿 | 阴液枯竭，危候 | 急救阴液 |

### 3.3 "入营犹可透热转气"理论

叶天士提出："到气才可清气，入营犹可透热转气，入血就恐耗血动血，直须凉血散血。"

- **到气才可清气**：邪在卫分不可过早用清气药，恐冰伏邪气
- **入营犹可透热转气**：邪入营分，仍可透邪外出，从营转气而解
- **入血直须凉血散血**：邪入血分，已动血耗血，必须凉血止血兼散瘀

### 3.4 络病理论

叶天士发展了"久病入络"的理论：
- 初病在经，久病入络
- 络病当以虫类药搜剔、辛润通络
- 常用药物：旋覆花、新绛、当归须、桃仁、郁金等

## 四、用药偏好与常用药对

### 4.1 用药总体特征

- **轻清透邪**：用药轻灵，不喜重剂，尤擅花叶类药物
- **注重养阴**：温病易伤阴，全程注意护阴养阴
- **分经用药**：根据邪在卫气营血不同层次，用药有明确区分
- **顾护胃气**：苦寒药中常佐以护胃之品

### 4.2 常用药对

| 药对 | 功效 | 适用层次 | 识别要点 |
|:---|:---|:---|:---|
| 金银花-连翘 | 清热解毒透表 | 卫分/气分 | 温病初起最常用对药 |
| 桑叶-菊花 | 疏风清热明目 | 卫分 | 风温初起，咳嗽目赤 |
| 薄荷-牛蒡子 | 疏风散热利咽 | 卫分 | 咽喉肿痛明显 |
| 石膏-知母 | 清气泄热生津 | 气分（经证） | 高热汗出口渴 |
| 水牛角-生地 | 凉血解毒 | 营分/血分 | 替代犀角，舌绛斑疹 |
| 玄参-麦冬 | 滋阴清热 | 营分/气分 | 舌干绛，阴伤 |
| 丹皮-赤芍 | 凉血散血 | 血分 | 斑疹紫暗，出血 |
| 竹叶-滑石 | 清心利湿 | 气分湿热 | 小便不利，心烦 |
| 连翘-心（莲子心） | 清心热 | 营分 | 心烦不寐 |
| 银花-天花粉 | 清热生津 | 气分 | 口渴明显 |

### 4.3 用药禁忌

- 卫分证忌用苦寒（冰伏邪气）
- 营分证忌纯用滋腻养阴药（留邪）
- 舌绛苔黄者忌早用滋腻（留湿）
- 湿温病忌过用寒凉（伤阳助湿）

## 五、学术倾向与特色

### 5.1 核心学术标签

- **轻灵派**：用药轻清，不尚重剂
- **养阴派（温病型）**：全程注重护阴
- **舌诊宗师**：以舌辨卫气营血
- **络病先驱**：发展久病入络理论

### 5.2 与《伤寒论》的关系

叶天士对《伤寒论》的态度是**尊而不泥**：
- 认识到温病不同于伤寒，不能套用伤寒方
- 但在具体用药中常化裁经方（如白虎汤、炙甘草汤）
- 提出"温邪上受"有别于"寒邪伤阳"

### 5.3 创新贡献

1. 创立卫气营血辨证体系
2. 完善温病舌诊体系
3. 提出"透热转气"治法
4. 发展络病学说
5. 系统化温病病因病机理论

## 六、与其他医家的关系与差异

| 对比维度 | 叶天士 | 吴鞠通 | 王孟英 |
|:---|:---|:---|:---|
| 辨证体系 | 卫气营血辨证 | 三焦辨证 | 综合两家，以六经统摄 |
| 用药风格 | 轻灵透邪 | 创制新方较多 | 清热化湿见长 |
| 理论特色 | 重视舌诊 | 重视方剂创新 | 重视经典与临床结合 |
| 对湿温的态度 | 重视但非专攻 | 三焦分治湿温 | 尤擅湿热病 |
| 方剂倾向 | 化裁古方为主 | 创制银翘散、桑杏汤等新方 | 灵活化裁，不拘一格 |

### 与伤寒学派的关系

- 叶天士的卫气营血辨证与张仲景的六经辨证**互补而非对立**
- 叶天士在《临证指南医案》中大量化裁经方
- 在本系统中，卫气营血辨证被翻译为六经语言，实现统一

## 七、在本系统中的应用层级建议

### 精通层级（温病课程核心医家）

叶天士是温病课程的**核心医家之一**，建议作为精通对象：

- **要求**：掌握卫气营血辨证的完整体系、舌诊要点、常用药对及其组方逻辑
- **识别用户处方**：
  - 见金银花-连翘、桑叶-菊花、薄荷-牛蒡子等卫分药对 → 叶天士卫分思路
  - 见石膏-知母清气 → 叶天士气分思路（也可为伤寒阳明思路，需结合整体判断）
  - 见水牛角-生地-丹皮-赤芍 → 叶天士营血分思路
  - 见轻清花叶类药物为主、剂量偏轻 → 叶天士用药风格

### 与内经理论的关系

- "温邪上受首先犯肺"→ 内经"肺主一身之表""天气通于肺"
- 卫气营血传变 → 内经"卫气营血"的生理概念病理化
- 养阴思想 → 内经"阴平阳秘""壮火食气"
- 透热转气 → 内经"火郁发之"的温病应用
