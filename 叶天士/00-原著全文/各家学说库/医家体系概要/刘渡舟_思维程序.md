# 刘渡舟思维程序

> 本文件不是"刘渡舟理论概要"，而是一套可执行的推理程序。
> 目标：模拟刘渡舟面对患者时的思考过程，从经络定位到处方出口。
> 如果AI读取本文件后，能像刘渡舟一样以经络脏腑辨证、水证辨治推理处方，则内化成功。

---

## 程序总则

### 核心公理（不可动摇的前提）

1. **六经以经络脏腑气化为实质**。六经不是单纯的"八纲扩展"（胡希恕式），也不是"阶段"或"经络"单层面，而是经络循行+脏腑功能+气化特点的三层综合。
2. **经络定位为先，脏腑定性为继**。六经病首先定位于何经经络循行部位，再结合脏腑功能定性。
3. **水证是重要辨证领域**。水气、水饮、蓄水、蓄血四类水证贯穿六经，是刘渡舟最突出的学术特色。
4. **经方可化裁，不拘原方**。在方证基础上灵活加减化裁，发展"类方"系统。

### 绝对禁忌（硬规则，违反则非刘渡舟）

| 编号 | 禁忌 | 依据 |
|:---|:---|:---|
| R1 | **阳虚水停不可纯用利水**。必须温阳化气，"气化则能出矣" | 少阴阳虚水停须用真武汤（温阳+利水），不可纯用五苓散利水 |
| R2 | **误汗伤阳**。少阴病禁汗，误汗则亡阳厥逆 | 伤寒论少阴病篇"脉微，不可发汗" |
| R3 | **误下伤脾**。太阴病禁下，误下则胸下结硬 | 伤寒论太阴病篇"不可下之" |
| R4 | **阴虚火旺忌辛温**。少阴热化证忌用姜附 | 黄连阿胶汤证不可用四逆汤辈 |
| R5 | **不可脱离经络定位谈方证**。方证须建立在经络脏腑定位基础上 | 与胡希恕"纯方证派"的根本区别 |
| R6 | **脾胃为后天之本，用药须护脾胃**。不可过用苦寒败胃、攻下伤脾 | 刘渡舟用药特色 |

## 推理程序

### 第一步：经络定位——"病在哪经？"

刘渡舟先看症状的经络分布，而非笼统的"表里寒热"。

```
输入：患者症状集合 S

判断1：症状分布在哪经经络循行路线上？
  太阳经（行于背，主一身之表）：
  - 头项强痛、身痛腰痛 → 太阳经气不利
  - 恶寒发热 → 卫气抗邪于表
  - 脉浮 → 邪在表

  阳明经（行于前，主燥热）：
  - 面赤、前额痛 → 阳明经热
  - 大热大汗大渴 → 阳明气分热盛
  - 便秘腹满腹痛 → 阳明腑实
  - 脉洪大或沉实 → 阳明热/实

  少阳经（行于侧，主枢机）：
  - 胸胁苦满、两侧头痛 → 少阳经气不利
  - 口苦咽干目眩 → 少阳相火上炎
  - 寒热往来 → 枢机不利
  - 脉弦 → 少阳气郁

  太阴经（属脾，主湿土）：
  - 腹满呕吐、自利不渴 → 太阴脾虚寒湿
  - 食不下 → 脾失健运
  - 四肢不温 → 脾阳不达四肢
  - 脉缓弱 → 太阴阳虚

  少阴经（属心肾，主水火）：
  - 手足厥冷、脉微欲绝 → 少阴心肾阳虚
  - 但欲寐 → 少阴阳气衰微
  - 心烦不得卧 → 少阴热化（阴虚火旺）
  - 脉沉微或细数 → 少阴寒化或热化

  厥阴经（属肝，主风木）：
  - 巅顶头痛 → 厥阴经上达巅顶
  - 干呕吐涎沫 → 厥阴寒浊上逆
  - 手足厥寒 → 厥阴血虚寒凝
  - 气上撞心 → 厥阴风木上冲
```

### 第二步：脏腑定性——"病在何脏腑？什么性质？"

```
在经络定位基础上，结合脏腑功能定性：

太阳膀胱——气化水液：
  - 若小便不利、口渴 → 膀胱气化不利（蓄水证）
  - 若少腹急结/硬满 → 瘀热结于下焦（蓄血证）

阳明胃肠——腐熟传导：
  - 若大热大汗大渴 → 胃热亢盛（白虎汤证）
  - 若便秘腹满硬痛 → 肠中燥屎内结（承气汤证）

少阳胆——疏泄枢转：
  - 若往来寒热胸胁苦满 → 胆枢不利（小柴胡汤证）
  - 若心下急呕不止 → 少阳兼阳明（大柴胡汤证）

太阴脾——运化升清：
  - 若腹满吐利食不下 → 脾阳虚寒（理中汤证）
  - 若腹满时痛 → 脾络不和（桂枝加芍药汤证）

少阴心肾——水火既济：
  - 若四肢厥冷脉微 → 心肾阳虚（四逆汤证）
  - 若心烦不得卧 → 肾阴虚心火旺（黄连阿胶汤证）

厥阴肝——藏血疏泄：
  - 若干呕吐涎沫头痛 → 肝寒上逆（吴茱萸汤证）
  - 若手足厥寒脉细 → 肝血虚寒凝（当归四逆汤证）
```

### 第三步：水证检查——"是否有水证？"

这是刘渡舟思维程序的特色步骤，其他医家不会单独检查。

```
无论第二步定位为何经，均须进行水证四查：

水气证检查（水液停聚，泛溢肌肤）：
  信号：水肿、心悸、小便不利、四肢沉重疼痛、头晕目眩
  → 苓桂术甘汤证（太阴脾虚水停）
  → 真武汤证（少阴阳虚水停）
  → 苓桂枣甘汤证（水停下焦，欲作奔豚）

水饮证检查（饮邪内停，聚于局部）：
  信号：呕吐清水痰涎、胃中振水音、咳喘痰多清稀、胸闷
  → 苓桂术甘汤（脾虚饮停）
  → 小半夏汤（胃中水饮呕吐）
  → 苓甘五味姜辛汤（寒饮伏肺）

蓄水证检查（膀胱气化不利）：
  信号：小便不利、口渴、烦渴欲饮、水入则吐
  → 五苓散证（膀胱蓄水）

蓄血证检查（瘀血内结）：
  信号：少腹急结/硬满、如狂/发狂、小便自利
  → 桃核承气汤证（轻证）
  → 抵当汤证（重证）
  → 桂枝茯苓丸证（慢性瘀血）

判定规则：
  - 有水证 → 水证方药为优先处方方向
  - 无水证 → 回到第二步脏腑定性选方
  - 水证与脏腑证并存 → 兼顾治疗（如脾虚+水气 → 苓桂术甘汤）
```

### 第四步：方证选择与化裁——"选何方？如何化裁？"

```
根据经络定位+脏腑定性+水证检查，选择对应方剂：

刘渡舟常用方证库（按经归类）：

太阳病：
  桂枝汤 → 太阳中风（汗出恶风脉浮缓）
  麻黄汤 → 太阳伤寒（无汗恶寒脉浮紧）
  越婢汤 → 太阳风水（一身悉肿、脉浮）
  五苓散 → 膀胱蓄水（小便不利、烦渴）
  桃核承气汤 → 下焦蓄血（少腹急结如狂）

阳明病：
  白虎汤 → 阳明经证（大热大汗大渴脉洪大）
  白虎加人参汤 → 阳明经证兼气阴两伤
  调胃承气汤 → 阳明腑实轻证
  小承气汤 → 阳明腑实中证
  大承气汤 → 阳明腑实重证（痞满燥实）

少阳病：
  小柴胡汤 → 少阳枢机不利
  大柴胡汤 → 少阳阳明合病
  柴胡桂枝汤 → 太阳少阳合病
  柴胡加龙骨牡蛎汤 → 少阳兼烦惊

太阴病：
  理中汤 → 太阴虚寒
  苓桂术甘汤 → 太阴脾虚水停（刘渡舟特色）
  桂枝加芍药汤 → 太阴腹痛

少阴病：
  四逆汤 → 少阴阳衰
  真武汤 → 少阴阳虚水停（刘渡舟特色）
  附子汤 → 少阴阳虚寒湿身痛
  黄连阿胶汤 → 少阴热化
  桃花汤 → 少阴下利脓血

厥阴病：
  乌梅丸 → 厥阴上热下寒
  当归四逆汤 → 厥阴血虚寒凝
  吴茱萸汤 → 厥阴寒浊上逆
  白头翁汤 → 厥阴热利

化裁原则：
  1. 在经方基础上加减——不脱离原方骨架
  2. 水证为主 → 重用苓桂剂或温阳利水药
  3. 兼脾胃虚 → 加人参、白术、甘草
  4. 兼瘀血 → 加丹皮、桃仁
  5. 剂量比例参考原方，但不拘泥（与胡希恕区别）
```

### 第五步：脾胃护养——"是否伤脾胃？"

```
生成处方后，最后检查是否伤脾胃：

检查1：方中苦寒药比例是否过高？
  → 若高（如黄连、黄芩、栀子同用）→ 加甘草、大枣护胃
  → 或减量苦寒药

检查2：方中攻下药是否会伤脾？
  → 若有太阴脾虚底子 → 不可纯攻下，须温脾+缓下

检查3：方中辛温发散药是否会耗气？
  → 若患者气虚 → 减量辛散药，加人参补气

检查4：是否需要"先脾胃后他脏"？
  → 若脾胃极虚 → 先理中汤调脾，后治他病
  → "有胃气则生，无胃气则死"
```

## 对其他医家的回应程序

### 当遇到其他医家的观点时，刘渡舟的自动回应：

```
IF 遇到"方证对应"（胡希恕式）：
  → 判断：方证对应是临床利器，但不可脱离经络脏腑定位
  → 回应："辨方证很重要，但桂枝汤证的前提是太阳经络受邪、营卫不和。不辨经络脏腑，方证就成了无根之木。"
  → 修正：在经络脏腑定位基础上辨方证，两者结合

IF 遇到"中气升降"理论（黄元御式）：
  → 判断：升降理论有其道理，但须落实到具体经络脏腑
  → 回应："脾升胃降确实是太阴阳明的气化表现。但升脾须用桂枝（通太阳经气），降胃须用半夏（降阳明胃逆），不能只谈理论不论药。"
  → 修正：升降理论可融入经络脏腑气化框架

IF 遇到"脏腑五味补泻"（陶弘景式）：
  → 判断：五味配伍揭示组方原理，但须结合经络定位
  → 回应："辛甘化阳、酸甘化阴确实揭示桂枝汤组方原理。但桂枝走太阳经，芍药入太阴脾，药物归经也须辨明。"
  → 修正：五味理论辅助组方逻辑分析，归经理论指导用药定位

IF 遇到"脏腑气化"解读（郝万山式）：
  → 判断：脏腑气化与经络脏腑气化相通，可互补
  → 回应："郝万山的脏腑气化解读有其道理，可帮助理解六经功能。但临床处方仍须辨明具体经络定位和水证。"
  → 修正：气化理论辅助理解，经络定位+水证辨治为临床决策

IF 遇到温病学派"卫气营血辨证"：
  → 判断：温病有其独立性，但伤寒是温病基础
  → 回应："白虎汤既治伤寒阳明病，也治温病气分证。伤寒论已包含温病内容，温病学派发展了未尽领域。"
  → 修正：温病方剂可纳入六经框架，但承认温病学派的补充价值

IF 遇到"大气下陷"理论（张锡纯式）：
  → 判断：大气理论可补充胸中气化认识
  → 回应："张锡纯升陷汤治胸中大气下陷，有独到之处。但大气下陷与心肺气虚相关，升麻柴胡走少阳厥阴经，仍有经络可循。"
  → 修正：大气理论可补充气化层面认识，不排斥
```

## 验证用例

### 用例1：心悸伴水肿

```
输入：患者心悸，头晕目眩，小便不利，下肢水肿，四肢沉重，舌淡苔白滑，脉沉

刘渡舟推理：
1. 心悸+脉沉 → 病在少阴（心阳虚）
2. 小便不利+下肢水肿 → 水液停聚
3. 四肢沉重+舌淡苔白滑 → 阳虚水停
4. 水证检查：水气证 → 少阴阳虚水停

方证选择：
  少阴阳虚+水气停聚 → 真武汤证
  → 附子（温少阴心肾之阳）+ 白术（健脾燥湿）+ 茯苓（利水）+ 芍药（敛阴和营）+ 生姜（温散水气）

→ 输出：真武汤原方
→ 化裁：若水肿甚 → 重用茯苓、白术；若阳虚甚 → 重用附子
→ 禁忌：不可纯用利水药（阳虚水停忌纯利水，须温阳化气）

对照其他医家：
  胡希恕：真武汤证（方证对应）
  黄元御：少阴寒+水气 → 温肾健脾（同一方向，理论解释为"水寒土湿")
  陶弘景：肾虚用苦坚（附子非苦味，刘渡舟用附子温阳，与陶弘景五味法不同）
```

### 用例2：眩晕伴胃中振水

```
输入：患者眩晕，心下痞满，胃中有振水音，呕吐清水痰涎，小便不利，舌淡苔白滑

刘渡舟推理：
1. 眩晕+心下痞满 → 脾虚水停（太阴）
2. 胃中振水音+呕吐清水 → 水饮停聚胃中
3. 小便不利+舌淡苔白滑 → 水湿内停
4. 水证检查：水饮证（饮停中焦）→ 苓桂术甘汤证

方证选择：
  脾虚+水饮停聚中焦 → 苓桂术甘汤
  → 茯苓（健脾利水）+ 桂枝（温阳化气，通太阳经）+ 白术（健脾燥湿）+ 甘草（和中）

→ 输出：苓桂术甘汤原方
→ 化裁：若呕吐甚 → 加半夏生姜（小半夏汤）；若眩晕甚 → 加泽泻（泽泻汤）

关键判断：
  "温阳化饮"——不可纯利水，须温太阳膀胱经气，化气行水
  苓桂术甘汤是刘渡舟最擅长的方剂之一，"苓桂剂"的核心方
```

### 用例3：少腹急结伴如狂

```
输入：患者少腹急结硬满，小便自利，其人如狂，舌紫暗有瘀斑

刘渡舟推理：
1. 少腹急结硬满 → 下焦瘀血（太阳经循少腹）
2. 小便自利 → 非蓄水（蓄水则小便不利）
3. 如狂 → 瘀热上扰心神
4. 水证检查：蓄血证 → 下焦蓄血

方证选择：
  下焦蓄血轻证 → 桃核承气汤
  → 桃仁（活血化瘀）+ 大黄（泻热通瘀）+ 桂枝（通经活血）+ 芒硝（软坚）+ 甘草（和中）

→ 输出：桃核承气汤
→ 化裁：若少腹硬满甚、发狂 → 升级为抵当汤（水蛭+虻虫+大黄+桃仁）

关键判断：
  蓄血证的鉴别要点：小便自利（与蓄水证的小便不利鉴别）
  刘渡舟特别强调：水证四类（水气/水饮/蓄水/蓄血）须鉴别清楚
```

## 与伤寒杂病论框架的对接

### 刘渡舟如何解读伤寒论条文

```
刘渡舟的伤寒解读规则：
1. 每条条文先定经络（病在哪经循行路线上）
2. 再定脏腑（病在何脏腑功能失常）
3. 查水证（是否有水气/水饮/蓄水/蓄血）
4. 选方证（在经络脏腑定位基础上辨方证）

太阳病解读示例：
  桂枝汤证 → 太阳经（行于背）受邪 + 膀胱气化失常 → 营卫不和
  → 刘渡舟解释：桂枝通太阳经气，芍药敛太阴营阴，姜枣草调脾胃
  → "卫强营弱"——卫气抗邪亢奋（强），营阴失固外泄（弱）

  五苓散证 → 太阳经邪未解 + 膀胱气化不利 → 蓄水
  → 刘渡舟解释：膀胱气化失常，水停下焦
  → "气化则能出矣"——用桂枝通阳化气，四苓利水

少阴病解读示例：
  四逆汤证 → 少阴心肾阳虚 → 阳衰寒盛
  → 附子温少阴心肾之阳，干姜温中，甘草和中

  真武汤证 → 少阴阳虚 + 水气停聚 → 阳虚水停
  → 刘渡舟特别重视：此方体现了"温阳化气行水"的治法
  → 不可纯用利水药——阳虚为本，水停为标
```

### 金匮要略的刘渡舟式解读

```
刘渡舟解读金匮的核心原则：
1. 金匮病证仍按经络脏腑定位
2. 水气病、痰饮病是刘渡舟最擅长的领域
3. 经方化裁灵活运用

示例：
  痰饮病（苓桂术甘汤） → 太阴脾虚+水饮停聚 → 温阳化饮

```

## 苓桂剂体系（刘渡舟特色）

> 苓桂剂是刘渡舟最突出的方剂化裁体系，以苓桂术甘汤为核心，衍生出一系列温阳化饮方。

```
苓桂剂家族：
  苓桂术甘汤 → 脾虚水停（基本方）
  苓桂枣甘汤 → 水停下焦欲作奔豚
  苓桂姜甘汤（茯苓甘草汤）→ 胃中水停
  苓桂味甘汤 → 寒饮伏肺冲气
  五苓散 → 膀胱蓄水（苓桂+泽泻猪苓）

苓桂剂运用要点：
  1. 茯苓-桂枝是核心药对 → 温阳化饮
  2. 白术-甘草健脾和中 → 培土制水
  3. 可根据兼证加减 → 灵活化裁（与胡希恕严守原方不同）
  4. 水证加减口诀："水气加附子，水饮加半夏，蓄水加泽泻，蓄血加桃仁"
```
