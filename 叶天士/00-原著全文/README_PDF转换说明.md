# 医案PDF转TXT工具

## 使用说明

### 快速开始

1. **安装依赖库**
   ```
   python 安装依赖.py
   ```

   或者手动安装：
   ```
   pip install pymupdf
   ```

2. **运行转换工具**
   ```
   python pdf转txt工具.py
   ```

3. **输入目录**
   - 直接回车使用默认目录：`{仓库根}\叶天士\00-原著全文\医案类`
   - 或输入自定义目录路径

4. **等待转换完成**
   - 转换后的TXT文件将保存在同一目录
   - 每个PDF会生成一个同名但扩展名为.txt的文件

### 支持的文件

此工具可以处理以下医案PDF：
- 临证指南医案（叶天士）
- 吴鞠通医案
- 王孟英医案绎注
- 刘渡舟验案精选
- 经方实验录（曹颖甫）
- 胡希恕医论医案集粹

### 输出示例

转换后的TXT文件包含：
- 每页内容的清晰分隔
- 页码标注
- 完整的中医医案文本

### 技术细节

- 主要使用 PyMuPDF (fitz) 库
- 支持大文件批量处理
- 自动处理编码问题
- 保留原文格式

### 注意事项

1. **扫描版PDF**：如果PDF是扫描的图片而非文字，可能会转换失败或只能提取少量文字
2. **加密PDF**：需要密码的PDF无法直接转换
3. **复杂布局**：多栏布局或表格可能在转换时略有格式问题

### 故障排除

**问题：提示"未安装PDF处理库"**
```
解决：运行 python 安装依赖.py
```

**问题：转换失败**
```
可能原因：
1. PDF文件损坏 - 尝试用其他软件打开确认
2. PDF是扫描版 - 需要OCR工具识别
3. 文件权限问题 - 确保有读取和写入权限
```

**问题：中文显示乱码**
```
解决：已配置UTF-8编码，应该不会乱码。如果仍有问题请反馈。
```
