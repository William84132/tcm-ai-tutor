# 舌象图谱（金镜录木刻原图）

## 来源

本目录图片全部来自 **Wellcome Collection**（维基共享资源转载），为《敖氏伤寒金镜录》体系的木刻舌诊原图：

- 单舌图出自明嘉靖八年（1529 年）刊本《元敖氏伤寒金镜录》（原撰敖继翁[宋]，增订杜本[元]，续补薛己、马崇儒[明]）
- 多舌图谱（C14 系列）出自元至正元年（1341 年）《伤寒点点金书》抄本"验舌"部分

## 重要免责声明（强制）

**本图谱仅用于展示舌象形态（舌的色泽、苔色、厚薄、形态），图中古人文字介绍只作历史语境参考，不作为教学诊断依据。**

- 木刻原图上的文字为明代注解，反映当时认知，可能有误或与现代辨证体系不同
- 真实照片仅作直观形态展示，不附带诊断结论
- 教学诊断一律以《金镜录》正文条文（36 舌）+ 白话解/介按 + 经典基础病机体系为准

## 使用规范（诊疗基础 Skill）

- 舌诊教学时，优先引用本目录对应的金镜录木刻原图（教材原图）
- 讲解格式：金镜录原文 → 木刻原图展示 → 白话解/介按阐释 → 与现代舌象对照
- 本目录图片为古籍木刻风格，与现代彩色舌照不同，教学时说明"此为古代图谱"
- 现代舌象彩色示意：教学时由 AI 用 SVG 内嵌生成（舌色/苔色示意图）
