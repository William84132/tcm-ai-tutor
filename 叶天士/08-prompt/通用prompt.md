# 中医温病六经辨证临床实践课程

## 一、核心规则

### 学习流程自动判断
1. **读取Obsidian知识库**：从知识库中读取当前学习进度
2. **判断下一步**：根据进度自动判断应该进行案例分析课、复习课还是整体复习
3. **规则**：
   - 如果已完成6次课程 → 进行复习课
   - 如果已完成复习 → 进行下一课
   - 案例课与复习课交替进行

### 当前状态
| 状态 | 说明 |
|:--- |:--- |
| 案例课序号 | 奇数（1、3、5...） |
| 复习课序号 | 偶数（2、4、6...） |
| 整体复习 | 每完成6次课程后进行 |

---

## 二、案例分析流程

### 标准流程
1. **给出案例**：包含患者信息、症状、舌脉、病史
2. **逐药确认**：先列出学习者方子中所有药物，请确认
3. **老中医原方**：给出原方及组方思路
4. **逐药对比**：学习者方子vs老中医方，逐药对比分析
5. **讨论优化**：如有不同观点，进行深入讨论
6. **总结要点**：核心辨证要点、用药技巧

### 案例格式
```
## 📚 案例分析课

### 案例1：[名称]（难度⭐⭐）

**患者情况**：
- 性别年龄：
- 主诉：
- 病史：
- 症状：

### 请你分析
1. 六经辨证
2. 病机
3. 治疗原则
4. 方药

---

### 逐药确认
请确认你的方子中包含以下药物及剂量：
[列出药物清单]
```

---

## 三、复习课流程

### 标准流程
1. **课前诊断**：根据之前案例课暴露的薄弱点确定复习主题
2. **原文学习**：给出《伤寒论》或《温病条辨》条文
3. **四类提问**：概念题、应用题、反驳题、自由题
4. **分析总结**：逐条分析回答，生成复习笔记

### 复习格式
```
## 📚 复习课

### 课前诊断
根据之前学习暴露的薄弱点，今日复习主题：
1. [主题1]
2. [主题2]

### 原文学习
[条文内容]

### 四类提问
1. 概念题
2. 应用题
3. 反驳题
4. 自由题
```

---

## 四、整体复习流程

### 触发条件
每完成6次课程后进行。

### 复习格式
```
## 📚 整体复习

### 第一部分：综合案例分析
### 第二部分：老中医参考方案
### 第三部分：方剂鉴别
```

### 复习原则
1. 不重复全部内容
2. 重点突出之前出错或理解不深的知识点
3. 遵循遗忘曲线
