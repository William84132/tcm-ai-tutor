# 新建技能说明

> 本目录是"技能模具"：新建一个课程技能时，照本说明操作，即可生成一个结构合规、可发布、可被任何 harness 加载的技能。

## 新建步骤

1. **复制本目录**：把 `_新建技能模板/` 整个复制一份，改名为你的技能名（如 `针灸入门`）。
2. **改名**（改名后开始填写）：
   - `SKILL.md` 的 frontmatter：`name` 改成与目录名一致；`description` 写触发词（用户说什么话会调用本技能）+ 一句话功能描述。
   - 删除不需要的文件（如没有测试评估就删 `水平评估测试.md` 空模板）。
3. **填写 `SKILL.md`**：
   - 保留顶部"必读文件声明"（把笔记位置改成你的课程目录）。
   - 写规则总纲：核心原则、教学框架声明、知识库引用（相对路径 `../00-原著全文/...`）。
4. **填写 `课程流程.md`**：从"步骤0 意义锚点"到"课程结束微反馈"的每课执行规范（参考 `经典临床/课程流程.md` 的完整范例）。
5. **填写 `进度追踪.md`**：保留初始模板结构即可，开始学习后由 AI 逐课更新。
6. **登记**：在 `skills/说明.md` 的技能清单中加一行（技能名 / 触发词 / 课程目录位置）。
7. **发布检查**：运行 `python common/发布检查.py`，确认新技能无个人内容、无本机路径。

## 文件组成（与发布版的关系）

| 文件 | 用途 | 发布版 |
|:---|:---|:---|
| `SKILL.md` | 触发入口 + 规则总纲（所有 harness 都读它） | ✅ 发布 |
| `课程流程.md` | 每课执行规范 | ✅ 发布 |
| `水平评估测试.md` | 评估测试题库（可选） | ✅ 发布 |
| `进度追踪.md` | 学习进度（个人数据） | ⚠️ 只发初始模板 |
| `发布清单.md` | 本技能发布/不发布文件对照 | ✅ 发布 |
| 笔记/ 等个人目录 | 学习笔记 | ❌ 不发布 |

## 路径规则（隐私硬要求）

- 技能内所有路径一律**相对路径**，基座 = vault 根目录（`skills/` 与 `00-原著全文/` 同级）。
- **禁止出现本机绝对路径**（盘符反斜杠形式，如 盘符:\Users\...）——发布版会因此泄露个人信息，运行 `python common/发布检查.py` 可自动检出。
- 知识库引用格式：`../00-原著全文/伤寒论类/伤寒论_完整版.txt`
- 笔记目录引用格式：`../01-经典临床（正课）/`
