# 经典临床 · 七杠杆精装修机制（学习者主动性层）

> **【文件性质】** 本文件是《经典临床》Skill 的七杠杆精装修正式配套文件（2026年用户确认转正，上线运行，按用户反馈迭代），被 `SKILL.md` / `课程流程.md` 必读声明引用。
> **【理论依据】** 七杠杆认知生长方法论（问题锚定/知行迭代/思想凝固/安全撤退/碰撞过滤/纵向嵌入/切片爆破）+ 意义系统理论（公共机制第十四章）。七杠杆解决"学的主动性"，意义系统机制解决"教的确定性"，两者互补。
> **【定位铁律】** 本层任何机制不得削弱既有机制的收敛保证（矛盾点漏斗）、验证锁死（外化验证/处方验证关）、全量覆盖（按序排课/药池阶梯）。**冲突时既有机制优先。**

## 一、问题锚定（杠杆一）

**适用范围**：L2及以上条文学习课与案例分析课。L1不执行。

**流程**：
1. **位置**：每课第〇步（意义空缺）之前。
2. **提问**：AI问——"这节课开始前，你最近在临床上/读条文时，最想解决的一个具体困惑是什么？（可以答'没有'）"
3. **学生给出问题 → 质检**（三标准，不合格收敛一次）：
   - 可检验：问题能被本课材料回答（"我想学温病"太泛；"湿热并重时舌脉什么样"合格）
   - 有落差：已会一点但卡住（完全空白说明该走主线，不该锚定）
   - 指向明确：能翻译成阅读目标
4. **通过质检** → 用学生的问题作为本课矛盾点漏斗的"入口包装"——漏斗内容与收敛点不变，仅入口场景换成学生的问题。
5. **答"没有"或收敛失败** → 走默认意义空缺（既有流程），不纠缠、不追问。
6. **课末回填**：总结时AI问——"这节课解决了你清单上的哪一条？"回答记入"个人问题清单"。

**记录**：进度追踪新增"个人问题清单"表（模板见第十章）：问题 / 提出课次 / 关联知识点 / 解决状态 / 解决课次。与 subconscious 联动（可选）：event_type=note。

**纪律**：本环节提问遵守提示纪律（14.2）——问完即停，不自问自答；学生答"没有"即默认走系统空缺，不得诱导学生编造问题。

## 二、候选误差提交（杠杆二，修正版）

**适用范围**：仅L3/L4案例分析课（独立辨证之后、处方验证关之前）。

**流程**：
1. 学生独立辨证完成、给出方名后，AI问——"你这套判断里，最没底的两三处是什么？"（只圈范围，不要求自我否定）
2. 学生标注候选误差 → 系统**先**按处方验证关检验学生标注的候选误差，**再**补查未标出的漏网误差。
3. 验证结束，输出**两列对照**：
   - "你自己找出的"（学生候选误差中被证实/被推翻的各附证据）
   - "你没发现的"（漏网误差，中性呈现，进缺口驱动补讲）
4. **评价分层原则（本环节的判定基础）**：
   - 第一层·药证逻辑校验（客观层，跨学派共通）：组成→角色→药证映射→换药检验，检验的是"方子作为结构撑不撑得起学生自己认定的病机"，不检验任何一家的学说解释。校验最小单位是药对与配伍结构，禁止拆单味药孤立评判（core 10.5）。
   - 第二层·多学派视角层（差异层，不判对错）：差异不等于错误，差异是教学素材（core 10.3）。
   - 校验全程使用学生当前方法精通表所选体系的逻辑语言；跨体系差异处明确标注"此为体系差异，非对错"。

**禁止**：
- AI代替学生标注候选误差（学生不标则直接进入验证关，跳过两列对照）
- 把"你没发现的"当作批评（中性呈现，只作缺口驱动输入）

## 三、思想凝固（杠杆三）

1. **每周固化**：每周至少一次输出（笔记/复盘/语音均可），稳定性优先于精美。AI在综合复习课时检查近7天是否有固化输出，无则提醒一次（不强制）。
2. **单元回看**：综合复习课内嵌"回看10分钟"——从本单元笔记中挑1-2个"当时卡住/当时认为对"的点，问学生"现在怎么看"。
3. **季度回看课**：每季度一次（可挂L3/L4单元第7课预留位或学期末），流程：
   - AI读取该季度全部笔记，生成两份清单：①"当时认为对、现在需要修正的"；②"当时卡住、现在通了的"
   - 以"与三个月前的自己对话"形式逐条过（AI扮演过去的自己抛出原判断，学生回应）
   - 产出"季度修正清单"写入笔记——认知进化的化石记录
4. **边界**：季度回看不产生新知识点调度，不干扰间隔重复系统；回看课不计入主线课次。

## 四、战略性搁置（杠杆四）

1. **触发**：同一方证/鉴别点在复习或学习中反复卡壳≥3次（进度记录或 subconscious pattern 可查）。
2. **提议**：AI提议"此点先战略性搁置"，说明理由；学生同意才执行，学生拒绝则继续正常流程。
3. **执行边界（硬规则）**：
   - 只对"非本单元核心的鉴别点/拓展点"开放
   - 锚点方（本单元教学主角）与主线条文**禁止搁置**
   - 外化验证锁死不因搁置豁免——搁置点回访时仍须复述过关
   - 记录：搁置原因 + 回访日期（按间隔重复取下一到期点）+ 回访时须验证的旧判断
4. **回访**：到点自动回访；回访先做"撤出复盘"（我学到了什么/哪些判断是准的/哪些是歪的），再走正常复习。
5. **安全阀**：同时搁置≥3个点且均未回访时，系统提醒"搁置过多，建议回访或排查基础缺失"。

## 五、碰撞过滤（杠杆五）

1. **碰撞三记录（L2及以上必做）**：多学派分析（common 10.3 五步流程）完成后，追加一步（经典临床专属，叠加于 10.3 之后）：AI问——"刚才几家视角里：①哪个让你动摇了？②哪个你仍然坚持？③为什么？"学生回答记入"学派碰撞记录"表；学生不答视为放弃（不强求），连续3课不表态则提醒一次。
2. **学派辩论回合（仅L4）**：学生先给出方案与理由；AI轮流将方案放入学生指定的2-3家"长期对手"的思维程序文件（`医家体系概要/[医家名]_思维程序.md`）中运行，指出"哪里运行不通"；学生辩护，AI用该家逻辑反驳；结束输出"辩论结论"（哪些点成立/哪些点需修订）。
3. **长期对手**：首次进入L3/L4的学派偏好询问（课程流程2.2b）时，除"固定学派"外，可另选2-3家"长期对手"（碰撞对象不需要多，关键是认知差异足够大）。
4. **边界**：碰撞三记录不得替代多学派五步流程本身；"动摇/坚持"是学生主观表态，AI不得评判其正确性，只记录。

## 六、纵向嵌入（杠杆六）

1. **纵向谱系卡**：每个方证单元（综合复习课前）由AI生成谱系卡，格式：
   - 【源头】内经理论根基（检索黄帝内经类目录，标注出处）
   - 【经典出场】伤寒/金匮/温病条文位置
   - 【后世流变】该方证在金元明清各家的发展（从各家学说库检索，标注出处；检索不到则明确写"该家未论及此方"，禁止推演冒充文献）
   - 【现代临床问题】今天此证在临床的运用要点（标注"参考"性质，不越界）
   谱系卡写入单元综合复习笔记。
2. **谱系课**：单元综合复习课内嵌15-20分钟，过1-2张谱系卡，重点在"源→流→用"的纵向联系（与意义网络回顾的横向联系互补）。
3. **时代困境识别（L3/L4开放层）**：可加一问"这个证，仲景时代怎么认识？这个认识今天还够用吗？"——开放层内容，不做强制。
4. **边界**：谱系卡"后世流变"只引用各家学说库已有文献；检索不到明确写明，禁止编造。

## 七、问题驱动精读（杠杆七）

### 7.1 入口与准入

- **入口**：①漏斗第四层"开放层"作为可选项；②学派大厅"精读车间"；③学生主动表达（"我想带着问题读读某家"）。
- **准入三条件**：L2及以上；当前不在主线课时进行中（开放层或两课之间）；一次只带一个主问题。
- 一次精读会话限时20-30分钟，计时开始。

### 7.2 六阶段闭环

**阶段一 触发与准入**
- 学生主动发起，或系统提议（L3/L4某次辨证后："你刚才在X上卡了两回，要不要带这个问题去读3-5页相关医案？"）
- 确认主问题唯一性。

**阶段二 问题收敛（系统主导，关键步骤）**
- 三标准质检：可检验 / 有落差 / 指向明确（同杠杆一）
- 不合格收敛一次；收敛失败→建议回主线，不做强制。
- 示例："我想学温病"→"这个范围太大，切片读法装不下。缩到你能带进3-5页的尺寸——你最近具体在哪一步卡住了？"

**阶段三 定位材料（系统当图书馆员，学生保留跳转权）**
- 系统本地RAG检索，给出2-3个锚点候选，每个标注"对应你问题的哪个子问题"
- 学生二选一：接受锚点 / 自己跳转（只给一次跳转机会，防止漫游）

**阶段四 限页精读**
- 明确页数上限（3-5页，医案集按一案或两案计），读完即停
- 只提示阅读姿态（"带着问题读，其他先放过去"），不打断、不要求记笔记

**阶段五 行动映射（核心产出，强制）**
- 学生必须写出一句话：**"根据这几页，我接下来可以____"**
- 格式质检：必须是可执行动作，不是知识复述。不合格打回重写（最多一次示例引导）；仍不合格→记录"未产出行动映射"，不硬凑。
- 无收获分支：读了3-5页写不出行动映射→允许换锚点一次（"不是这本书不好，是它跟你的当前问题不匹配"）→重走阶段三-五；再失败→判定"问题与材料不匹配"，进入阶段六记录，不硬凑。

**阶段六 回流验证（闭环关键，缺失则整条链断裂）**
- 三处落账：①行动映射写入"个人问题清单"对应问题；②进度追踪"拓展精读记录"（问题/锚点/映射/有无收获/换书与否——只记录，不产生主线进度）；③挂间隔复习（1-3-7-14-30-60），到期AI把行动映射原样抛回问"用上了吗"。
- **现场验证**：后续主线课遇到同类证候时，AI先问"上次你从X案提炼的行动是什么？这次的医案里，你的行动灵不灵？"——行动映射从"纸上的一句话"变成"下一次辨证的预判"，接受现实检验。
- **季度合流**：三个月后精读记录进入季度回看课的"修正清单"。

### 7.3 硬边界（防滥用，必须划死）

1. 不产生主线进度、不进质检、不替代任何漏斗环节——精读是开放层的可选项，不是必修。
2. 主线条文禁止切片：398条、金匮22篇、温病条辨的顺序学习是"以经为纲"的承诺；切片只对拓展医案集（吴鞠通医案、王孟英医案、经方实验录等）开放。
3. 连续3次精读均"无收获"→系统建议回主线（提示基础缺失，该走全量覆盖）。
4. 精读医案不得虚构，来源标注同主线规则。
5. 与学派大厅分工：大厅是橱窗（看各家怎么分析一个方），精读是车间（带自己的问题钻进某家原文）；可互相跳转，不合并入口，防止把浏览当精读。

## 八、与既有机制的冲突自检表（新老规则兼容性裁定）

| # | 新机制 | 潜在冲突点 | 裁定 |
|:---:|:---|:---|:---|
| 1 | 问题锚定 vs 步骤0意义空缺 | 两个"开场"谁先谁后；学生问题带偏本课矛盾点 | 锚定在空缺**之前**；漏斗内容与收敛点不变，仅入口包装换场景；答"没有"走默认空缺 |
| 2 | 候选误差 vs 处方验证关 | 验证顺序被打乱；学生不标怎么办 | 候选误差**先于**验证关，不替代验证关；不标则直接进验证关、跳过两列对照 |
| 3 | 候选误差 vs 外化验证锁死 | 未过验证关是否放行 | 不放行：验证关照常执行，候选误差只是调整"先验谁"的顺序 |
| 4 | 战略性搁置 vs 外化验证锁死 | 搁置=逃避验证？ | 只对非核心鉴别点/拓展点开放；锚点方与主线条文禁止搁置；回访仍须复述过关 |
| 5 | 战略性搁置 vs 全量覆盖 | 搁置造成盲区 | 搁置有回访日期（间隔重复排程），不是放弃；≥3点未回访触发安全阀 |
| 6 | 碰撞三记录 vs 多学派五步流程（10.3） | 追加步骤是否越权修改公共机制 | 不修改10.3；作为经典临床专属追加环节叠加在10.3第五步之后 |
| 7 | 谱系卡 vs 内经溯源规范（引用不论证） | 后世流变编造风险 | 只引用各家学说库已有文献；检索不到明确写"未论及"；现代应用标"参考" |
| 8 | 问题驱动精读 vs 全量覆盖/药池阶梯 | 切片破坏按序学习 | 主线禁止切片，只对拓展医案集开放；不产生主线进度、不进质检 |
| 9 | 问题驱动精读 vs 医案分档A/B/C/D | 精读医案来源可靠性 | 精读医案仍走真实来源+出处标注，宁缺毋滥 |
| 10 | 新环节 vs 教学流程完整性清单（14.7） | 新环节漏执行 | 0.3新增检查点，课中标注【已做：X】，漏项自动补做（同14.7） |
| 11 | 新环节 vs 提示纪律（14.2） | 问题锚定/碰撞记录提问泄题或自问自答 | 提问遵守纪律：问完即停；不诱导学生编造问题；行动映射示例符合材料泄题禁令 |
| 12 | 新环节 vs 禁止虚假引用（14.5） | 碰撞记录/候选误差引用学生原话 | 记录学生真实原话，可回查；不把AI提示包装成学生产出 |
| 13 | 季度回看 vs 间隔重复系统 | 两套复习机制打架 | 间隔重复=横向到期复习（既有）；季度回看=纵向认知比对，不产生知识点调度 |
| 14 | 学派辩论 vs 方法精通表 | 辩论中换了体系语言 | 辩论用学生当前精通体系为主语言；各家思维程序为对照，标注体系归属 |
| 15 | 精装修 vs L1-L4分层表 | 跨层误执行 | 按0.2适用层级表严格执行；L1禁止杠杆一/二/五/七 |
