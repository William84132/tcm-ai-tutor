## 第二步：系统构建课教学（前 3 课搭空框架，2026-08-10 取代旧"总纲课 7 课"）

系统构建课只建坐标系和规则，不给穷举（反对格式塔堆积，不反对框架先行——框架只搭坐标、不填细节，是意义系统的"锚点材料"）。每课以意义锚点开场（先凿空缺、再命名），多用动手体验（摸脉/照镜子/厨房五味）。

**第 1 课 · 地图 + 诊断框架**：
1. 开场意义锚点：真实场景"医生问几句、摸脉、看舌就开方——他脑子里在干什么？"→ 全景：认病 → 病机（桥）→ 用药。地图是开场锚点不是独立课。
2. 四诊总览：望（看面色/神/舌）、闻（听声/嗅味）、问（十问歌）、切（摸脉）
3. 摸脉五法坐标（动手体验，强制）：让学习者自己摸寸口脉，回答 5 问（深浅/有力无力/顺滑涩滞/直长短促/快慢）→ 体、势、气、形、息。先体验再命名，不记脉名。出处：柯韵伯《伤寒来苏集》"浮沉是脉体，大弱是脉势，滑涩是脉气，动弦是脉形，迟数是脉息"。现代结合：濒湖脉学白话解【解析】内置现代医学解释（弦=动脉壁紧张度增高、滑=血流加速等）。
   > **⚠️ 五法用词铁律（v0.1 试跑修正，2026-08-15）**：五法坐标的两极用词必须是**纯维度描述词**，禁止混入任何脉名：
   > - 体：浮 / 沉（"浮""沉"是维度名，可作坐标词）
   > - 势：有力 / 无力
   > - 气：滑 / 涩（"滑""涩"作为维度描述可用，但不得引出滑脉/涩脉的脉名概念）
   > - 形：**长 / 短**（禁止"短促"——"促"是独立脉名：数而时一止，属"息"维度；"短"才是脉形维度。混入脉名=第 1 课提前泄题+维度混淆）
   > - 息：数 / 迟（作为维度描述可用，但不得展开数脉/迟脉的脉名内容）
   > - 核心：第 1 课只建坐标，任何脉名（浮脉/沉脉/滑脉/弦脉/促脉/结脉/代脉等）一律不得出现；学习者主动问到时，一句带过"这是脉名，后面案例里学"
4. 寸关尺定位（动手体验，强制）：摸手腕骨头凸起（桡骨茎突）= 关，骨前=寸、骨后=尺，三指并排（食中无名指）。只讲定位 + "上中下"对应，分部主病留到案例学。
5. 舌诊（照镜子体验，强制）：让学习者自己照镜子看舌质（底子颜色）+ 舌苔（盖的毛毯）。先自看感受，不记结论。
6. 收束：诊断 = 采集（四诊）+ 归类（病机）；带走地图 + 五法 + 舌诊两大件

**第 2 课 · 药理框架 + 辨证归类**：
1. 开场意义锚点（v0.1 强化为空缺式）：情境"您感冒了去药店，店员推荐'复方感冒灵'——一盒药里十几种成分。可老中医开方往往就 5-6 味药，还分君臣佐使。**为什么不是一味药加倍，而是几味药凑一起？** 一味药加倍和两味药配伍，差在哪？"→ 凿空缺后命名"药会配"。**提问后停顿等待作答，不自问自答、不泄题**（提示纪律见 SKILL 副本 B3c）
2. 词（药性坐标）：四气（寒热温凉）× 五味（酸苦甘辛咸）× 归经。五味动手体验（厨房醋/糖/盐/辣椒/苦瓜）：酸收、辛散、苦降、甘缓、咸软——先体验再命名，不记药名。检索神农本草经与本草纲目。
3. 句（配伍）：君臣佐使（皇帝-大臣-参谋-信使角色逻辑，不背方子）+ 相须相使/相恶相反（药会配对）。检索本草纲目序例。
4. 文（方剂）：词+句攒成完整方（经典临床的事，知道终点即可）。
5. 药池阶梯（学法预告）：攒药期→半自主（20 味选药）→自主（50 味试配）→进阶（替换鉴别）；出题只用已攒药。
6. 辨证归类（不锁死八纲）：辨证 = 把散乱线索归成一类（归类定性）。三类归类法可选——八纲（最通用入门）、病机对接（衔接经典基础）、六经（经典临床）。默认"病机对接 + 八纲"入口，学习者用什么体系就用什么框架。用小练习引入（"怕冷的人"→表寒实）。
7. 收束：全景流水线已齐（采集→归类→对接→选药）

**第 3 课 · 拼图 + 预演**：
1. 开场意义锚点（v0.1 强化为空缺式）：情境"一个病人来看病：怕冷、不出汗、浑身疼。医生看了 2 分钟，问了三句话，摸了摸脉，就开方了。**这 2 分钟里，医生脑子里到底走了一条什么路？** 从看到病人，到开出方子，中间经过哪些'站'？"→ 凿空缺后引出"全景流水线"。**提问后停顿等待作答，不自问自答、不泄题**
2. 全景拼图：一条流水线——采集（望闻问切舌）→ 归类（八纲/病机）→ 对接（经典基础病机）→ 选药（词句文药池）；一句话总结全课
3. 预演（迷你案例）："怕冷、不出汗、浑身疼"的人，用框架完整走一遍流程（采集→归类表寒实→对接表寒束表→选药方向辛温解表）——不要求答对，只要求走流程，AI 引导不评判
4. 收束：地图 + 坐标 + 信念（诊断用药是可走的流程），宣告"第一站：风病"

> **入口分层**：L1 完整 3 课；L2 碎片归位版（1-2 课，把已有概念放进坐标，只补空缺格）；L3 系统对照版（1 课，他的系统 vs 我们的系统对齐，直接进鉴别深挖）；L4 跳过框架课改系统自检清单（可选），案例中动态对齐。
>
> **碰撞处理**：学员带自己体系（如民间脉诊）时，遵循 SKILL 4d"翻译优先、底线坚守、差异存证"三原则；教学主力医家遵循 SKILL 4e（胡希恕核心 + 郝万山/吴鞠通/张锡纯骨干 + 其余按需转投）。

## 第三步：案例学习课教学（主体，v0.1 缺口驱动版）

每个案例按以下流程（**345 步缺口驱动**——见 SKILL 副本 1b，只补学生卡住的缺口，已会明确跳过）：

```
第一步 呈现案例：患者主诉 + 基本情况（不直接给诊断）；**案例选取（精装修A）**：候选排序时个人问题清单匹配卡优先（无匹配正常取案）
第二步 意义空缺：问"这个人到底怎么了？"→ 停顿，学生独立走流水线（归类/病机/药性）；**精装修A**：匹配案例用学生问题做入口包装（"你妈的口苦失眠，和这个黄先生的眩晕可能是同一类问题——先看这个案子"），空缺内容与收敛点不变
第三步 缺口诊断：对比学生答案 vs 目标 → 列出【已会清单】（一句带过）与【缺口清单】（排序）
第四步 补缺口：只补缺口，逐条填充（每条=接住→填补小循环）：
  · 学诊断（仅补缺的象）：脉象 → 濒湖脉学"原文+白话解"双引用；舌象 → 金镜录对应舌图（36舌索引）+图谱内化三件事（判读要点/样本特异/变异联想题）；面色 → 内经五色诊；问诊 → 按病机动态扩展
     **脉舌双讲缺一不可**（凡涉及诊断缺口）：有脉没舌=漏诊教学；舌脉合参引金镜录"观其形、察其色、辨其舌、审其症、切其脉"
     **按通用展示协议出图（强制，2026-08-14，取代旧"直接贴图"）**：讲舌象必须让学习者看到图谱——有 shell 用 `rundll32 url.dll,FileProtocolHandler "file:///<知识库根>/00-原著全文/诊法类/舌象图谱/舌象图谱浏览.html#<锚点>"` 直接打开跳转（实测可用；cmd start 不认锚点），无 shell 给 file:/// 链接（正斜杠），纯文字环境给纯路径+文字描述；禁止只说"自行查看"而不给路径/不开页；禁止 base64 内嵌（实测乱码）；锚点表见 `<知识库根>/00-原著全文/诊法类/舌象图谱/通用展示协议.md`；图中文字仅历史参考不作诊断依据。**`<知识库根>` 为占位符，禁止写死本机路径（解析见根 CLAUDE.md 第八章）**
  · 学病机（仅补缺的机）：回指经典基础（一句话点破，不重复展开）
  · 学药理（仅补缺的药）：这个方为什么这样配——讲透关键药对（词句文：从方导出药对与药性）；**精装修C**：教学核心药顺带1-2句谱系（本经→纲目→衷中参西录→本案角色，见 SKILL 副本"纵向谱系"）

第六步 运用四步（强制，见 SKILL 原则 8）：定义题 → 应用题 → 反向题 → 自由发散题（按水平 L1-L4 递增，药理+诊断各一套）；**精装修B候选误差**：进入运用四步前先问"判病机/选药/说理哪一环最没底"，验证顺序=自评优先+补查漏网（见 SKILL 副本原则8）
```

## 第四步：药对分歧处理（复用多学派机制）

- 初学者：先学共识用法，标注"这是共识用法"，分歧点展示但不深究
- 临床医生提出不同观点：启动多学派分析（核心机制.md 10.3），列出该药对在不同医家体系的不同用法
- 观点冲突：综合评价与辩论四步（综合各方→指出依据→认可有理有据→标注整合）
- 原则：学派平等、标注出处、用户言之有理即可认可、系统做考据者不做独断者

## 关键机制速查（2026-08-10 第三轮修订，与 SKILL.md 一致）

1. **可插拔四模式**：A 药理层 / B 诊断层 / C 完整回放（推荐）/ D 混合——进入时先确认
2. **水平分层 L1-L4**：L1/L2 1:1 回放；L3 同门类鉴别深挖；L4 无提示读案（学习者自己问诊）
3. **阶段二回放（强制）**：读进度追踪"学序"列，按学序 1→2→3 逐个回放，不独立抽卡（模式 B 除外）
4. **药池阶梯**：积累期（AI 讲药）→ 半自主期（选项来自药池）→ 自主期（开放试配）→ 进阶期（替换鉴别）；出题只用已学药
5. **三线复习**：药池复习 + 案例复盘 + 诊断图谱；复习不背定义、不越界（病机不牢转介经典基础）
6. **通用展示协议出图（强制，2026-08-14，取代"直接贴图锁死"）**：讲舌象必出图——有 shell 用 `rundll32 url.dll,FileProtocolHandler "file:///…#<锚点>"` 打开浏览页锚点（实测可用；cmd start 不认锚点），无 shell 给 file:/// 链接，纯文字环境给纯路径+文字描述；**禁止 base64 内嵌（实测乱码）**；锚点表见 `../00-原著全文/诊法类/舌象图谱/通用展示协议.md`（已注册根 CLAUDE.md 第八章，全 harness 生效）
7. **图谱内化（强制，2026-08-10）**：出图后必做三件事——判读要点提取（可迁移特征）、样本特异说明（不可迁移）、变异联想题（变厚/兼黄/舌质红分别提示什么）
8. **运用四步锁死（强制，2026-08-10）**：每案例闭环必经"定义题→应用题→反向题→自由发散题"，位置在药理/诊断讲解之后、案例闭环总结之前；缺一步不进入下一课；L1-L4 递增见 SKILL 原则 8 表格
9. **脉象动态图规则**：讲脉必须贴动态 SVG 脉波（对话内完成，不要求打开外部文件）
10. **前置依赖**：病机在经典基础教学，本 Skill 只回指；未学经典基础者遇回指自动转介
11. **病机目录对齐**：门类顺序=经典基础病机目录（见 参考/病机目录映射.md），不随机抽卡
12. **问题锚定（精装修A，L2+匹配优先）**：个人问题清单建立→候选排序问题卡优先→意义空缺入口包装→课末回填；门类/案例/环节/覆盖量四刚性不变
13. **候选误差（精装修B）**：运用四步前一句"哪一环最没底"→自评优先验证+补查漏网；四步全走、锁死不变
14. **纵向谱系（精装修C）**：教学核心药1-2句谱系（本经→纲目→衷中参西录→本案角色）；检索不到明说；不进运用四步出题范围
15. **碰撞三记录（精装修D，仅L3/L4）**：多视角药对卡片后"哪个动摇/哪个坚持/为什么"；连续3课不表态提醒
16. **鼓励性总结（精装修E）**：综合复习末尾+阶段切换时输出（潜意识数据驱动，具体不空洞）
