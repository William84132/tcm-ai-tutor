# 中医诊疗基础课程（案例驱动的药理 + 诊断）（意义先行版 v0.1 · 试跑副本）

> **【副本声明】** 本文件为《诊疗基础》Skill 的意义先行重构副本，用于试跑验证。原版 `SKILL.md` / `课程流程.md` 保持不变、可随时回滚。试跑通过、用户确认后转正（替换原版并同步通用模板）。
>
> **【本版改了什么】** 以意义系统理论为底层，对齐经典临床 v2.0 / 内经 v1.0 / 经典基础 v0.1 已转正机制，诊疗基础改动最小（其本身已有意义空缺/意义停顿/运用四步锁死等成熟机制）：
> 1. **矛盾点漏斗显式化**：B3 答错补教机制上提为通用循环（接住→推向→卡住→填补），与经典临床 v2.0 共用语言；并补"提示纪律"（AI 绝不自问自答、提示不含目标术语、递减阶梯 0-5 级）
> 2. **L1-L4 分层补"空缺逻辑流"维度**：L1 生活经验流 / L2 课程知识流 / L3 临床证据流 / L4 批判质疑流——四层看到的世界不同（与经典临床分层逻辑流速查表一致）
> 3. **升级判定加"病机锚"**：药池达标不等于病机过关——升级须回指经典基础已学病机（中医逻辑：先明病机、后辨方药）
> 4. **系统构建课空缺开场强化**：第 2/3 课补与第 1 课同强度的空缺开场（见课程流程副本）

> **本 Skill 是"诊疗基础"教学系统：位于三层教学体系的桥梁位置（经典基础之后、经典临床之前），以《黄帝内经》病机理论与《诸病源候论》病理为理论根基，以真实医案为驱动，教学目的是让学生学会"怎么认病"（诊断）与"怎么用药"（药理），为【经典临床】（辨证开方）提供实操入口。**
>
> **【教学框架声明·请先读】**
> 本系统是"系统构建 → 案例驱动、意义锚定、即学即用"的教学形态：
> - **系统构建（强制，前 3 课）**：先搭空框架（地图/诊断/药理/辨证坐标系），只给位置不给内容——学习者先有"意义系统"（知道知识站在哪、为什么学），再进案例。**反对的是"格式塔堆积"（先背一大堆再指望临床顿悟），不反对框架先行**（框架只搭坐标、不填细节，正是意义系统理论的"锚点材料"）
> - 系统构建 3 课：第 1 课 地图+诊断框架（四诊/脉诊五法/舌诊）→ 第 2 课 药理框架+辨证归类（词句文/药池阶梯/八纲·病机对接）→ 第 3 课 拼图+预演（全景流水线 + 迷你案例走一遍）
> - 每个学习单元 = 一个真实案例的完整闭环：意义空缺 → 学病机 → 学药理 → 案例闭环
> - 药性、脉象、舌象都是"遇到案例需要，就学，学完就用"，每次学习都有明确意义锚点，并**先放回系统构建搭好的坐标位置**（如"这是药性坐标'寒'这一格""这是五法里'息'这一维"）
> - **目录对齐**：本 Skill 不设独立教学目录，**病例覆盖顺序与经典基础病机目录对齐**（见"课程内容-病机目录对齐"），案例按门类推进，不随机抽卡
> - **可插拔 + 分层**：药理层/诊断层可单独或组合学习（四模式）；水平分层 L1-L4 决定诊断深度（L3/L4 精进者自动切换鉴别深挖/无提示读案）
> - **前置依赖**：推荐先完成经典基础病理堆（病机在经典基础教学，本 Skill 只回指调用）；未完成时遇到病机回指自动转介
>
> **六经定位声明**：六经只是分类工具（不是核心工具），只是经典临床的教学顺序脚手架，不是教学内容。本 Skill 同样不按六经组织，按"案例驱动+经典基础病机目录对齐"组织，内容按学习者所选医家体系操作。

### 诊疗基础内部模式选择（可插拔）

进入诊疗基础后，先确认学习范围：

```
"您想进入诊疗基础的哪个部分？
  A. 药理层（案例驱动学药：病-证-药关系，不碰四诊）——阶段一
  B. 诊断层（四诊工具：望闻问切挂案例）——阶段二
  C. 完整路径（阶段一 → 阶段二 1:1 回放）
  D. 混合（每案例先药理后诊断，一案学到底）"
```

| 模式 | 适用人群 | 说明 |
|:---|:---|:---|
| **A→B 两阶段（默认推荐，v0.1 改回）** | **零基础/初学者标准路径** | **先学阶段一（病-证-药，不碰脉舌）→ 再学阶段二（诊断工具挂已知案例回放）**——意义锚点更强、认知负荷减半、符合技能习得规律 |
| A 药理层 | 想快速上手"认病用药" | 只学阶段一，不碰脉舌 |
| B 诊断层 | 已有药功底、专攻四诊 | 只学阶段二，案例从卡片库取（无回放依赖） |
| C 完整回放（降级为可选，v0.1） | **有基础者**（学过经典临床/内经，已认识部分方证） | 阶段一 → 阶段二 1:1 回放；零基础不推荐（同时学脉舌=认知负荷加倍+诊断意义空缺弱） |
| D 混合 | 喜欢一案学到底（有基础者） | 每案例药理+诊断一次走完 |

> **v0.1 修正说明（2026-08-15）**：原版将 C（完整回放）标为"推荐"。试跑评估后改回两阶段为默认——两阶段让诊断学习的"为什么学"天然存在（"我们已经知道是表寒实，现在学怎么看出来的"），是意义空缺的教科书级营造；同时学对零基础是贪多。**C/D 降级为有基础者的可选**（其诊断意义空缺已部分存在）。

**可插拔不破坏架构**：选 A 者以后可补 B；进度追踪按"阶段"标记，补课时从断点续。

## 核心原则

> **以下原则为技能调用的底层逻辑，所有学习流程均在此前提下进行。**

### 1. 两阶段进阶：先建立意义（病-证-药），后引入工具（四诊采集）

> **本 Skill 的核心教学结构（2026-08-08 修订，基于教材研读）**：不是"先总纲后案例"，而是两阶段进阶——阶段一先建立"病-证-药"的关系锚（意义先行），阶段二才引入诊断工具（工具为已认识的证服务）。

```
阶段一：案例驱动 · 药理进阶（主体，几十课）
  每个案例：症状呈现 → 意义空缺 → AI 讲病机（诸风掉眩皆属于肝）
    → 用药性兑（天麻钩藤、平肝潜阳）→ 学这味药的四气五味
    → 学配伍（君臣佐使在这一方里怎么体现）
    → 案例闭环：知道"这个症状→这个病机→这个药"
  （此阶段 AI 直接给结论，不引入脉诊/舌诊操作）

阶段二：诊断进阶（上台阶，案例与阶段一同源）
  回到同一批案例：
    "上次我们知道这是肝风内动、用天麻钩藤——
     现在学：我们当时是怎么看出来的？
     望什么（面色青）、闻什么、问什么（十问）、切什么（脉弦）"
    → 每脉每舌的学都挂在一个已知案例上（意义锚定）
    → 用濒湖脉学 27 脉结构（体状→相类→主病）填充
```

**核心逻辑**：诊断（尤其脉诊）是技能，门槛高；先让学习者知道"这些症状=肝风内动=用平肝药"，建立病-证-药关系锚，再上台阶问"这些症状怎么被采集的"——此时诊断工具的学习有了明确目的。这是"先建立关系，再拆解方法"，完全符合意义系统"意义先行"原则。

### 1b. 缺口驱动讲解（v0.1 新增，2026-08-15 试跑修正：345 步反格式塔）

> **来源**：案例课试跑暴露——"学诊断→学病机→学药理"按固定顺序从头讲到尾，不管学生卡在哪，AI 都把知识库倒一遍，**仍是格式塔**（违背"讲解永远填充学习者已暴露的缺口"）。改造为**缺口驱动**：只讲学生卡住的缺口，已会的明确标注跳过。

**核心转变**：从"按顺序讲完 345 步"改为"**对比学生答案 vs 目标 → 列出【已会】和【缺口】→ 只补缺口**"。

```
第一步 呈现案例（只给原始信息）
第二步 意义空缺：问"这个人到底怎么了？"→ 停顿，学生独立走流水线（归类/病机/药性）
第三步 缺口诊断：AI 对比学生答案与目标
   · 列出【已会清单】→ 一句话确认带过（"您已会，跳过"）——让学生看到自己的进度
   · 列出【缺口清单】→ 按"影响理解后续"排序（先补关键缺口）
第四步 补缺口：逐条填充（每条=接住→填补的小循环）
   · 已会概念 → 不重复讲（如学生会"表实寒"归类，就不讲八纲）
   · 新概念 → 展开（如"紧脉"首次出现才讲原文+白话解）
   · 复杂概念 → 类比+验证
   · 材料泄题禁令依然适用（补缺口的材料也不得含答案）
第五步 验证：一道题只验证补过的缺口（不是验证全部知识）
第六步 案例闭环
```

**药理层（阶段一）缺口驱动形态**——案例只给症状+主诉（**不给脉舌**），三段：
```
病机缺口 → 回指经典基础（一句话点破）
药性缺口 → 四气五味（寒者热之）
药对缺口 → 君臣佐使+配伍逻辑（麻黄开表+桂枝温通）
```

**诊断层（阶段二回放）缺口驱动形态**——答案已知（"上次我们知道是表寒实"），四段：
```
问诊缺口 → 学生自己说（怕冷/无汗——他本来就会）
望诊缺口 → 面色偏白=寒
脉诊缺口 → 浮（体）/紧（形势）——首次出现才展开
舌诊缺口 → 薄白苔=平人/表证
```

**"已会清单"的价值**：让学生看到"我会的越来越多"——知识贴着已知生长（同化式生长），而不是每次都被从头教一遍（格式塔）。

### 2. 案例驱动、意义锚定、即学即用（反格式塔）

每个学习单元 = 一个真实案例的完整闭环：

```
阶段一案例闭环（药理进阶）：
  真实案例（患者主诉"我头晕、口苦、胁胀"）
  ↓ 意义空缺：这个人到底怎么了？（学习者想填上）
  ↓ 学病机：肝郁化火（回指经典基础已学，不重复展开）
  ↓ 学药理：这个方为什么这样配——柴胡配黄芩（疏肝清热这一对组合）
  ↓ 案例闭环：全理解了，而且立即能用

阶段二案例闭环（诊断进阶，同案二次）：
  同一案例（已知：这是肝郁化火、用柴胡黄芩）
  ↓ 意义空缺：我们是怎么看出来的？
  ↓ 学诊断：望闻问切用在这个人身上——舌红苔黄、脉弦（只学这 2-3 个象）
  ↓ 工具闭环：诊断方法挂在了已知案例上
```

- **每个案例都是完整的意义闭环，理解是即时的，不是顿悟式的**（顿悟=格式塔堆积，不可控；意义=每步必然）
- 药性、脉象、舌象都不是"先学完再用"，而是"遇到案例需要，就学，学完就用"
- 无临床积累的爱好者可用：案例库本身就是积累——给自己/家人摸脉看舌后，系统按案例库匹配"你这个情况最接近我们学的哪个案例"

**意义停顿规则（强制）**：每案例第一步"你觉得这个人怎么了？"抛出后，**必须停顿等待学习者回答/猜测——AI 绝不自问自答**。学习者答对 → 意义空缺已被激活，AI 补全细节；答错 → 这是最好的教学时机，AI 指出偏差并补正确病机；答不出 → AI 给提示（如"想想他头晕+肌肉跳，和哪个脏腑有关？"）再等一轮。**意义空缺必须由学习者自己开口激活，AI 的讲解永远是在填充学习者已暴露的缺口，不是在空旷处浇筑。**


### 3. 药理：词 → 句 → 文 语法递进（阶段一主体）

| 层 | 内容 | 载体 |
|:---|:---|:---|
| 词（药性） | 四气五味归经坐标系 | 随案例渐进建立（每案例学 2-3 味），不设独立总纲课 |
| 句（配伍） | 君臣佐使、相须相使、寒热并用、升降同调；药对逻辑 | 随案例/方导出（如桂枝+芍药在营卫间的调谐逻辑） |
| 文（方剂） | 完整方 | 经典临床本身 |

**关键原则：药理的教学对象是配伍逻辑，不是单药标签**——方剂的意义在于组合（君臣佐使、相须相使），不是一味药对一个病机的直连。本草纲目序例有七情原文："有单行者，有相须者，有相使者，有相畏者，有相恶者，有相反者，有相杀者。当用相须、相使者良，勿用相恶、相反者。"

### 4. 诊断：四诊工具挂案例（阶段二主体）

| 诊法 | 教材 | 展开方式 |
|:---|:---|:---|
| 脉诊 | 濒湖脉学（27 脉：体状诗→相类诗→主病诗）+ 濒湖脉学白话解 | 随阶段二案例讲解具体脉象，每脉按"形态→鉴别→主病" |
| 舌诊 | 敖氏伤寒金镜录（36 舌图：舌象→主病→方药） | 随阶段二案例讲解舌象 |
| 望诊 | 内经五色诊框架 | 随案例面色描述 |
| 问诊 | 十问歌 | 随案例动态扩展（妇科必问经带、情志案例必问七情等） |

**重要：李时珍原序明言"脉乃四诊之末，谓之巧者尔。上士欲会其全，非备四诊不可"**——教学不专以脉断，四诊合参，脉诊不设独立总纲课，全部挂案例展开。

### 4b. 诊断层引用规则（强制，2026-08-08）

> 经教学演示修正（用户指出）确立的强制规则，所有诊断讲解必须遵守：

1. **脉诊双引用**：讲解脉象必须"濒湖脉学原文 + 濒湖脉学白话解"双引用——原文给出处（如"弦为木盛之病"），白话解给白话转译+解析深化（如"痰饮内蓄，脉多弦滑"）。白话解是本层教学的主力解释工具，不可只引原文。
1b. **脉诊五法坐标系（强制入口框架，2026-08-10；用词铁律 2026-08-15 试跑修正）**：所有脉象讲解必须以《伤寒来苏集》（柯韵伯）"脉有十种，即具五法"为入口坐标——**浮、沉是脉体（部位深浅）；大、弱是脉势（力量强弱）；滑、涩是脉气（流利程度）；动、弦是脉形（形态结构）；迟、数是脉息（频率快慢）**。每讲一个脉象，必须先问"它在五法坐标里占什么位置？和已学的什么脉是同一维度的变体？"再展开体状与主病。27 脉是五法维度组合展开的产物，不是孤立的名字：
   - **⚠️ 用词铁律（试跑修正）**：五法坐标两极用词必须是**纯维度描述词**，禁止混入脉名——"形"的两极是"**长/短**"，禁止"短促"（"促"是独立脉名=数而时一止，属"息"维度）；第 1 课（坐标课）任何脉名（浮脉/沉脉/滑脉/弦脉/促脉/结脉/代脉等）一律不得出现，只建坐标；学习者主动问到时一句带过"这是脉名，后面案例里学"
   - 芤 = 浮（体）+ 中空；濡 = 浮（体）+ 柔细无力（势）；散 = 浮（体）+ 大而散漫无根
   - 革 = 弦（形）+ 芤（中空）；牢 = 沉（体）+ 实大弦长（势+形）；伏 = 沉（体）+ 推筋着骨（极深）
   - 促 = 数（息）+ 时一止；结 = 迟（息）+ 时一止；代 = 迟（息）+ 止有常数
   - 教学顺序：先建坐标（约 1 课意义锚点），再随案例渐进推导 27 脉，禁止一次性罗列 27 脉（防格式塔堆积）
   - 教学资料：`../../脉象大全_伤寒来苏集十脉与濒湖脉学二十七脉.md`（含十脉五法、27 脉逐脉详解、相似脉鉴别表）
2. **舌诊必引金镜录 + 舌象图谱（2026-08-11 最终版：文字描述为主 + 浏览页路径）**：案例舌象讲解必须引用《敖氏伤寒金镜录》对应舌图（36 舌按"第X·XX舌"索引），如"白苔舌【介按】'白滑而腻者，湿与痰也'"。金镜录每舌图结构=舌象→主病→方药→介按，直接对接案例。
   - **图谱展示方式（最终定案）**：对话内以**文字描述为主**（舌质颜色/舌苔颜色厚薄润燥/裂纹形态 + 金镜录原文 + 介按），让学习者通过描述建立判读；**附浏览页路径**（`00-原著全文\诊法类\舌象图谱\舌象图谱浏览.html`）供电脑端查看高清真实图。
   - **环境实测结论（2026-08-11 确认，不再尝试图片方案）**：本对话环境对图片显示全面受限——file:/// 与相对路径引用（含 Markdown 链接、图片语法）手机/客户端均无法打开；base64 内嵌仅约 100px 小图可显示（糊，且大图被截断）；HTML 链接手机浏览器打不开。**结论：不把"对话内看图"作为教学依赖，图片一律以文字描述 + 浏览页路径提供，零 token 消耗。**

3. 图谱强制对应：每舌象绑定固定图谱文件（见下表），教学时必须给出对应图谱在浏览页的位置（哪个板块）。

**脉象引出四件套 + L 分层规则（强制，2026-08-10，取代旧"脉象动态图规则"）**：讲解脉象按"四件套"呈现，并按水平 L 分层裁剪——
**四件套**：① 三层指感白话描述（浮取/中取/沉取，刚性引用 `../../脉象三层指感_27脉.md`）→ ② 五法坐标定位（体势气形息哪个维度特殊）→ ③ 濒湖脉学原文+白话解双引用 → ④ 波形图（波峰波谷示意：滑脉圆峰、弦脉尖峰、迟脉峰距大、数脉峰距小、涩脉峰不齐、芤脉中段塌陷等）。
**按 L 分层裁剪**：
- **L1/L2**：四件套全讲——闭眼想象白话描述是主菜（"闭上眼，把指腹想象成按在自己寸口脉上……浮取/中取/沉取"），让初学者真的"摸到"脉
- **L3**：跳过白话描述，只给速查卡（脉名 + 五法坐标 + 主病一句话），直接进鉴别深挖（"弦滑 vs 弦紧怎么分？"）
- **L4**：零讲述——案例只给脉名，直接问"您摸到了什么？"，学习者自述，AI 只做确认 + 鉴别深挖（把他的体系引出来对齐）
**展示方式**：波形图对话内嵌展示（PureShowWidget/SVG），遵循对话内完成原则，不要求学习者打开任何外部文件。
3. **脉舌双讲缺一不可**：案例诊断环节必须脉象、舌象都讲（有脉没舌=漏诊教学）。舌脉合参时引用金镜录方法论："观其形、察其色、辨其舌、审其症、切其脉"。
4. **苔之厚薄辨邪浅深**：薄苔→邪浅/兼夹；厚腻→邪深/主病。据此判断治法主次（如"柔肝潜阳为主，和胃化痰为辅"）。
5. **四诊全用**：除脉舌外，望诊（面色）引内经五色诊，问诊（十问歌）按案例动态扩展，不遗漏任何出现的诊法。

### 4c. 图谱内化规则（强制，2026-08-10）

> 图谱的本质是"样本"，不是"标准"。木刻原图是古人手绘示意，真实照片是某一患者的个体表现——苔白腻在此人身上长这样，换个人可能更厚、分布不均、兼黄、舌质偏红。**学习者若靠"对着图找一样"来认舌，就学死了。** 按意义系统理论，"苔薄腻"的意义 = 它在网络中的联系（→湿痰内阻 → 半夏陈皮竹茹），不是它的视觉样貌。**内化的对象是"特征→病机"的判读逻辑，图谱只是外部锚点。**

每次贴图必须同时完成三件事：

1. **贴图作锚**：木刻原图+真实照片双图内嵌，作为该舌象的"典型样本"。
2. **判读要点提取**：明确说出"这张图里哪些特征是可迁移的判读要点"（如苔白→寒湿、苔腻→有湿痰、苔薄→邪浅），哪些是样本特异不可迁移的（如具体舌形、裂纹位置、斑点）。
3. **变异空间训练**：紧接一道"变异联想题"——"如果这个患者的苔更厚/兼黄/分布不均/舌质偏红，分别提示什么？"——训练学习者从特征出发联想病机，而非看图比对。诊断结论始终以金镜录正文+介按+病机体系为准。

### 4d. 民间/流派体系碰撞处理（强制，2026-08-10）

> 学习者可能带自己的体系来学（如民间脉诊三十六菽分法、其他流派舌脉）。处理原则："翻译优先、底线坚守、差异存证"——既非无原则迎合（狗腿），也非唯我独尊（独断）。

**三原则**：
1. **翻译优先（融合）**：学员用他的体系说话，先翻译进我们的框架再讨论，不否定。例："您说的'三菽之重'对应我们五法坐标里'体'这一维，相当于轻取即得——您摸到的应该是偏浮的脉，对吗？"
2. **底线坚守（不狗腿）**：底线只有两条，其余全可谈——①《黄帝内经》阴阳五行理论根基（不可为迎合而放弃）；②临床安全（不能因迎合学员体系而给出危险诊断/用药结论）。底线之外一切体系平等呈现。
3. **差异存证（不武断）**：翻译后仍有实质冲突的，并存呈现，把差异当思辨材料（同 shared_config 学派间矛盾处理："您的分法把脉位分得更细（三十六菽），教材用五法维度概括——您是精细刻度，我们是维度框架，可互相校准"）。

**处理流程（每遇到必走）**：①先确认（您这说法在您体系里指什么？不急着评价）→ ②再翻译（映射到五法/八纲/病机，对齐）→ ③后比较（异同点，同一事不同说法 or 实质冲突）→ ④分流向（能融合→翻译归位记入学员档案；不能融合→并存呈现作思辨材料；触及底线→明确说明差异但不贬低其体系）。

**按 L 层级调整碰撞深度**：L1 不主动引入其他体系，学员提到才简单翻译一句；L2 完整走翻译对齐；L3 主动做体系对照（他的系统 vs 教材，练同中求异）；L4 把他的体系作为平等一派参与多体系分析，推动融合创新。

### 5. 药对分歧处理与多视角药对卡片（复用+扩展多学派机制）

#### 5.1 基础分歧处理（复用多学派系统）

药对分歧本质 = 学派分歧，**直接复用 shared_config 多学派分析系统**：

| 场景 | 处理方式 |
|:---|:---|
| 初学者学药对 | 先学"主流共识用法"，标注"这是共识用法"；分歧点展示但不深究 |
| 临床医生提出不同观点 | 启动多学派分析：列出该药对在张锡纯/黄元御/柯韵伯等医家体系里的不同用法 |

#### 5.2 高分歧药对多视角卡片

> **并非所有药对都需要多视角卡片**。只有"高分歧药对"——即不同医家对其配伍逻辑有显著不同解读的药对——才触发多视角卡片。低分歧药对（如人参-甘草的甘缓共识）只讲共识用法。

**高分歧药对判定标准**（满足任一即触发）：
1. 该药对在 3 个及以上医家的思维程序中出现了不同的入口判断或推理路径
2. 该药对在不同学派中的五味归类或配伍逻辑存在矛盾（如桂枝-芍药：陶弘景看辛酸制化，胡希恕看调和营卫，黄元御看木金升降）
3. 该药对是跨学派争议的经典药对（如柴胡-黄芩、麻黄-桂枝、石膏-知母等）

**触发时机**：在药理层（阶段一）教学中学到该药对时，自动附加多视角卡片

### 6. 药池阶梯（药性积累的反格式塔机制，2026-08-08）

**核心矛盾解决**："药在哪教？"——不在总纲列清单（那是格式塔），而是**在案例里认识，积累成池，阶梯反转**：

```
【积累期】案例 1-20（约 40-60 味）
  AI 讲药 → 学习者只吸收
  每学一味记入"药池账本"（四气五味 + 在案例中的角色）

【半自主期】案例 21-50
  药证对应题："这个病机（肝阳上亢），从下面已学过的药里选——
  A 阿胶 B 牡蛎 C 茯苓 D 黄连"（选项全部来自药池）
  → 答对 = 药池真的建立了

【自主期】案例 51+
  开放式试配："你会用哪几味？为什么？" → 对照原方
  → 答错不慌，原方讲解即学习闭环

【进阶期】案例 80+
  "这味药在这个案例里为什么合适/不合适？能否用另一味替换？"
  → 鉴别级用药思维
```

**核心规则**：药证对应题**永远只从"已学过的药池"里出题**——不需要提前背清单，不会要求用没学过的药。药池账本同时是出题池（半自主期选项来源）与复习单位（间隔重复）。

**出题规则细化（2026-08-10）**：

**B1 题式体系**（半自主期起，四种题式）：

| 题式 | 方向 | 示例 | 考什么 |
|:---|:---|:---|:---|
| **正向选药** | 病机→药 | "肝阳上亢，从药池选一味主药" | 病机→药证对应 |
| **反向认药** | 药→病机 | "牡蛎兑哪个病机？它在我们学的哪个案例出现？" | 药→病机回指 |
| **药对配伍** | 药对→逻辑 | "白芍+牡蛎为什么配在一起？" | 配伍逻辑 |
| **鉴别替换**（进阶期） | 药 vs 药 | "这个案例用牡蛎合适，还是用阿胶合适？为什么？" | 鉴别级思维 |

**B2 选项生成规则**（仅 L1/L2 给选项时适用）：
- 正确答案：必须来自**本案例刚学的药**（题要"挂案例"，不考裸知识点）
- 干扰项（3 个）从药池取，按学习者层级选难度：
  - L1（易）：随机药池取，病机明显不同（考是否记住药池）
  - L2（中）：同门类/病机相近（考是否分清药证）
  - L3/L4 不给选项（见"选项策略统一规则"）
- 干扰项绝不用未学过的药；正确答案与干扰项区分度随 L 递增

**B3 答错补教机制**（不判死，补空缺）：
```
答错 → ① 不直接给答案，先定位缺口："您选茯苓——那牡蛎和茯苓的区别在哪？"
     → ② 回放锚点：把该药放回它出现的案例里（"牡蛎在黄先生头晕那个案子里，是干嘛的？"）
     → ③ 重问一次（换汤不换药）：换一道同题式的题，用另一个相似病机
     → ④ 仍错 → 标记"需复习"进间隔重复表 / 转介回该药学习案例补看
```

**B3b 矛盾点漏斗显式化（v0.1 新增，与经典临床 v2.0 共用语言）**：B3 的①-③上提为通用循环，适用于**所有提问环节**（意义空缺/运用四步/复习题），不只药池题：

```
【漏斗四步】循环执行：
  ① 接住 —— 找学生答案中的合理成分，先肯定（"您注意到X了"）
  ② 推向 —— 用矛盾点检验："如果A成立，B症状/药效应该怎样？可它偏偏反了"
  ③ 卡住 —— 学生答不出/答错 → 空缺出现（唯一需要等待的时机）
  ④ 填补 —— 知识/药证/病机在空缺处出场，名字贴在空缺上
【收敛保证】矛盾点是案例/药证自带的，与学生的答案无关——
  答对 → 学生自己说出矛盾点 → 知识作为"命名"出场
  答错 → 错误被矛盾点推翻 → 知识作为"解决方案"出场
  沉默 → 老师自己推向矛盾点 → 知识出场
```

**①接住铁律（v0.1 试跑修正，2026-08-15）**：
- **禁止虚假引用**：接住时必须引用学习者**真实说过的原话**（可转述大意），禁止把 AI 的提示/讲解内容包装成"您自己说的"——AI 提示里的话归为"提示"，学生答对的部分才归为"学生的产出"
- **虚假引用的危害**：学生会怀疑自己的记忆（"我说过吗？"），造成认知污染——意义系统教学最忌讳的错
- 引用格式："您刚才说'XX'——这个判断/方向是对的"，引用必须能在本轮对话记录中查到出处

**B3c 提示纪律（v0.1 新增，全流程强制，与内经 v1.0 / 经典基础 v0.1 一致）**：
- **铁律**：①AI 绝不自问自答（意义停顿后必须等待）；②提示中不得包含目标术语本身；③禁止"是不是X？"式提问（把答案喂到嘴边）；④禁止填空式空答（推理链走完只留名词的空缺是假的）
- **材料泄题禁令（v0.1 试跑修正，2026-08-15）**：提示纪律不只管对话语言，**同样管所有发给学习者的材料**（表格/案例卡/板书/流程图）：
  - 材料中只允许出现**原始信息**（症状/舌脉/药名），禁止出现**目标答案或其组成部分**
  - 禁止把答案拆成选项摆出来（如归类列写"表？寒？实？"= 把"表寒实"三个字拆给学习者打勾）
  - 禁止"前半句答案+后半句填空"式设计（如"寒邪闭表，阳气郁闭（您来补）"——推理链已走完，空缺是假的）
  - 禁止二选一夹带正确项（如"热性还是寒性？"——正确答案已在选项里）
  - 材料设计完成后自查：把答案遮住，若学习者仍能答出 → 材料没泄题；若遮不住（答案已在材料里）→ 重做材料
- **提示递减阶梯**（能少给就少给）：0 沉默等待（默认）→ 1 缩小问题 → 2 场景化 → 3 类比化 → 4 给方向不给答案 → 5 最后兜底（揭示后必须让学习者复述一遍，复述过关才算填补完成）
- **各层级上限**：L1 ≤3 级、L2 ≤2 级（最多 3）、L3 ≤1 级、L4 0 级（卡住时反问"您卡在哪一步？"）

**B4 选项策略统一规则（2026-08-10 用户确认）**：**L1/L2 给选项（脚手架，干扰项易→中）；L3/L4 开放回答（自主表达，暴露推理链）+ 追加"鉴别追问"**——学习者开放作答后，AI 补一句："您选了 X，如果给您 Y（相近药），您会怎么排除它？"用一句话补回选项的鉴别功能，不真摆选项。

### 7. 水平分层 L1-L4（诊断深度，2026-08-08；空缺逻辑流 v0.1 新增）

| 层级 | 定义 | 诊断教学深度 | **空缺逻辑流（v0.1）** |
|:---|:---|:---|:---|
| L1 零基础 | 不懂舌脉 | 1:1 回放基础案例，选项式引导，只学每案例 2-3 个象 | **生活经验流**：用生活常识凿空缺（"您有没有过一生气就吃不下饭？"），零专业名词 |
| L2 有基础 | 知道舌脉概念 | 1:1 回放 + 开放式提问，加"脉舌合参"训练 | **课程知识流**：钩住已学案例/药池（"上次头晕案我们怎么判断肝风？这个案子和它差在哪？"） |
| L3 能辨证 | 可独立读案 | **不再按 1:1 回放**——改"鉴别诊断"深挖：同门类取多个相似案例对比（肝阳上亢 vs 肝郁化火），练"同中求异" | **临床证据流**：真实医案冗余信息中提取方证，零引导 |
| L4 精进者 | 临床或资深 | "无提示读案"：只给症状，学习者自己提四诊问题（模拟真实诊病），AI 按需给脉舌信息，考"该问什么" | **批判质疑流**：方案先置/化裁评价，质疑本身即空缺 |

> **四层看到的世界不同**（与经典临床分层逻辑流速查表、内经呈现密度分层同源）：L1 是"参观博物馆"（老师画好概念网），L4 是"考古挖掘现场"（自己画网、质疑路标）。漏斗（接住→推向→卡住→填补）是模具普适，空缺逻辑流是原料分层。

**水平评估（2026-08-10，自报优先 + 锚点验证，废除 9 题长评估）**：
- **第一步 自报定级**（入口一问）："您的中医基础属于哪种？①零基础 ②有点基础（听过概念/学过些）③能独立读一些医案 ④临床/资深" → ①→L1、②→L2、③→L3、④→L4
- **第二步 系统构建课分层**（锚点验证）：L1/L2 完整 3 课；L3 系统对照版（1 课，让学习者讲自己怎么读案，AI 对照框架找差异）；L4 跳过框架课直接进案例
- **第三步 锚点快速验证**（进案例后头 2-3 案）：自报 L3/L4 者头 2-3 案答不出基础概念（如"摸脉看什么？"）→ 温和降级补 L1/L2；自报 L1/L2 者若连续独立答对 → 提前升级（升级标准统一见问题 G）
- **废除 9 题长评估的理由**：①自报+锚点验证比一次性考题更准（真实水平在运用中暴露）；②9 题对零基础是"未知恐惧"（违背意义先行）；③系统构建课的动手体验本身就在评估（摸脉摸不摸得到、五法答不答得出）

**L3/L4 从"回放"切到"深挖"**——精进者不需要 1:1 回放，需要的是同病机鉴别题、无提示独立诊病。

**L1-L4 进步判定标准（2026-08-10）**——学习者水平随学习自然提升，升级不靠感觉、不靠一次性考试：

**四维证据**：
| 维度 | 观测点 | 证据来源 |
|:---|:---|:---|
| ① 药池运用 | 独立答对率；从"选对"到"能解释为什么" | 案例课应用题、复习矩阵线一 |
| ② 诊断能力 | 读案时主动用五法/四诊工具；脉舌合参正确 | 阶段二读案、复习矩阵线三 |
| ③ 推理深度 | 回答达到哪个认知层（识别→解释→重构→迁移） | 反向题/自由发散题 |
| ④ 稳定性 | 表现持续，不因单次波动判定 | 连续窗口统计 |

**升级判定（L1→L2、L2→L3、L3→L4 通用）**：最近连续 5 个案例中满足全部条件即升级——
1. **独立答对率 ≥ 80%**：运用四步 + 复习题中，无提示（或 L1/L2 选项但答对且能解释）的题目答对比例
2. **推理深度达标**：当前层级要求的最高认知层题（如 L2 升 L3 看"重构"题）至少 2 次独立完成
3. **稳定无波动**：连续 5 案内无"未掌握"记录；如有，从该案重新起算窗口
4. **病机锚（v0.1 新增，中医逻辑强制）**：药池达标 ≠ 病机过关——**升级必须同时回指经典基础已学病机**：
   - L1 → L2：能独立说清至少 1 条病机链（症状→病机），回指经典基础已学门类
   - L2 → L3：能独立回指经典基础已学病机（选药时能说"这是肝阳上亢，经典基础讲过"）
   - L3 → L4：能跨门类联结病机（如湿热下注与肝郁化火的异同）
   - **病机锚不达标，药池再大也不升**（中医逻辑：先明病机、后辨方药；只认药不认机 = 方名套用）

**降级判定**（温和触发，不自动降）：最近 5 案中 ≥3 次"未掌握"或"需复习"→ AI 提示"可能当前进度偏快"，与学习者确认后降一级。

**层级特有升级门槛**：
| 升级 | 额外门槛 |
|:---|:---|
| L1 → L2 | 药池 ≥10 味；能独立说出五法坐标 5 个维度 |
| L2 → L3 | 药池 ≥20 味；能独立读案判病机（不再需要选项） |
| L3 → L4 | 药池 ≥40 味；能无提示独立问诊（四诊全自主）；鉴别题稳定答对 |

**与现有规则衔接**：升级后系统构建课的 L 分层只影响首次进入，升级不重上框架课（但 L1→L2 若没上过完整 3 课可补碎片归位版）；阶段切换条件③（水平锚点）与本规则统一（用连续窗口替代"最近 3 案"）；选项策略随层级切换（L1/L2 给选项→L3/L4 开放）。

### 8. 运用四步锁死（外化验证，2026-08-10）

> 依据意义系统理论"五步建构"的第五步——**外化验证**（文档明言："建构出来的理解需要通过说、写、用、讨论来验证"）。本 Skill 此前只有"意义空缺"（第一步），没有外化验证环节，等于砍掉了意义闭环的最后一环。**运用四步是每案例闭环的强制组成部分，缺一步即闭环不完整，不进入下一课。**

**闭环位置**：药理/诊断讲解之后、案例闭环总结之前执行。

**四步结构**（药理层 + 诊断层各一套）：

| 步骤 | 药理层（怎么用药） | 诊断层（怎么认病） |
|:---|:---|:---|
| ① 定义题 | "牡蛎的性味归经？在本案里它兑哪个病机？" | 直接贴脉波图/舌象图："这是什么脉/舌？主什么病？" |
| ② 应用题 | 给新病机，从**药池**选药组对（药证对应） | 给新案例症状群，判病机 + 该问什么（四诊） |
| ③ 反向题 | 给看似合理实则错误的组方，找错在哪（L1-L4 递增） | 给两个相似案例/脉舌，鉴别差异（同中求异） |
| ④ 自由发散题 | "换一味药你会换什么？为什么？"（L1-L4 递增） | "如果换你接诊，还缺哪些信息？"（无提示读案） |

**出题规则**：①②题全部从"已学药池/已学脉舌"出题，不考没学过的东西；答错不判死，当场补讲缺口后再重问（补的就是意义空缺）。**选项策略统一（见原则 6 B4）**：L1/L2 给选项；L3/L4 开放回答 + 鉴别追问。

**第三题（反向题）L1-L4 递增**——从"判断对错"走向"重构+推演"：

| 层级 | 药理层示例 | 诊断层示例 | 认知要求 |
|:---|:---|:---|:---|
| L1 | 给提示的是非题："去掉牡蛎还能潜阳吗？"（两选项+提示） | 给提示判断："有人说这苔腻主热，对吗？" | 判断 |
| L2 | 独立判断+说理："肝阳上亢用附子温阳压得住吗？为什么？" | 独立鉴别："弦滑脉跟弦数脉，病机差在哪？" | 判断+解释 |
| L3 | 纠错+重构："这组方错在哪？给出正确版本并说明依据" | 相似案鉴别："肝阳上亢 vs 肝郁化火，同是头晕，怎么分？" | 重构 |
| L4 | 误治推演："若按气血亏虚补之，会如何传变？如何规避？" | 证伪设计："哪些信息能推翻肝阳上亢这个判断？" | 推演+证伪 |

**第四题（自由发散题）L1-L4 递增**——从"引导发散"走向"无提示独立读案/试配"：

| 层级 | 药理层示例 | 诊断层示例 | 认知要求 |
|:---|:---|:---|:---|
| L1 | AI 给方向供选："想深挖白芍的柔肝，还是牡蛎的潜阳？" | AI 引导："这张图你想知道苔为什么白，还是为什么腻？" | 选择式发散 |
| L2 | 开放提问，AI 结合知识库标注来源回答 | 开放提问，AI 按濒湖脉学/金镜录原文+白话解回答 | 开放式发散 |
| L3 | 跨病机联结："若患者兼脾虚便溏，本方怎么调？" | 复杂合参："脉弦滑+苔黄腻，跟本案的白腻差在哪？" | 联结+比较 |
| L4 | 自主试配："新患者只给主诉，你来问诊、判病机、组方" | 无提示读案："你来问四诊，问什么我答什么" | 完全自主 |

**递增逻辑**（对应意义系统三种发展形态）：识别（同化）→ 解释 → 重构（顺应）→ 迁移（升维）。

## 课程内容与课时结构

### 第 0 阶段：系统构建（强制，前 3 课，2026-08-10）

> **本阶段是课程的第一性设计**：先搭空框架（坐标系），只给位置不给内容——学习者先有"意义系统"（知道知识站在哪、为什么学），再进案例。反对格式塔堆积（先背一大堆），不反对框架先行（框架只搭坐标、不填细节，即意义系统理论的"锚点材料"）。
> **入口分层（L1-L4）**：
> - **L1 零基础**：完整 3 课（全量框架）
> - **L2 有基础**：碎片归位版（1-2 课）——重点不是教新东西，是把他已有的零散概念放进坐标，只补空缺格
> - **L3 能辨证**：系统对照版（1 课）——不做框架课，做"他的系统 vs 我们的系统"对齐，直接进鉴别深挖
> - **L4 临床/资深**：跳过框架课，改"系统自检清单"（可选），案例中动态对齐，不问不教

**第 1 课 · 地图 + 诊断框架**（45-60 分钟）：
1. 开场意义锚点（5 分钟）：真实场景"医生问几句、摸脉、看舌就开方——他脑子里在干什么？"→ 引出全景：认病 → 病机（桥）→ 用药。**地图是开场锚点不是独立课。**
2. 四诊总览：望（看面色/神/舌）、闻（听声/嗅味）、问（十问歌）、切（摸脉）
3. 摸脉五法坐标（动手体验，强制）：让学习者自己摸寸口脉，回答 5 个问题（深浅/有力无力/顺滑涩滞/直长短促/快慢）→ 体、势、气、形、息。**先体验再命名，不记脉名。**
4. 寸关尺定位（动手体验，强制）：摸手腕骨头凸起（桡骨茎突）= 关，骨前=寸、骨后=尺，三指并排（食中无名指）。**只讲定位 + "上中下"对应，分部主病留到案例学。**
5. 舌诊（照镜子体验，强制）：让学习者自己照镜子看舌质（底子颜色）+ 舌苔（盖的毛毯）。**先自看感受，不记结论。**
6. 收束：诊断 = 采集（四诊）+ 归类（病机）；带走地图 + 五法 + 舌诊两大件

**第 2 课 · 药理框架 + 辨证归类**（45-60 分钟）：
1. 开场意义锚点："为什么是 5 味药凑一起，不是一味药加倍？"→ 答案：药会配
2. 词（药性坐标）：四气（寒热温凉）× 五味（酸苦甘辛咸）× 归经。**五味动手体验（厨房醋/糖/盐/辣椒/苦瓜）**：酸收、辛散、苦降、甘缓、咸软——先体验再命名，不记药名
3. 句（配伍）：君臣佐使（皇帝-大臣-参谋-信使角色逻辑，不背方子）+ 相须相使/相恶相反（药会配对，有合得来合不来）
4. 文（方剂）：词+句攒成完整方（经典临床的事，知道终点即可）
5. 药池阶梯（学法预告）：攒药期→半自主（20 味选药）→自主（50 味试配）→进阶（替换鉴别）；出题只用已攒药
6. 辨证归类（不锁死八纲）：辨证 = 把散乱线索归成一类（归类定性）。三类归类法可选——八纲（最通用入门）、病机对接（衔接经典基础）、六经（经典临床）。**默认"病机对接 + 八纲"入口，学习者用什么体系就用什么框架。** 用小练习引入（"怕冷的人"→表寒实）
7. 收束：全景流水线已齐（采集→归类→对接→选药）

**第 3 课 · 拼图 + 预演**（45-60 分钟）：
1. 开场收束：所有零件已齐，拼图
2. 全景拼图：一条流水线——采集（望闻问切舌）→ 归类（八纲/病机）→ 对接（经典基础病机）→ 选药（词句文药池）；一句话总结全课
3. 预演（迷你案例）："怕冷、不出汗、浑身疼"的人，用框架完整走一遍流程（采集→归类表寒实→对接表寒束表→选药方向辛温解表）——**不要求答对，只要求走流程，AI 引导不评判**
4. 收束：地图 + 坐标 + 信念（诊断用药是可走的流程），宣告"第一站：风病"

**系统构建后的案例学习**：每案例学到的药/脉/舌，**必须先放回系统构建搭好的坐标位置**（如"这是药性坐标'寒'这一格""这是五法里'息'这一维"），再展开细节。

### 阶段一：案例驱动 · 药理进阶（主体，约 60-70% 课时）

- **案例来源**：案例卡片库（1361 卡，按病机标签取用）
- **每案例流程**（AI 直接给结论，不引入诊断工具）：
  1. 呈现案例（患者主诉 + 基本情况，不直接给诊断）
  2. 意义空缺："你觉得这个人怎么了？"——**停顿，等学习者回答**（意义停顿规则）
  3. 讲病机：回指经典基础（诸风掉眩皆属于肝——一句话回指，不重复展开）
  4. 用药性兑：这个方为什么这样配（讲透关键药对与单药四气五味）
  5. **运用四步（强制，见原则 8）**：定义题 → 应用题 → 反向题 → 自由发散题（按水平 L1-L4 递增），药理层各一套
  6. 案例闭环：总结"症状→病机→药"，标记新学药对，更新进度
- **案例覆盖（病机目录对齐）**：不随机抽卡，按经典基础病机目录的**门类顺序**推进（见 `参考/病机目录映射.md`）。每个门类：先回指经典基础该门类病机总纲（逆向五步成果）→ 再从该门类卡片取 2-3 案逐案展开 → 门类学完进入下一门类。每案例学 2-3 味新药、1-2 组新药对
- **药理分层**：精讲层（临床高频药约 300-400 味，随案例积累）+ 检索层（本草纲目全量可查，遇到按需展开）
- **药物讲解**：四气五味归经 + 在此方中的角色（君臣佐使）+ 与经典基础的病机呼应

### 阶段二：诊断进阶（上台阶，约 25-30% 课时）

- **案例来源（回放机制，强制）**：阶段二**不独立排课、不独立抽卡**——读取阶段一的【案例序列】（进度追踪"学序"列），按学序 1→2→3 逐个二次进入。门类顺序、案例顺序、案例本体 100% 与阶段一一致（1:1 对应）。仅模式 B（纯诊断层）无回放依赖，按门类取卡。
- **每案例流程**（工具挂已知案例）：
  1. 回顾："上次我们知道这是肝风内动、用天麻钩藤"
  2. 意义空缺："我们当时是怎么看出来的？你觉得医生会先看什么？"——**停顿，等学习者回答**（意义停顿规则）
  3. 学诊断：望闻问切用在这个人身上——只学本案例需要的 2-3 个象
     · 脉象 → 濒湖脉学对应脉（体状诗→相类诗→主病诗）+ 白话解 + **动态脉波图**
     · 舌象 → 金镜录对应舌图（舌象→主病→方药）+ **双轨图谱直接贴出（遵循 4b 直接贴图锁死 + 4c 图谱内化规则）**
     · 面色 → 内经五色诊；问诊 → 十问歌动态扩展
  4. **运用四步（强制，见原则 8）**：定义题 → 应用题 → 反向题 → 自由发散题（按水平 L1-L4 递增），诊断层各一套
  5. 工具闭环：诊断方法挂在了已知案例上（意义锚定）
- **水平切换**：L1/L2 按上述回放；L3 同门类鉴别深挖；L4 无提示读案（见原则 7）
- **四诊合参**：李时珍明言"脉乃四诊之末"，不专以脉断，脉舌望问组合呈现
- **阶段切换判定（2026-08-10）**：三个入口条件齐备后，AI 主动提示"药理层完成，建议进入诊断层"→ **学习者确认后切换**（不自动跳，学习者可要求多学几个案例再切）：
  1. **门类覆盖**：6 大门类每门类 ≥2 案例（病机广度）
  2. **药池达标**：药池 ≥20 味（半自主期起点，保证药物积累够支撑诊断层回放）
  3. **水平锚点**：最近 3 个案例的运用四步答题，定义+应用 ≥2 次独立答对（无选项也答对）
- **D 混合模式特殊处理**：D 混合（每案例药理+诊断同步）不适用"阶段切换"（每案已在走诊断）。此时"诊断进阶"判定改为：阶段一药理学完（6 门类覆盖+药池达标）后，诊断层从"随案学象"升级为"独立读案/鉴别深挖"（从学工具切到用工具）。

### 复习机制（三线复习 × 运用四步融合矩阵，2026-08-10）

**总原则**：复习**永不"背定义"**——所有复习题都是应用型（给药说病机、给病机配药、给图谱说主病），复习是练"调用"不是练"记忆"。

- 3 学 1 复节奏（约 25% 复习课）；间隔重复 1-3-7-14-30-60 课次，每课结束前检查到期知识点
- **复习单位**：药（药池账本）+ 药对 + 脉象/舌象（图谱）+ 案例

**核心设计**：三线复习定"考什么内容"，运用四步定"考多深层次"——正交融合为矩阵。每次复习课三条线各出题，每题落在运用四步的某个层次上，深度按 L1-L4 控制。

**融合矩阵**：

| 复习线（内容） | 定义题（识别） | 应用题（应用） | 反向题（辨误） | 自由发散题（迁移） |
|:---|:---|:---|:---|:---|
| **线一：药池** | 给药说病机（反转）/"牡蛎兑哪个病机？" | 给病机从药池选药 | 给错误药对组合找错（"这组配得对吗？"） | "换一味药会怎样？" |
| **线二：案例** | 症状→病机倒推（复述链条） | 病机→症状反推 | 相似案例鉴别（肝阳 vs 肝郁） | "换你接诊还问什么？" |
| **线三：图谱** | 贴脉波图/舌象图问"什么脉/舌？主病？" | 给症状让学习者选对应图谱 | 两相似脉/舌鉴别 | 脉舌合参复述（弦滑+薄腻→？） |

**层次分配按 L 层级**（复习深度递增）：

| 层级 | 复习课出题层次 |
|:---|:---|
| L1 | 定义题 + 应用题为主（识别+应用，选项式引导） |
| L2 | 定义 + 应用 + 反向题（独立判断） |
| L3 | 四步全用，反向题升级为鉴别深挖 |
| L4 | 四步全用 + 自由发散深挖（无提示） |

**题源优先级**（每次复习课出题顺序）：
1. **到期知识点**（间隔重复表里"下次应复习课次"= 本课次的）——必考
2. 本单元 3 课新学内容（药/药对/脉/舌）——必考
3. 药池随机抽查（防遗忘）——选考

**间隔复习到期检查细则（2026-08-10）**：

**F1 到期判定**（每课结束前检查）：进度追踪间隔表记录每知识点"下次应复习课次"——**当前课次 = 下次应复习课次**即到期。按紧急度排序：**逾期**（已过到期课次未复习）> 刚到到期课次 > 接近到期（下次课次 - 当前课次 ≤ 2，预判提醒）。

**F2 呈现方式**（到期必考，走复习矩阵）：
- **药/药对到期** → 走复习矩阵"线一：药池"（正向选药/反向认药/药对配伍）
- **脉象/舌象到期** → 走复习矩阵"线三：图谱"（贴图反查/鉴别）
- 每条到期知识点出 1 题，用学习者 L 级对应层次的题式

**F3 掌握状态更新规则**（复习后判定）：

| 复习表现 | 更新为 | 下次应复习课次 |
|:---|:---|:---|
| 独立答对 + 能解释 | 已掌握 | 按间隔表推进（1→3→7→14→30→60） |
| 提示后答对 | 基本掌握 | 按间隔表推进 |
| 答错但补讲后明白 | 需复习 | **不推进**（下次复习课次 = 当前 + 1） |
| 答错且补讲仍不明白 | 未掌握 | **重置**（重新学习，回到首次间隔 1 课） |

**F4 逾期处理**：逾期知识点（过了到期课次还没复习）**优先出题**（在题源优先级第 1 条内，逾期 > 刚到期）。

**F5 非综合复习课**：日常案例课结束前只**检查**（列出到期知识点，预告"第 X 课将复习"），不展开复习；综合复习课才**执行**。

**复习边界（不越界经典基础）**：案例复盘聚焦"药"与"诊断工具"，病机只做"标签确认"（选填空），**不展开病机论证**（那是经典基础的领地）。学习者病机不牢时——不补教，**转介回经典基础对应门类复习**。
