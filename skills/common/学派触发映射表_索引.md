## 四、使用规则

1. **学生药证关产出**（核心药对从学生嘴里说出）→ 查"药对速查"→ 定位 JSON 行号读取
2. **无速查命中** → 按"一、结构速览"的层定位范围，在对应层内 grep
3. **病机触发** → 查"病机速查"第二层
4. **组方法度**（第三层）与**用户开方逻辑**（第四层）→ 按结构速览定位后检索
5. 定位后仍无法确定 → 回退全文检索（4725 行全读，仅在必要时）
6. **本索引不替代映射表**：索引只做定位，命中学派的完整触发理由以 JSON 为准
