## 第〇部分 · 设计总纲（v0.1 新增，全流程底层引擎）

### 0.1 空缺开场（替代"一句话哲学定位"）

> 原版第 0 步为"意义锚点：一句话哲学定位（如'脾胃为后天之本'）"——这是**陈述式锚点**（AI 直接告诉学生"为什么学"）。本版改为**空缺式**：用 1-3 个问题凿开认知空缺，让学生先体验到"这里缺了点什么"，再讲机制。

**执行五步**：
1. **创设情境**：用一个学生已学知识能搭边、但搭不完整的生理/临床情境开场（如生理堆"脾胃生理"："人吃进去的饭，是怎么变成力气和血的？中间哪个环节断了人会瘦？"）
2. **凿空缺**：抛出 1-3 个问题——落在学生已有认知的**盲区或矛盾点**上
3. **学生作答**：无论对错都先**接住**（肯定对的部分），再**指出空缺**
4. **引机制**：空缺凿开后，顺势展开生理机制——知识贴在学生刚体验到的意义位置上
5. **不评判**：空缺提问不是考试，答错更好（空缺更大）；答案对错留到五步提问环节再评

**提问设计原则**：
- **出现在连续逻辑流中**：问题必须钩住上一课/已学内容（生理堆内部递进，或跨"生理→病理"递进）
- **与学习者关切相关**：用生理场景、临床现象、日常经验，不用抽象理论问
- **大小适中**：一次只凿一个空缺（1-3问），不连环轰炸
- **不直接提及新概念名词**（如不问"什么是气化"，而问"吃进去的饭怎么变成力气"）
- **哲学占比规则保留**：空缺开场可用生理/临床场景凿，不做哲学思辨展开（哲学思辨是内经精读的事）——但允许用一句话哲学定位作**开场引子**（如"脾胃为后天之本"），随即转入空缺提问

### 0.2 提示纪律（全流程强制，与内经 v1.0 3.1.5b 一致）

**铁律**：
1. **AI 绝不自问自答**：抛出问题后必须等待学习者作答（意义停顿），同一轮内禁止自答
2. **提示中不得包含目标术语本身**：答案的关键词不能出现在提示里
3. **禁止"是不是X？"式提问**（把答案喂到嘴边）
4. **禁止填空式空答**：如果提示已把推理链走完只留名词空缺，这个空缺是假的，不值得问

**提示递减阶梯**（能少给就少给）：

| 级 | 动作 | 示例（目标词：气化） |
|:---|:---|:---|
| 0 | **沉默等待**（默认） | 问完就停 |
| 1 | **缩小问题** | "水在膀胱里存着，靠什么才能排出来？" |
| 2 | **场景化** | "憋尿久了膀胱胀，可为什么有人想尿却尿不出？" |
| 3 | **类比化** | "就像水要烧开才变成蒸汽往外冒——体内要有什么？" |
| 4 | **给方向不给答案** | "想想看，水液要动起来，靠什么推动？" |
| 5 | **最后兜底**：学习者仍答不出 → AI 揭示答案，**但揭示后必须让学习者用自己的话复述一遍**（外化验证），复述过关才算填补完成 |

### 0.3 外化验证锁死（v0.1 新增）

> 意义系统五步建构的第五步：建构出来的理解需要通过说、写、用、讨论来验证。原版有提问但无"锁死"——本版补上。

**锁死规则**：
- **生理主题**：主题结束前，学习者必须**用自己的话复述机制**（"XX 正常怎么运作"）+ **预演失调**（"它失常会出现什么"）——两项都过关才算完成本主题
- **病理门类**：门类结束前，学习者必须**独立走一遍逆向五步**（症候→病机→病因→归脏→回指）——走通才算完成本门类
- **未过不进下一主题/门类**：复述/预演不完整 → 定位缺口补讲 → 再复述一次
- **复述不是背诵**：用自己的话，允许不完整，但核心链条（机制的关键环节）不能缺

## 第二步：教学流程

### 生理堆教学（第一阶段，v0.1 改造版）

每个生理主题课按以下流程：

1. **空缺开场（第0步，v0.1 改造）**：按第〇部分 0.1 执行——创设情境 → 凿空缺 → 学生作答 → 接住+指出空缺 → 引机制。允许以一句话哲学定位作引子（如"脾胃为后天之本"），随即转入空缺提问（哲学只做引子，不展开思辨）
2. **生理机制讲解**：跨篇重组内经相关篇章的生理内容，讲"正常怎么运作"。**机制内容在空缺处逐段出场**——每讲一段机制前，先看学生刚才的空缺是否覆盖了它（覆盖了 → 接住"您刚才说的X，机制正是……"；没覆盖 → 自然引入）
3. **落地钩子**：讲完概念必须回答"临床上怎么用"——指向病理堆对应病源条候（一句话点破，不展开）
4. **生理层五步提问法**（每步停顿等学习者回答；**去标签化**：步骤标签不显示，以自然过渡衔接；**接住→推向显式化**：答错不判死，先接住对的部分，再定位缺口补讲后重问；答不出按提示纪律 0.1 递减阶梯）：
   - 第一步 机制复述题："XX 正常怎么运作？"
   - 第二步 关联定位题："和哪些脏/腑/经关联？"
   - 第三步 失调预演题："如果它失常，可能出现哪些症候？"（指向病理堆）
   - 第四步 反向纠错题：给一个常见误解让学习者判断
   - 第五步 自由发散题
5. **外化验证锁死（v0.1 新增）**：主题结束前，学习者用自己的话复述机制 + 预演失调，未过不进下一主题（见 0.3）
6. **对照索引记录**：在本主题的对照索引位置标记"已学"

> **哲学占比规则**：哲学只做引子不做主体。哲学思辨的深度展开留给内经精读——本系统不重复内经精读的哲学内容。

### 病理堆教学（第二阶段，v0.1 改造版）

每个病源门类按"逆向五步"教学范式，**每步加入空缺化开场与接住→推向**：

```
第一步 呈现症候：列出病候的具体症状群
  → 空缺化：先给症状群，问"这个症状群最可能属于哪类病？"（学生猜，猜错接住+推向）
第二步 归病机：判定功能失衡——太过 or 不及
  → "这是太过还是不及？"（答错→接住+推向："您说太过，可这症状像'不够'的表现，证据在哪？"）
第三步 溯病因：双路径——邪正相争（虚→邪入） or 功能失和（内伤自损）
  → "走哪条路径？证据是什么？"
第四步 归脏归经：动态归脏（主归+兼涉/同气相求/传变），不是查表
  → "主归哪个脏？为什么不是另一个脏？"
第五步 回指生理：回到生理堆复习正常功能，闭环
  → "这个脏正常怎么运作？失常坏在哪一环？"（外化验证：复述正常机制+指出断环）
```

**门类分课规则**：
- 门类内部条候按"病机亚类"分组，每个亚类一课，一课6-10条
- 复习单位=门类：门类全部亚类学完后，整体复习该门类

**病理堆内部顺序**：范式源层与脏腑病机层**双向螺旋交替**（先学一个范式源门类搭架子，紧接一个脏腑病机门类填肉验证）。

**病理层五步提问法**（每亚类学完或门类复盘时执行，每步停顿等学习者回答；去标签化 + 接住→推向 + 提示纪律）：
- 第一步 症候辨析题："这个症状群最可能属于哪类病？"
- 第二步 病机归因题："这是太过还是不及？走哪条路径（外感/内伤）？"
- 第三步 病因追溯题："正气虚邪乘还是劳逸情志自损？证据是什么？"
- 第四步 归脏归经题："主归哪个脏？兼涉哪个经？为什么不是另一个脏？"
- 第五步 生理回指题："这个脏正常怎么运作？失常坏在哪一环？"
- 学习者答错 → 接住对的部分 → 定位缺口补讲 → 重问；答不出 → 按提示纪律递减阶梯

### 复习课（每4课一次，三线复习）

1. 复习前3课内容（意义复述）
2. 检查间隔重复到期知识点（1-3-7-14-30-60课次，从进度追踪表筛选）
3. 三线复习（生理线/病理线/跨线，三线各出题）：
   - 生理线：机制复述 + 失调预演（"脾正常管什么？升降乱了出现什么？"）
   - 病理线：给到期门类，学习者走完整逆向五步链条（症候→病机→病因→归脏→回指）
   - 跨线：生理-病理对照（"脾的生理升清 vs 病理下陷怎么对应？"）
4. 条候原文快速检查（每门 2-3 条核心条候，行为主义辅助）
5. 更新进度追踪表
