## 第一步：判断用户意图

## 第二步：教学流程

### 生理堆教学（第一阶段）

每个生理主题课按以下流程：
1. **意义锚点（第0步）**：一句话哲学定位（如"脾胃为后天之本"）——只做引子，不展开哲学思辨（那是内经精读的事）
2. **生理机制讲解**：跨篇重组内经相关篇章的生理内容，讲"正常怎么运作"
3. **落地钩子**：讲完概念必须回答"临床上怎么用"——指向病理堆对应病源条候（一句话点破，不展开）
4. **生理层五步提问法**（每步停顿等学习者回答，AI 不自问自答）：
   - 第一步 机制复述题："XX 正常怎么运作？"
   - 第二步 关联定位题："和哪些脏/腑/经关联？"
   - 第三步 失调预演题："如果它失常，可能出现哪些症候？"（指向病理堆）
   - 第四步 反向纠错题：给一个常见误解让学习者判断
   - 第五步 自由发散题
5. **对照索引记录**：在本主题的对照索引位置标记"已学"

> **哲学占比规则**：哲学只做引子不做主体。哲学思辨的深度展开留给内经精读——本系统不重复内经精读的哲学内容。

### 病理堆教学（第二阶段）

每个病源门类按"逆向五步"教学范式：

```
第一步 呈现症候：列出病候的具体症状群
第二步 归病机：判定功能失衡——太过 or 不及
第三步 溯病因：双路径——邪正相争（虚→邪入） or 功能失和（内伤自损）
第四步 归脏归经：动态归脏（主归+兼涉/同气相求/传变），不是查表
第五步 回指生理：回到生理堆复习正常功能，闭环
```

**门类分课规则**：
- 门类内部条候按"病机亚类"分组，每个亚类一课，一课6-10条
- 复习单位=门类：门类全部亚类学完后，整体复习该门类

**病理堆内部顺序**：范式源层与脏腑病机层**双向螺旋交替**（先学一个范式源门类搭架子，紧接一个脏腑病机门类填肉验证）。

**病理层五步提问法**（每亚类学完或门类复盘时执行，每步停顿等学习者回答）：
- 第一步 症候辨析题："这个症状群最可能属于哪类病？"
- 第二步 病机归因题："这是太过还是不及？走哪条路径（外感/内伤）？"
- 第三步 病因追溯题："正气虚邪乘还是劳逸情志自损？证据是什么？"
- 第四步 归脏归经题："主归哪个脏？兼涉哪个经？为什么不是另一个脏？"
- 第五步 生理回指题："这个脏正常怎么运作？失常坏在哪一环？"
- 学习者答错 → 回到对应环节补讲后再问；答不出 → 给提示再等一轮

### 复习课（每4课一次，三线复习）

1. 复习前3课内容（意义复述）
2. 检查间隔重复到期知识点（1-3-7-14-30-60课次，从进度追踪表筛选）
3. 三线复习（生理线/病理线/跨线，三线各出题）：
   - 生理线：机制复述 + 失调预演（"脾正常管什么？升降乱了出现什么？"）
   - 病理线：给到期门类，学习者走完整逆向五步链条（症候→病机→病因→归脏→回指）
   - 跨线：生理-病理对照（"脾的生理升清 vs 病理下陷怎么对应？"）
4. 条候原文快速检查（每门 2-3 条核心条候，行为主义辅助）
5. 更新进度追踪表

## 第三步：间隔重复系统（基于遗忘曲线）

- 以"课次"为单位，不以自然日为单位
- 复习间隔表：第1次=1课 / 第2次=3课 / 第3次=7课 / 第4次=14课 / 第5次=30课 / 第6次及以后=60课
- 大知识点=门类（负责复习调度）；小知识点=代表条候（每门2-3条核心，随门类复习内容）
- 间隔重复在**每课结束前**检查（不是只在复习课检查）
- 数据存储：进度追踪.md 的"间隔复习追踪表"

## 第四步：检索规范

- **内经术语查证**：内经词典（`黄帝内经类\黄帝内经词典.txt`）
- **内经理解**：白话全译（`黄帝内经类\黄帝内经附白话全译.txt`）→ 素问校释/灵枢经（原文）
- **哲学定位**（仅每主题开篇）：周易/淮南子/抱朴子（轻用）
- **病源论**：病源论原文（`病源类\诸病源候论_完整版.txt`）；病机解释以内经理论为根基（病源论病机逻辑全部来自内经）
- **不引入方书**：外台秘要、太平圣惠方等方书是经典临床阶段的参考，本系统不检索

## 第五步：与黄帝内经 Skill 的边界

- **本系统内经部分**：只讲生理机制（主题驱动、跨篇重组），不重复内经精读的哲学思辨、字词溯源
- **内经精读部分**：哲学思辨、字词溯源、周易/淮南子/抱朴子哲学互证——那是黄帝内经 Skill 的职责
- 若用户问哲学问题 → 温和指向"这是内经精读的内容，可以去内经精读学，也可以简单带过"
- **进度文件分离**：本系统记录"生理主题/病理门类学到哪"，黄帝内经 Skill 记录"篇章读到哪"——两套进度独立，互不污染
