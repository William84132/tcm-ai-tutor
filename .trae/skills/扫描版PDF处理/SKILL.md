# 扫描版PDF处理工具

## 核心功能

1. **智能识别PDF类型**：自动判断是文本版还是扫描版PDF
2. **OCR文本提取**：对扫描版PDF进行光学字符识别
3. **图像预处理**：增强对比度、去噪、二值化提高识别准确率
4. **批量处理**：支持批量转换多个PDF文件
5. **多语言支持**：支持中文、英文等多语言识别

## 工具位置

- **工具路径**：`e:\叶天士\叶天士\10-学习工具\扫描版PDF处理工具.py`
- **配置文件**：工具内部配置Tesseract路径

## 使用方法

### 方式一：命令行直接使用

```bash

# 批量处理目录中的PDF
python "e:\叶天士\叶天士\10-学习工具\扫描版PDF处理工具.py" -d "E:\叶天士\叶天士\00-原著全文" -o "E:\叶天士\叶天士\00-原著全文\文本版"

# 检查依赖项

```

## 参数说明

| 参数 | 说明 | 示例 |
|:--- |:--- |:--- |
| -i, --input | 单个PDF文件路径 | -i "古籍.pdf" |
| -o, --output | 输出文件/目录路径 | -o "古籍.txt" |
| -d, --dir | 输入目录（批量处理） | -d "E:\PDF" |
| --check | 检查依赖项 | --check |
| --ocr-only | 强制使用OCR模式 | --ocr-only |
| -h, --help | 显示帮助信息 | -h |

## 处理流程

1. **输入判断**：判断输入是单个文件还是目录
2. **类型识别**：使用pdfplumber尝试提取文本，判断是文本版还是扫描版
3. **文本提取**：
   - 文本版PDF：直接使用pdfplumber提取
   - 扫描版PDF：使用OCR提取，包含图像预处理
4. **结果保存**：保存为UTF-8编码的TXT文件
5. **状态反馈**：返回处理结果和文件路径

## 注意事项

1. **扫描版PDF质量**：图像越清晰，识别准确率越高
2. **文件大小**：超大PDF文件可能需要较长处理时间
3. **语言包**：确保已安装中文语言包(chi_sim)
4. **输出编码**：默认UTF-8编码，兼容中文
5. **目录结构**：批量处理时保持原目录结构
