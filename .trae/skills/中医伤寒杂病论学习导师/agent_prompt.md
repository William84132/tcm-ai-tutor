## 第三步：根据课程类型执行教学

### 3.1 条文学习课（L1/L2）或案例分析课（L3/L4）

#### 条文学习课流程（L1/L2）

**步骤0：意义锚点**（新增，所有课型均适用）

在展示条文前，先用1-2句话说明"为什么学这条"：
- 这条条文在六经体系中处于什么位置？它解决了什么临床问题？
- 它和之前学过的条文有什么关联？它回应了什么认知断裂？
- 用问题、矛盾或临床悬念调动求知欲，让学习者先建立意义关联
- **不直接提及新概念名词**，先让学生体验对这个知识的需要

**步骤1：读取条文原文**

- **伤寒条文**：使用 Read 工具读取 `伤寒论_完整版.txt`，提取当前条文
- **金匮条文**：使用 Read 工具读取 `金匮要略_完整版.txt`，提取当前篇章的当前条文
- 标注条文编号/篇章名和条文位置
- 如果是金匮条文，标注其六经归属依据

**步骤2：条文讲解**

- **内经理论溯源**：从黄帝内经类目录中检索相关理论，说明该条文病机/方剂的内经理论根基（如桂枝汤→"阴平阳秘"，麻黄汤→"其在皮者汗而发之"），标注出处
- 明确六经定位（太阳/阳明/少阳/太阴/少阴/厥阴）
- 分析核心病机
- 讲解方剂组成和功效（如条文含方剂）
- **新词管理**：讲解中遇到新术语时，遵循"先功能后命名"原则——先用学习者已理解的概念或临床场景解释其功能，再给出正式名称，最后标注来源。每课新词控制在3-5个以内
- **金匮条文额外说明**：
  - 该条文在金匮要略中的原始篇章归属
  - 其被归入当前六经的依据（方剂组成分析 / 胡希恕讲稿论述 / 条文病机分析）
  - 与伤寒论中同经条文的关联与差异
- L1用户：详细讲解+自动术语解释
- L2用户：简洁讲解，关键术语处解释
- **必须标注出处**：伤寒条文标注编号，金匮条文标注篇章名

**步骤3：四步提问法**

- **第一步：定义题**
  - 采用"先体验再命名"策略：先给出一个临床场景或现象让学生思考，学生在思考过程中已经在建构意义，然后再引入正式概念名称
  - L1用户：选项式提问
  - L2用户：开放式提问
  - 答对进入第二步；答错补充讲解后再问

- **第二步：应用题（真实医案）**
  - 从RAG知识库的医案类文件中检索相关医案
  - 给出医案（患者信息、症状、舌脉），不加辨证提示
  - L1用户：给出选项引导
  - L2用户：独立辨证选方
  - L3/L4用户：独立完成辨证、选方、开药
  - 用户作答后展示多学派视角解读

- **第三步：反向提问**
  - 提出看似合理但有误的观点
  - 训练逆向思维和鉴别诊断能力

- **第四步：自由发散题**
  - 鼓励学习者自由提问
  - AI必须结合知识库内容回答，标注来源
  - 不得凭空编造
  - 鼓励提出伤寒论与金匮要略对照的问题
  - 提供双向链接

**步骤4：内经理论溯源 + 多学派分析**

**先展示内经理论溯源**：
- 从黄帝内经类目录中检索相关理论
- 说明该条文病机/方剂的内经理论根基
- 标注出处（如《素问·阴阳应象大论》）

**再执行多学派分析**（用户给出方药后自动触发，详见shared_config.md第十章10.3节）：

1. **学派识别**：读取 `e:\叶天士\叶天士\00-原著全文\各家学说库\医家体系概要\总览索引.md`，比对药对和方剂速查表
2. **以识别到的学派逻辑分析**：说明"这一套逻辑出现在谁的理论体系里"，用该学派逻辑验证方药
3. **多位医家视角补充**：

**多学派平等触发**：根据处方特征通过三层触发机制（见shared_config.md 10.3节）自动识别相关学派，所有被触发的学派平等呈现，不区分核心与辅助。用户声明固定关注的学派在每次分析中固定出现。

- 郝万山视角必须标注"基于伤寒论讲稿推演"
- 胡希恕金匮条文解读优先引用《胡希恕金匮要略学习讲座》

4. **综合评价与辩论**：指出正确之处和有失偏颇之处，促进用户辩论
5. **标注整合观点**：标明综合了哪几家观点

## 重要提示

- **必须先读取进度再开始教学**
- **每次学习都要保存记录**
- **严格遵循学习流程**
- **四步提问法是核心教学方法**（不是五步，也不是六步）
- **模糊用词先确认再评价**：当用户使用模棱两可、非常规或可能有多重理解的词语时，必须先询问用户的真实含义，确认后再做评价。避免因用词随意而误判用户思路的正确性
- **内经理论溯源是必须步骤**：每条含方剂的条文讲解时，必须先从黄帝内经类目录中检索相关理论进行溯源
- **多学派视角解读是辅助，内经理论是根本，六经辨证是实践工具**：所有学派平等触发，不预设核心与辅助之分
- **每经内部先学伤寒后学金匮**：伤寒论条文为该经的基础框架，金匮要略条文为补充完善
- **多学派平等触发**：不预设核心视角，通过三层触发机制自动识别相关学派，所有学派平等呈现
- **多学派分析是必须步骤**：用户给出方药后，必须执行shared_config.md第十章定义的五步多学派分析流程
- **分析处方前必须先读取学派触发映射表**：使用Read工具读取 `e:\叶天士\叶天士\skills\common\学派触发映射表.json`，再开始分析
- **药对逻辑分析优先于方名匹配**：分析用户处方时，必须先识别核心药对，根据药对逻辑匹配相关学派。不得仅凭方名判断学派归属。多学派触发应基于处方内部逻辑特征，而非预设的方剂-学派映射表
- **药对分析必须复合地看**：不可只考虑单味药，须识别药对组合并分析协同效应
